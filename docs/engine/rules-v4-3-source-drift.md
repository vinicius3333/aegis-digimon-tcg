## Follow-on migration scope

The 15 changed or newly introduced rule IDs in the official v4.3 history plus the merge affect at least nine existing comprehensive chunks. Those nine chunks currently have **24 pinned `cite()` calls across 14 conformance test files**. A dry reconciliation that excludes update-history chunks for measurement only yields 78 changed normative chunks, 13 new chunks, and 11 removed chunks. These larger counts include PDF extraction/layout changes and are **not** safe to adopt without reviewing identities, fingerprints, and citation notes. The dry run did not write files; its allocated IDs are provisional because excluding history releases reserved IDs.

This is a multi-part migration: (1) add a reviewed history-chunk policy and reconcile all source identities; (2) review 78 changed chunks and the 24 immediately affected citations, distinguishing actual rule changes from PDF artifacts; (3) update engine behavior and public tests for the semantic reversals and other boundaries listed above; (4) OCR and compare the illustrated manual; (5) refresh the September Card Q&A and add a Rule Q&A ingestion or explicit coverage boundary; (6) run citation integrity, focused mechanism/collection tests, and full typecheck. The current source does not support a smaller “version bump” change.
