# Retaliation lifecycle

The §16-13 contract triggers only when the Digimon with Retaliation is deleted in battle; the battled opponent Digimon is then deleted and the processing is mandatory. Bounded public cases cover native BT19-059, inherited BT19-067, a plain control, and the effect-deletion exception: public ST1-16 Gaia Force deletes a Retaliation holder without causing Retaliation, while an unrelated permanent survives. Assertions use the exact physical source and target instance IDs.

This evidence does not certify ties, security battles, or every grant producer.
