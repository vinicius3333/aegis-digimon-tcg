# Engine notes

Each note here explains one engine mechanism that spans card sets: its rules
sources, its edge cases, and the evidence behind the current behavior. File
names use kebab-case.

These notes once lived in `docs/audits/engine/`. The per-set audit ledgers
(`docs/audits/<SET>.md`) and their scores were removed. Older notes still cite
those ledgers; read them in git history if you need the old evidence.
