## Knowledge-base check

- `node tools/kb/query.mjs card EX13-013` → `(no knowledge-base entries)`. **No KB rulings
  available; the set is pre-release.** No card-specific Q&A was invented.
- `node tools/kb/query.mjs rules "Engage"` → no chunks. The general rule is in
  `data/kb/rules/comprehensive.md`:
  - **16-44 ＜Engage＞** — "a keyword effect where a Digimon with this effect may attack at the
    end of your turn"; **16-44-2** it is a trigger-type effect at the End of Your Turn timing;
    **16-44-3** the processing is optional. This is exactly the `Static` keyword marker plus an
    `EndOfYourTurn` optional self-`Attack` encoding used by EX12-019, EX12-060 and 20 other
    cards.
  - **§4-22-1** — "with [X] in its text" means the token anywhere in the printed information,
    which the engine models as `match: "text"` (name ∪ traits ∪ every printed text field). KB
    Q4574 records the same reading for BT21-066.
- Borrowed card-specific rulings on the *sentence shape* (not on this card): BT19-015's KB Q3070
  (the delete is mandatory when a legal target exists) and Q3071 (a chosen but undeletable target
  still counts as "didn't delete"). Both are properties of the shared IR shape, which is why the
  `Delete` carries no `optional`.

### Cross-card consistency

- Delete-or-buff shape mirrors `BT19-015` (same sentence, different DP band and duration) and
  `BT25-014` (`ifThisEffectDidNotDelete` after a mandatory `Delete`).
- Dual-timing single body mirrors `BT21-029` and `BT26-073`; `sharedUseKey` is deliberately
  omitted because neither printed clause carries `[Once Per Turn]`.
- `PlayWithoutCost` from hand-or-trash mirrors `BT26-073` / `BT21-066`.
- `SecurityManipulation {op:"trashTop", controller:"opponent"}` mirrors `ST22-06`.
- `selfHasNameContaining` mirrors `BT17-015` / `EX3-041`; the host check makes this the inherited
  counterpart of the `match: "name"` substring reading already used by the set's `EX13-001`,
  `EX13-002` and `EX13-007`.
- Fixtures follow the set convention: inert main-deck bodies only, no Digi-Egg in security or
  deck, no numeric `security: <n>` form, and a spare playable card in hand wherever a Main phase
  has to stay open.

## Remaining ambiguity

- `[End of Attack]` for a Digimon deleted *during its own attack* would fire both printed
  triggers; with no KB Q&A for the set, the tests deliberately isolate each timing (a surviving
  attacker for `[End of Attack]`, a deleted defender for `[On Deletion]`) rather than assert an
  ordering the printed text does not settle.
- `＜Engage＞`'s attack target is chosen by the engine's own `Attack` action (it checks security
  here). The printed keyword names no target, so nothing card-specific is asserted about it.
- The module is not imported by `apps/api/src/cards/EX13/index.ts` (a file this lane may not
  edit); the test registers the card by importing `./EX13-013.js` directly. **The coordinator
  must add the `import "./EX13-013.js";` line to that index.**
