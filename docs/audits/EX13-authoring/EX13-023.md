## Authoring decisions

- **"change orientation" has no dedicated action.** EX13-023 is the only card in the catalog
  printing that sentence. Choosing the Digimon already fixes the direction, so the clause is a
  two-bullet `Modal`: suspend an unsuspended Digimon, or unsuspend a suspended one.
  `optionConditions` gate each bullet on a matching battle-area Digimon existing —
  `canAttemptModalAction` (`apps/api/src/engine/effects/interpreter/actions/modal.ts`) treats
  Suspend/Unsuspend as always attemptable, so without the gates the player would be offered a
  guaranteed no-op branch. With them, `runModal` skips the impossible direction and auto-selects
  when only one remains; the tests prove both the no-prompt single-direction path and the real
  `chooseOption` when both directions exist.
- **`traits: ["CS"]` is exact trait equality**, the "w/[X] trait" wording, over forms ∪ attributes
  ∪ types. The header carries no color, so it is strictly wider than the printed Blue Lv.5
  EvoCost — proven with a yellow Lv.5 [CS] Angewomon, with a colour/level-matched yellow Lv.5
  **without** [CS] and a Lv.4 **with** [CS] as the two negatives.
- **`names` (substring), not `namesExact`**, for the Assembly slots: the header says "in name", so
  AeroVeedramon and ExVeemon qualify.
- **The `[All Turns]` clause follows BT26-029**, which prints the same sentence: `dpImmune` for
  the DP half, `StackTrashLock` for "or trash them" (the seat-aware stack lock), and
  `returnToHandOrDeck` — which `maps.ts` normalizes to `beReturned` + `byOpponentEffectsOnly` — for
  "return its stacked cards to the hand or deck".
- **"this unsuspended Digimon" is a live gate, not a one-shot condition.** `Restrict` carries it on
  `while`, which marks the restriction continuous; `StackTrashLock` has no `while`, so it rides the
  continuous pass with `condition` instead (an `AllTurns` record is cleared and re-derived from a
  clean tier on every `recomputeContinuousEffects`, the shape EX11-070 already uses). Both halves
  are proven two-sided: protected while unsuspended, lifted once suspended, restored on unsuspend.
- **No `returnDigivolutionCardsFirst`** on the return action: the printed sentence returns the
  Digimon, and the ordinary leave handling trashes the stack beneath it. Asserted.

## Remaining ambiguity

- The catalog shows no near-miss trait anywhere in the game whose text contains `CS` without being
  exactly `CS`, so the exact-vs-substring distinction for the digivolve header is argued from the
  printed "w/[X] trait" wording and the codebase convention rather than from a discriminating
  fixture. The available negatives (colour/level-matched non-[CS], and [CS] at the wrong level) are
  what the card pool allows.
- `＜Evade＞` interacts with the `[All Turns]` clause only in that the clause never protects against
  deletion; that separation is asserted implicitly by the Evade tests, which run while the Digimon
  is unsuspended and still let the deletion reach it.
