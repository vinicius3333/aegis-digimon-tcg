### Authoring decisions

- **No preceding `Suspend`.** Every earlier printing of "can't unsuspend until their turn
  ends" (EX12-063, BT26-042/044/046, EX9-042/044, P-209, EX11-031/036) pairs it with a
  suspend. Mikemon's `[On Play]`/`[When Digivolving]` does **not** — the Restrict stands alone,
  so an already-unsuspended permanent is a legal (inert-until-it-suspends) choice.
- **`duration: "untilOpponentTurnEnd"`**, matching every peer printing. `clearsAt`
  (`apps/api/src/engine/effects/continuous.ts:488`) clears `UntilOpponentTurnEnd` only on a
  turn-end sweep whose sweep seat is not the source owner, so the lock survives my own turn end
  and the opponent's unsuspend phase, then lapses at their turn end. Proven both ways: an
  explicit `sweep(state, "ownerTurnEnd", 0)` leaves it standing, and a full `runTurn(1)`
  clears it. Mutating the duration to `forTheTurn` turns this test red.
- **`sourceFilter: { isSelfRef: true }` on `whenSuspended`**, the shape P-093 uses for the
  identical sentence. This is exactly the `whenSuspendedSelfGate` path
  (`interpreter/actions/subTrigger.ts:460`), which compares suspended-permanent ids to the
  anchor; per REVIEW-NOTES that gate ignores other `sourceFilter` predicates, and this card
  bundles none, so there is no footgun here. The bus covers combat suspension
  (`combat/controller.ts:1225`), which the attack test exercises.
- **No `frequency`.** Neither printed clause carries `[Once Per Turn]`, so two host
  suspensions in one turn each fire; the test asserts the second one.
- **`Aura`, not `ModifyDP` + `duration: "permanent"`.** Both express the continuous buff
  and both pass this suite, but `Aura` is the dedicated continuous primitive (no `duration`
  field) and is what EX13-038 uses for this byte-identical printed sentence. Chosen for
  cross-card consistency.
- **No `digivolutionRequirement`.** No `[Digivolve]` line is printed; the catalog `evoCosts`
  entry is the only route. The red-Lv.3 negative runs with `useAlternateCost` both `false` and
  `true` and asserts the base card is unchanged and memory is untouched — not merely
  `ok: false`.

## Remaining ambiguity

- The test imports `./EX13-040.js` directly because `apps/api/src/cards/EX13/index.ts` is
  coordinator-owned and does not list the module yet. The coordinator must add
  `import "./EX13-040.js";` there.
- "When this Digimon suspends" is read as every suspension cause (effect, cost, and the attack
  declaration), which is how the `whenSuspended` bus is wired and how P-093 behaves. No EX13
  ruling exists to narrow it to effect-only suspension; if a post-release Q&A does, the fix is
  `event: "whenEffectSuspends"`.
