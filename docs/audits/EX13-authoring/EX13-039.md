### Fixtures

Inert bases and fillers only; no Digi-Egg in deck or security, and the one Digi-Egg used
(BT20-002) sits in the trash, which the brief permits. `ST1-04` Dracomon (Red Lv.3, 4000 DP,

is colorless; `BT1-027` Armadillomon (Blue Lv.3, inert) is the off-color non-Dracomon control
that is refused outright, which is what attributes the 2 charged off ST8-03 to the alternate
rather than to an EvoCost. `BT1-013` / `BT1-014` are the in-name and wrong-level negatives.

### Mutation evidence

Deleting `excludeKind: ["DigiEgg"]` from the trash filter fails 3 of the 16 tests (the
return, the Digi-Egg-only negative, and the decline test, which all then see the Bebydomon as
a legal return). The field is load-bearing, not decorative.

## Remaining ambiguity

- **`printedTextOnly` on the `match: "text"` filters.** Per REVIEW-NOTES this flag narrows a
  live `match: "text"` ref to a permanent's own printed information (§4-23-2). It is omitted
  here, matching EX13-018 — the card with this exact printed sentence — and the omission is
  behaviourally inert in both places it could go: a `whenPlayed` subject has just entered the
  battle area by PLAY, so its digivolution stack is empty, and the `into` pool is loose hand
  cards, which have no stack at all. The trash filter reads card definitions, not permanents.
  Worth a note only because EX13-021/EX13-024 do set the flag on filters where it *is*
  live; this card has no such filter.
- **Alternate-route negatives.** `useAlternateCost` is a preference in both directions
  (REVIEW-NOTES), so the in-name negative asserts the **memory charged** (3, the printed Red
  EvoCost) rather than `ok: false`. `alternateRequirementIndex` was deliberately *not* used to
  pin the printed route: per `apps/api/src/engine/actions/digivolve.ts:524` an explicit index
  that matches nothing fails the whole digivolve, so it cannot express "printed route only".
- **Which trash card is returned** when several non-Digi-Egg token cards sit in the trash is
  the controller's free choice; the test seeds exactly one legal candidate so the outcome is
  deterministic.
- **Peer divergence, informational:** BT20-040 Coredramon is this card's earlier Green/Red
  printing. It shares the alternate `[Digivolve]` header verbatim but its watcher is narrower
  (blue Digimon only, into `[Groundramon]` by name), so only the header is shared IR — no
  conflict.
