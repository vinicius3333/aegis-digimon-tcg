## Notable IR decisions

- **`payCost: false`, not `reduceCostBy`.** This card's otherwise identical sibling EX13-019
  prints "with the cost reduced by 2" and uses `payCost: true` + `reduceCostBy: 2`. "Without
  paying the cost" is the free-play form, so no memory moves at all.
- **`sharedUseKey` across three timings.** One printed `[Once Per Turn]` spans `[On Play]`,
  `[When Digivolving]` and `[When Attacking]`; without the shared ledger key each window would
  keep its own counter (EX13-012 / EX12-024 precedent).
- **The inherited name gate lives in `hostFilter`, not `sourceFilter`.** The `whenSuspended`
  branch of `registerSubTrigger`
  (`apps/api/src/engine/effects/interpreter/actions/subTrigger.ts`, `whenSuspendedSelfGate`)
  reads only `sourceFilter.isSelfRef` and compares the suspended permanent ids to the anchor; the
  filter's other predicates are never consulted on that path, so a `nameOrTrait` bundled into
  `sourceFilter` would have been silently inert. `hostFilterGate` runs the full
  `permanentMatchesFilter` against the anchor host, whose `nameOrTrait` reads the host's top card.
  EX13-017's identically worded clause puts the token in `sourceFilter`, but it rides a
  `Replacement`, which does evaluate the whole filter.
- **`restriction: "suspend"` with no `blocksCombatSuspend`.** The interpreter records a printed
  `"suspend"` restriction as `beSuspended`, and `ContinuousEffects.hasRestriction`
  (`apps/api/src/engine/effects/continuous.ts`, `equivalentRestrictions`) treats the two spellings
  as one prohibition at the read boundary, so effect suspension and the implicit attack-declaration
  suspend are both already covered. Matches BT20-084 / BT22-027.
- **No `excludeSelf` on the Tamer-play watcher.** "Any of your Tamers" has no "other", and the
  flag would be inert anyway since this card is a Digimon.

## Remaining ambiguity

- **`traits` vs `traitSubstrings` for `[CS]` is behaviourally unobservable.** `traits: ["CS"]`
  (exact) is the correct reading of "w/[CS] trait" and matches EX13-019/EX13-012/BT23-008, but no
  card in the catalog carries a trait containing `CS` as a proper substring (the substring check
  in `cardData.ts` is case-sensitive, so "Abadin Electronics" does not qualify), so swapping to
  `traitSubstrings` leaves every behavioural test green. The choice is pinned by the compiled-shape
  assertion and the peer convention only. The illegal-source test still carries BT17-034 Bulkmon
  (Yellow/Green Lv.4, trait "Abadin Electronics") as the closest available near-miss.
- **Simultaneous-event ordering for the lock.** When several of the controller's Tamers enter in
  one resolving effect, the clause should fire once; no such card is available in EX13 to exercise
  it, and `oncePerTiming` was deliberately not added since the printed `[Once Per Turn]` already
  caps the clause at one activation per turn.
