## Retained red (engine seam)

`it.fails("lets another granted ＜Guard＞ holder pay to save PrinceMamemon")`.

§16-45-1 scopes ＜Guard＞ to the **holder's other** Digimon, so a BigMamemon that received
the keyword should be able to delete itself to keep PrinceMamemon in play. A leave-prevention
`Replacement` is registered once against the permanent that carries the IR
(`apps/api/src/engine/effects/leavePrevention.ts` keys subscriptions by source permanent) and
`Filter.excludeSelf` is **source**-relative, so one anchored subscription can either protect
the anchor — which made PrinceMamemon illegally save itself (observed: an opponent-effect
deletion of a lone PrinceMamemon returned a deleted count of 0) — or exclude it entirely.
Never "every holder protects everyone but itself".

This module takes the narrower reading (`excludeSelf: true` on `target.filter` and
`sourceFilter`), because it never produces an illegal save: PrinceMamemon's own ＜Guard＞ then
behaves exactly as printed. Expected in the retained test: PrinceMamemon survives and
BigMamemon is trashed. Actual: PrinceMamemon is deleted, BigMamemon untouched. Fix shape: a
real ＜Guard＞ keyword hook that subscribes once per keyword **holder**; no card-side field
expresses it. `coverage: "partial"` with that one `residual` entry.

EX12-072 grants the same keyword with the same approximation, but there it is unobservable
(its source is a face-up security card, never a Digimon in the protected pool).

## Remaining ambiguity

- The reveal slot's `match: "trait"` (exact [Mutant], not `traitContains`) is asserted
  structurally only. The single substring-adjacent trait in the catalog is
  `[Ancient Mutant]`, carried solely by BT12-071 / BT18-074 at play cost 13 / 12 — both
  already refused by `playCostLte: 10`, so no fixture can separate the two modes
  behaviourally here.
- Assembly materials with no level (an Option or Tamer printing `[Mamemon]`, e.g. BT8-106)
  are refused because "Lv.5 or lower" needs a level. That reading follows
  `materialMatchesAssemblySlot`; no pre-release ruling confirms it for this card.
