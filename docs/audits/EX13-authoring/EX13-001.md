Printed clauses — the card has exactly one, on the inherited line:

1. `[Your Turn]` — the clause only fires while its controller holds the turn.
2. `[Once Per Turn]` — one activation per turn, resetting on the controller's next turn.
3. "When any of your red Tamers are played" — trigger: a Tamer, controlled by this
   Digimon's controller, that is red.
4. "this Digimon may digivolve" — optional, and the digivolving permanent is the host
   carrying Gigimon in its digivolution cards.
5. "into a Digimon card with [Growlmon] or [Gallantmon] in its name in the hand" — a
   Digimon card, name substring match on either token, sourced from the hand only.
6. "with the cost reduced by 2" — a real digivolution (requirements still apply), with the
   printed digivolution cost reduced by 2.

## Implementation

`apps/api/src/cards/EX13/EX13-001.ts` — one inherited `YourTurn` effect with
`frequency: "OncePerTurn"`, whose single action is a `SubTrigger` on `whenPlayed` filtered
to `{ controller: "mine", kind: ["Tamer"], colors: ["Red"] }`, resolving an optional
`Digivolve` of the self permanent into a hand `Digimon` filtered by
`nameOrTrait: [{ tokens: ["Growlmon"], match: "name" }, { tokens: ["Gallantmon"], match:
"name" }]` with `payCost: true` and `reduceCost: 2`.

Peer precedent (no new primitive invented):

- `P-188` / `BT25-002` — the `YourTurn` + `OncePerTurn` + `SubTrigger` on `whenPlayed`
  with a Tamer `sourceFilter` (P-188 uses `colors: ["Blue"]`, the exact colour-filter form
  reused here).
- `BT23-053` — the `Digivolve` + `into.nameOrTrait` + `from: ["hand"]` + `reduceCost: 2` +
  `optional` half, including the `target: { filter: { isSelfRef, kind: ["Digimon"] },
  isSelf: true }` shape.
- `EX5-001` — the nearest Digi-Egg precedent for an inherited "this Digimon may digivolve
  out of hand at a discount" clause.

`match: "name"` is the substring form, which the printed "in its name" wording requires —
so WarGrowlmon is a legal destination (proven behaviourally), as would be
Gallantmon: Crimson Mode.

### Evolution-stack and cross-card verification

- The smallest legal stack that reaches this clause is used throughout: an inert red host
  with `under: ["EX13-001"]`, i.e. Gigimon as the bottom digivolution card, exactly as a
  hatched Digi-Egg sits. After each effect-driven digivolve the test asserts the full
  ordered stack by instance id (`[egg, previousTop, …]`) and that `stack[0].cardId` is
  still `EX13-001`, so source identity and the inherited clause survive the transition —
  the once-per-turn test chains two digivolves and asserts the three-card stack.
- Illegal-source negative: `ST7-09` (red Lv.5 base) and `ST7-08` (red Lv.4 base) both
  match the name filter but have no route from the red Lv.3 host, and are left in hand.
- Unreduced control: the same Growlmon digivolved by the plain public `digivolve` intent
  costs the printed 2, pinning the 2 charged to the reduction rather than to the fixture.
- Fixtures follow the brief: inert main-deck Digimon (`BT1-009`, `BT1-013`, `BT1-020`,
  `BT1-024`), no Digi-Egg in deck or security, no numeric `security: <n>` form, and a
  spare playable card kept in hand so Main never auto-passes.

## Remaining ambiguity

- No card-specific ruling exists yet (pre-release set), so two readings are settled by
  general rules and peer precedent rather than by Q&A:
  1. "with the cost reduced by 2" is treated as a reduction of the digivolution cost with
     the digivolution requirement still enforced (comprehensive §2-3-5, §7-2-3-3), the
     same reading `BT23-053` uses for identical wording.
  2. "in its name" is a substring match, so WarGrowlmon / Gallantmon: Crimson Mode qualify.
     This follows the brief's naming rule ("w/[Name] in name" is substring) and the
     `match: "name"` convention across the codebase.
- The English text is a pre-release community translation; if the printed card differs on
  release, clause 5's token list is the single place to revise.
