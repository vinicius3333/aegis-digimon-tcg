### Authoring decisions

- **`match: "name"` everywhere, not `nameExact`.** "w/[Sukamon] in name" / "with [Chuumon] or
  [Sukamon] in its name" are the substring reading (§2-3-1, and the existing
  BT11-040/BT11-041/BT11-043/EX13-027 encodings of the same sentences). PlatinumSukamon is the
  positive substring proof; Geremon — which prints `[Sukamon]` only in its effect text — is the
  negative. Both tokens live in ONE `nameOrTrait` ref because `tokens` is an OR-list.
- **No `hostFilter: {isSelfRef: true}` on the trash cost.** The card says "your Digimon's
  digivolution cards"; BT11-041's otherwise identical pool says "this Digimon's" and therefore
  carries the host gate. Adding it breaks the other-stack test (mutation-checked).
- **No `payCostBeforeOptional`.** §15-7 makes the "by X" condition the player's own choice, so the
  accept/decline is one decision and declining spends nothing. The three repo cards using that
  flag (BT17-050/-059/-080) each cite a card-specific ruling (Q2813/Q2853) that pre-commits the
  cost; no such ruling exists for this pre-release card. See "Remaining ambiguity".
- **No `SetBaseDP` beside the grant.** BT11-043 (the BT11 KingSukamon, same sentence) carries only
  the object grant and still reports `currentDP === 3000`; BT14-097's extra `SetBaseDP` is
  redundant.
- **Three separate effects, no `sharedUseKey`.** The card prints no `[Once Per Turn]` over its three
  timings (contrast EX12-060 / EX13-014, which do).
- **`count: 3` in one Assembly material slot**, not three slots: the header repeats one requirement
  and adds no "different names/levels" qualifier, so three copies of one Sukamon are legal.

## Retained reds / engine gaps

None. No `it.fails`, no `it.skip`, no `@ts-nocheck`; `coverage: "full"`, `residual: []`.

Two engine behaviours worth recording, neither a gap for this card:

- An accepted optional action whose cost is payable but whose target set is empty still pays the
  cost (observed while building the Black Lv.4 route test, where the Sukamon-named base itself was
  the only payable card and no opponent Digimon existed). That test declines the clause instead of
  asserting the behaviour, because the printed text is silent and no ruling covers it.
- `onDeletionOf` usually resolves its `sourceFilter` against a card definition (the deleted
  permanent is already gone), yet `excludeSelf` is still honoured here — the mutation check
  confirms removing it makes the host's own deletion arm the watcher.

## Remaining ambiguity

Whether a player may pay the trash cost and then decline the rewrite. §15-7 treats "by X, Y" as one
optional condition (the encoding used here: decline costs nothing), while the Q2813/Q2853 family of
rulings pre-commits the cost for cards whose payload adds its own "you may". If an EX13 ruling later
says the trash is spent regardless, the fix is one field: `payCostBeforeOptional: true`.
