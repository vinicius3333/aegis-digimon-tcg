## Knowledge-base check

- `node tools/kb/query.mjs card EX13-011` → `(no knowledge-base entries)`. No rulings
  available; EX13 is pre-release (street date 2026-10-02). Nothing invented.
- General rules consulted: `comprehensive §16-23` ＜Raid＞ — a trigger-type keyword that may
  switch the attack target to the opponent's unsuspended Digimon with the highest DP when the
  Digimon with the keyword attacks. The engine's existing Raid implementation matches this,
  so the card only declares the keyword.
- `[Mon]` resolves to exactly one printed card: the EX13-075 White Tamer (play cost 4).

## Remaining ambiguity

- The catalog prints `w/[Huckmon] in text`, the community-database spelling of the official
  `[Huckmon] in its text`. The engine's `texts` gate reads the full card-information union, so a
  card merely *named* Huckmon also qualifies — consistent with EX12-051 / KB Q6829. No EX13
  ruling exists to confirm this for BaoHuckmon specifically.
- The alternate route's cost (2) equals the printed red Lv.3 cost, so the alternate only widens
  the legal base pool; it never produces a cheaper route.
