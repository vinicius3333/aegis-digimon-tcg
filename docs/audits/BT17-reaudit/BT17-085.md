## Q2868 name gate — fixed in shared (lane S); a second, unrelated seam keeps the test red

The **naming** half of Q2868 is closed.

- File: `packages/shared/src/cards/effectiveNames.ts`, `parsedStaticNameAliases`.
- Was: the parser harvested every `[X]` in an "also treated ..." phrase as a **full name
  alias**, so `effectiveStaticNames("EX4-030")` yielded `["Kuzuhamon", "Sakuyamon"]` and
  `match: "nameExact"` accepted Kuzuhamon as `[Sakuyamon]`.
- Now: aliases are split into two channels. "treated as **having** [X]" / "[X] **in its
  name**" feeds `effectiveSubstringOnlyNames` only; a bare "also treated as [X]" /
  "(Rule) Name: Also treated as [X]" feeds `effectiveExactNames`.
  `effectiveExactNames("EX4-030")` is `["Kuzuhamon"]`.
- Readers: `apps/api/src/engine/effects/interpreter/matching/definition.ts`
  (`match: "nameExact"`) and `apps/api/src/engine/cards/cardData.ts`
  (`matchGatedRequirement`'s `namesExact` gate) now read the exact channel.
  Behaviourally, Rika's route no longer digivolves Renamon into EX4-030.

## Cross-file test-hygiene defect found by lane S (BT17-085.test.ts:179)

`it("does not treat an unrelated Digimon as Sakuyamon for the named evolution")` activates
Rika's `[Main]` effect and asserts **synchronously** — no automation flags on `setupEngine`, no
`settle`, no `respondDecision`. The activation raises an `optional` decision nobody answers, so
the test ends with an engine resolution still in flight. That orphaned resolution churns
microtasks in the same worker and starves the next file's `advance.waitForMainPhase`, which
polls on microtasks. This is the cause of the 15 s timeout on
`BT17-019.test.ts > treats [Matt Ishida] as a substring of the Tamer name` in
`logs/restart-checkpoint-collection.log`; BT17-019 itself is clean.

Fix (card lane / coordinator; lane S may only flip `it.fails` in this file): settle the
activation before asserting — `{ autoDeclineOptional: true }` plus a `settle`, or an explicit
declining `respondDecision`, then `assertNoLoudGap(s)`. Isolation evidence is in
`SHARED-NAME-ALIAS-MECHANISM.md` section 6.
