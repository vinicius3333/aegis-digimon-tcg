# BT17-048 Argomon — re-audit

Lv.5 Green/Purple Mutant Digimon, DP 7000, play cost 8. Normal evo: Green/Purple
Lv.4 for 5. Printed alternate: `[Digivolve]Lv.4 [Argomon]: Cost 4`.

## Printed clauses

1. `[Digivolve]Lv.4 [Argomon]: Cost 4` — alternate evolution route.
2. When digivolving into this card, by suspending up to 5 Tamers, reduce the
   digivolution cost by 1 per Tamer suspended.
3. `[Opponent's Turn]` None of your opponent's Tamers can unsuspend.
4. `[On Deletion]` If 4+ [Argomon] in your trash, you may play 1 level 6
   [Argomon] from hand without paying the cost.
5. Inherited `[When Attacking][Once Per Turn]` By suspending 1 [Rhythm],
   unsuspend this Digimon.

## Q&A covered (KB: Q2799, Q2800, Q2808)

- Q2799 (choose Tamers from either player for the suspend cost): behavioural —
  the cost filter is `{ kind: ["Tamer"] }` with no `controller`, so both players'
  Tamers are eligible. Test `Q2799 suspends an opposing Tamer...` digivolves with
  only an opposing Tamer available and confirms it is suspended and the cost drops
  by 1 (memory 8 -> 4). Test `reduces its own digivolution cost...` covers the
  own-Tamer side.
- Q2800 (deleted card counts itself toward the 4+ threshold): behavioural —
  test `with 3 Argomon in trash before deletion...` deletes the on-field Argomon
  (3 pre-existing + itself = 4) and confirms the Lv.6 Argomon (BT17-051) enters
  play from hand.
- Q2808 (Argomon removed from trash before the triggered [On Deletion] activates
  cannot activate): untestable at this layer — the engine does not model the
  trash-membership re-check between trigger and activation. Documented, no test.

## IR change (report to coordinator)

Changed `digivolutionRequirement[0]` from `names: ["Argomon"]` to
`namesExact: ["Argomon"]`. The printed route carries no "in name", so per the
coordinator route decision it must be exact-name (`cardData.ts` nameExact gate,
line 488). Behavioural proof: a base named exactly `Argomon` (BT17-045) takes the
cost-4 route (memory 8 -> 4); a near-name base `Gargomon` (BT17-046, Lv.4
Green/Purple, name contains "argomon") is refused on the alternate route and
falls back to the catalog Lv.4 route at cost 5 (memory 8 -> 3). This doubles as
the required illegal-source / near-name negative.

A true case-sensitive substring near-name (a base named with capital `Argomon`
as a proper substring) does not exist in the catalog, so `names` vs `namesExact`
are otherwise behaviourally identical here; `Gargomon` differs only in case.

Consequence: `packages/shared/src/effects/effects.json` still snapshots
`names: ["Argomon"]`, so `BT17-catalog-sync.test.ts` goes red until the
coordinator regenerates the set snapshot. effects.json not touched (not an
allowed file).

## Remaining gaps

- The single-Rhythm inherited test (`naturally unsuspends...`) proves the host
  ends unsuspended (uniquely the inherited effect's doing, since attacking is the
  only thing that suspended it), but its `rhythm.isSuspended` assertion is
  confounded by Rhythm's own reactive self-suspend. The dedicated once-per-turn
  test avoids that confound by asserting host suspension state and Rhythm-suspend
  counts across two Rhythms, so the confound is no longer material to the axis.
- No engine seams hit; no `it.fails` retained.

## Follow-up note (behavioural axis lift to 2)

Added two behavioural tests at the coordinator's request:

- `inherited unsuspend is once per turn and resets on the next own turn`: through
  the real turn loop (`runOneTurn` / `advance().runTurn`). Attack 1 fires the
  effect (host unsuspended, one of two Rhythms suspended); a second attack the
  same turn leaves the host suspended even though the spare Rhythm is still
  unsuspended (refusal, not cost exhaustion); after a real opponent turn the host
  is readied by the unsuspend phase and a third attack fires the effect again.
  `runOneTurn` runs one turn and stops at End without handing over, so the test
  emulates the production `run()` loop's `passTurn` (flip seat, negate the gauge)
  between turns.
- `Q2799 suspends an opposing Tamer...`: digivolves with only an opposing Tamer
  present and asserts it is suspended for the cost, reducing memory 8 -> 4.
  Reachable — no seam.
