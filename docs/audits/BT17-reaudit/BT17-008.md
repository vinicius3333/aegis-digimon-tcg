# BT17-008 Guilmon — re-audit (lane 29)

## Card summary

Digimon, Lv3, Red, Virus, Reptile. Play cost 3, DP 1000. `evoCosts`: Red Lv2 for 0.
No printed `[Digivolve]` route, so `compiled.digivolutionRequirement` is absent.

Printed clauses:

1. `[Your Turn] [Once Per Turn] When one of your [Calumon] or Tamers with [Takato Matsuki] in their name is played,` — a `whenPlayed` sub-trigger, own turn only, once per turn.
2. `delete 1 of your opponent's Digimon with 3000 DP or less.`
3. `If this effect didn't delete, gain 1 memory.`
4. Inherited: `[All Turns] While you have 0 or less memory, add 2000 to this Digimon's DP-based deletion effects' maximums.`

Catalog strings carry no U+00A0; the test asserts both texts byte-for-byte.

## Defects found and fixed (IR changed)

1. `[Calumon]` is a bracketed name with no "in name", so it is literal card-name
   equality. The module used `match: "name"` (substring). Changed to
   `match: "nameExact"`. No near-name negative is possible from the catalog: the
   only cards whose `nameEn` contains "Calumon" are BT19-077 and EX2-045, both
   named exactly `Calumon`. `Tamers with [Takato Matsuki] in their name` is
   correctly left as substring `match: "name"`.
2. `condition: { kind: "memoryAtMost", value: 0 }` had no `controller`. Without
   it, `interpreter/conditions.ts` (`memoryAtMost`) reads the raw turn-relative
   `state.memory`, which is the OPPONENT's memory on the opponent's turn — wrong
   for an `[All Turns]` inherited effect that says "while YOU have 0 or less
   memory" (Q2712). Changed to `controller: "mine"`, which resolves the gauge
   against `ctx.source.ownerSeat`.

Both are compiled-IR changes, so `BT17-catalog-sync.test.ts` needs the
coordinator's set sync. `effects.json` was not touched.

Test defect fixed: the previous "raises a DP deletion threshold" test used
`BT1-010` (2000 DP) under the alias `fiveKTarget`. 2000 is already inside
Growlmon's printed 4000 maximum, so the test proved nothing about the +2000
bonus. It now uses `BT1-013` (5000 DP, inert), plus a positive-memory negative.
