# BT17-018 Gallantmon: Crimson Mode — re-audit

## Card

Digimon, Lv7, Red, play cost 8, DP 15000, Mega, Virus, type Holy Warrior.
Catalog evo cost: Red Lv6 for 5. `isAce: true`, `overflowMemory: 5`.

Printed clauses:

1. `[Digivolve] Lv.6 w/[Gallantmon] in its name: Cost 4`
2. `[Hand] [Counter] ＜Blast Digivolve＞`
3. `[On Play] [When Digivolving] Choose any number of your opponent's Digimon whose total DP adds up to 15000 or less and delete them.`
4. `[When Attacking] [Once Per Turn] For every 10 cards in both player's trash, trash 1 card from the top of your opponent's security stack.`

No inherited effect.

## Q&A

- **Q2747** (2024-03-28): "for every 10 cards in both players' trashes" is the
  SUM of both trashes, not each separately. Covered by
  `trashes two security cards from a natural attack after counting both players' trashes (Q2747)`
  (10 cards in each trash -> 20 total -> 2 security cards trashed) and re-exercised
  by the once-per-turn test, which also runs at 20 total. The IR encodes this as
  `scaling: { per: 10, unit: "cards", filter: { zone: "trash", controller: "any" } }` —
  `controller: "any"` is the summing form.

## Defects and gaps

- No defects found; no test retained red.
- Observed engine behaviour worth recording: `useAlternateCost: true` is a hint
  the server revalidates. When no printed alternate path accepts the source, the
  engine silently falls back to the catalog route and charges the catalog cost
  rather than refusing the intent. The test asserts the charged cost (5, not 4)
  instead of a refusal, so the reduced route cannot be claimed by an ineligible
  source. The refusal negative uses an off-color Lv.6 base, where both routes are
  illegal.
- The once-per-turn reset uses `advance(...).verb.unsuspend` between real attacks
  (allowed plumbing) and real `runTurn` calls for the turn rotation; no injected
  timing is used anywhere in the file.
- Gap: `isAce` / `overflowMemory: 5` is catalog-driven and is not represented in
  the compiled IR, and no test in this lane exercises the ACE overflow. It is not
  a printed `effectText` clause, so it is out of this card's clause list, but a
  coordinator-level ACE check would be worth having.
- Fixtures use inert main-deck Digimon (BT1-009) and inert Lv6 bodies (BT8-017,
  BT1-080); no Digi-Egg in security or deck and no numeric `security: <n>` form.
