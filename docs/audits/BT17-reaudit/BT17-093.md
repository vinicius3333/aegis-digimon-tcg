## Q&A coverage

- **Q2877** (playing into an empty breeding space without paying the cost is not hatching):
  carried by the IR event name — the SubTrigger listens to `whenHatch`, which the engine raises
  only from the `hatchEgg` intent; no play-into-breeding action raises it. **Residual gap**: no
  behavioural negative. Every printed card that plays a Digimon into the breeding area does so from
  an `[End of Your Turn]` effect, which races this card's own end-of-turn clause and would prove
  nothing cleanly.
- **Q2878** (a copy played by this effect cannot itself use `[End of Your Turn]`): covered
  behaviourally. After a real `runTurn(0)`, the played copy stays in the battle area, is not in the
  deck, and the third deck card is never drawn (no second ＜Draw 1＞).

## Defect found and fixed

`apps/api/src/cards/BT17/BT17-093.ts` modelled "by suspending this Tamer" as a plain `Suspend`
action followed by `GainMemory`, so an already-suspended Tamer still gained 1 memory on every
hatch — an unpayable cost being ignored. Rewritten as a real `cost: { kind: "suspend", ... }` on the
`GainMemory` action (`optional: true`, `abortOnDecline: true`). The engine's suspend cost gate
(`apps/api/src/engine/effects/interpreter/costs.ts:646-659`, `isSuspended === false`) then refuses
it, and the new negative test locks the behaviour in. **This is an IR change**:
`BT17-catalog-sync.test.ts` will be red until the coordinator runs the set sync.
