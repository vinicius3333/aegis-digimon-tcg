# BT17-077 Imperialdramon: Paladin Mode — re-audit

Digimon, Lv7, White/Blue/Green, DP 16000, play cost 9. ACE (overflow 5).

## Printed clauses

1. `[Digivolve]Lv.6 w/[Imperialdramon] in its name: Cost 5` — alternate reduced route.
   "in its name" is substring, so `digivolutionRequirement` uses `names` (not
   `namesExact`). Correct per the coordinator route-name rule; no IR change.
2. `[Hand] [Counter] ＜Blast Digivolve＞` — keyword-only effect, no actions.
3. `[On Play] [When Digivolving]` — trash all opponent digivolution cards; then
   return all cards from your OR your opponent's trash to the deck bottom (modal
   choice); if the return moved a white level 7 card, gain 3 memory.
4. `[When Attacking]` — optional: return 1 opponent Digimon with no digivolution
   cards to the deck bottom to unsuspend this Digimon.
5. `[Rule] Trait: Has the [Free] attribute` — reflected in catalog `types`
   (`["Ancient Holy Warrior", "Free"]`); static, asserted in the catalog test.

## Q&A coverage

- Q4711 (who returns trash): modal `chooseOption`. Behavioral both branches —
  own trash (index 0) and opponent trash (`preferOptionIndex: 1`).
- Q2848 (multicolor white L7 counts): BT12-112 (White/Red, L7) returned → +3.
  Engine `definitionMatches` uses `colors.some`, so a card that merely contains
  White matches `colors: ["White"]`. Behaviorally verified.
- Q2849 (two white L7 return still only +3): two white L7 in trash → memory 7
  (9 − 5 cost + 3), not 10. `GainMemory` is a flat +3, fires once. Verified.
- Q2847 (Digi-Egg in trash → bottom of the Digi-Egg deck): NOT tested.
  Reason: no engine support and a fixture prohibition. The interpreter has no
  egg-deck concept at all — `rg -n "eggDeck|digiEgg|isEgg"` over
  `apps/api/src/engine` returns nothing — so `Return { to: "deckBottom" }`
  (`actions/removal.ts`) routes every card to the main deck. Testing it also
  requires a Digi-Egg in trash, which the fixture rules forbid. Documented as an
  engine seam rather than blessed with a wrong result.
