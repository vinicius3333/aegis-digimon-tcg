## Q&A covered

- **Q2785** — this effect does not let you ignore an Option's colour
  requirements. Covered by "cannot ignore an Option's colour requirements, per
  Q2785": with only Yellow permanents on the board, the black `[Plug-In]` Option
  BT10-105 is not a candidate and stays in hand, and only the digivolve cost is
  paid. The companion test proves the same fixture does use a yellow
  `[Plug-In]` (P-146) at 2 less.

## Defects found

None in the module. Both name references are printed as "in its name", so the
substring forms (`match: "name"` for `[Plug-In]`, `selfHasNameContaining` for
`[Sakuyamon]`) are correct — the set-wide `nameExact` defect does not apply here.
`allowMultiColor: true` is right: the card prints no single-colour restriction.
`playCostLte: 99` is the no-ceiling sentinel; the card prints no cost ceiling,
and a cost-6 yellow Option is proven usable.

Session-3 defect fixed (test flow, not IR): "uses a same-cost yellow Option from
the very fixture that refuses the black `[Plug-In]`" waited for P-146 to reach
the trash. P-146 `Recharge Plug-In Q` prints `[Main] Place this card as 1 of
your non-white Digimon's bottom digivolution card`, so the used card goes to the
digivolution stack and never reaches the trash; the file also never imported
`../P/P-146.js`, so the module registered nothing. The predicate had always been
false: it only started failing once `bfa5aba87 test(testkit): make settle throw
when its predicate never holds` turned a silently-satisfied `settle` into an
error. Fix: import the P-146 module and settle on the card leaving hand, then
assert the real end state (instance in `perm("base").stack`, absent from trash,
memory 2, black `[Plug-In]` still in hand, no pending decision). No engine
regression and no IR defect; the end-state assertions were strengthened, not
weakened.

Test hygiene fixed: two numeric `security: <n>` fixtures replaced with explicit
inert main-deck Digimon (`BT1-012`); an unused `optionId` binding turned into a
real trash-zone assertion; endpoint assertions (memory, hand, trash, stack, no
pending decision) added to the two pre-existing behavioural tests.
