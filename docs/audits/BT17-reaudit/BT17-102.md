## Defects

None found in the module. Two clarifications recorded rather than fixed:

- `useAlternateCost: true` is a *selector*, not an assertion: when the printed route's gate
  fails the engine silently uses the catalog route (`apps/api/src/engine/actions/digivolve.ts`
  around the `intent.useAlternateCost === true` checks). The negative test asserts the
  resulting memory cost rather than a rejection, which is the honest endpoint.
- `[All Turns]` granted names are not visible on a breeding-area permanent (see Q2901 above).
  Engine continuous-scope behaviour; no test retained red, because Q2901's own endpoint (the
  moved Digimon's names) does hold.

No retained `it.fails` / `it.skip`. No injected timing (`advance`, `fireSubTrigger`,
`fireTiming`) anywhere in the file — every behavioural test drives `applyIntent` and settles.
Fixtures use no Digi-Egg in security or deck and no numeric `security: <n>` form.
