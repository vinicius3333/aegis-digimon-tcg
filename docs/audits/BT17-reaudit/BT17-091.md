2. `[Start of Your Turn]` If you have 2 memory or less, set your memory to 3.
3. `[Main] ＜Mind Link＞` (place as bottom digivolution card if no Tamer in
   its digivolution cards) 1 of your Digimon with the [Dark Animal]/[SoC] trait.

   Digimon's digivolution cards without paying the cost.

## Q&A coverage

- **Q2874** (can the inherited End-of-All-Turns effect play *this* card from a
  Digimon's digivolution cards?): covered by "naturally plays itself from the
  host stack at End of All Turns". With the IR fix below this now passes through
  the real name-alias path, not a hardcoded card name.

## Defect fixed locally (IR change)

`effects[5]` targeted `{ tokens: ["Eiji Nagasumi", "Cracker Fang"], match: "name" }`.

- `match: "name"` is substring (`definitionMatchesRef` in
  `apps/api/src/engine/effects/interpreter/matching/definition.ts`), but the
  printed reference `[Eiji Nagasumi]` is an exact-name reference.
- The literal `"Cracker Fang"` token was a workaround for the self-play (Q2874)
  case. It is unnecessary: shared `effectiveStaticNames`
  (`packages/shared/src/cards/effectiveNames.ts`) already parses the
  `[Rule] Name: Also treated as [Eiji Nagasumi]` text and adds "Eiji Nagasumi"
  to Cracker Fang's effective names, which `nameExact` reads.

Changed to `{ tokens: ["Eiji Nagasumi"], match: "nameExact" }`. This is faithful
to the printed exact-name reference, still plays a genuine [Eiji Nagasumi]
(BT14-087 / BT20-089) from the stack, and makes the Q2874 self-play prove the
Rule alias through the real engine path. Test still green.

**This is an IR change.** `BT17-catalog-sync.test.ts` will go red until the
coordinator runs the set sync. `effects.json` not touched. Module still has one
`registerIrCard`, `coverage: "full"`, `residual: []`.

## Remaining gaps

## Catalog / shared observations (not edited; out of scope)

- `effectiveStaticNames` also emits a spurious `"Rule"` alias for any card with
  `[Rule] Name:` text, because its bracket scan runs over the whole matched
  phrase including the leading `[Rule]`. Harmless (no card is named "Rule"), but
  a real shared-parser bug. `packages/shared/src/cards/effectiveNames.ts`,
  `parsedStaticNameAliases`.
- Catalog `BT17-091.traits` is `["-"]` while `types` is `["SoC"]`; the printed
  Mind Link / inherited clauses key off the [Dark Animal]/[SoC] traits of the
  *host*, not this Tamer, so this does not affect behaviour.
