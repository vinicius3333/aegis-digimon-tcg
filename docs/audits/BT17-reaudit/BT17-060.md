for 7 or White Lv6 for 7. No inherited effect. No knowledge-base entries

are no Q&A ids to cover. BT17-060 is not the BT17 banlist entry (that is BT17-069).

1. `When you would play this card from the hand, by placing up to 13 cards with the

## Set-wide `[Name]` defect

Not present. `[Unidentified]` is a printed trait ("with the [Unidentified] trait") and is
compiled as `match: "trait"` — exact, which is correct. `[Diaboromon]` is printed as
"[Diaboromon] in its text" and is compiled as `match: "text"`, which is the substring form
the printed wording asks for. Nothing on this card is compiled as `match: "name"`.

## Evidence notes

- The cost reduction is asserted by the MEMORY DELTA (16 -> 3) and by the three named
  trash instances being absent from trash and present in the deck, not by `{ ok: true }`.
- The budget clause is asserted twice, positively and negatively: at exactly 15 the two
  cheaper permanents go and the 16-cost one stays; at 19 the engine can only take a subset
  and exactly one permanent survives, with the surviving/deleted split checked against the
  catalog play costs.
- The attack test discovered a real fixture trap: the opponent's Armageddemon has
  ＜Blocker＞, so the defending seat's block window must be answered
  (`applyIntent(1, { type: "declineBlock" })`) or the attack never resolves while the
  intent still returns `{ ok: true }`. This is worth adding to the shared trap list.
- `duration: "permanent"` on `GrantCanAttackUnsuspended` is a real `EffectDurationRef`.
- Fixtures use inert main-deck Digimon, no Digi-Egg in security or deck, no numeric
  `security: <n>` form, and keep a spare card in hand.

## Defects, gaps, discrepancies

- No module defect found; `BT17-060.ts` is unchanged, so the compiled IR is unchanged and
  `BT17-catalog-sync.test.ts` is unaffected.
- No retained red tests, no engine seam hit.
- No catalog discrepancy. The catalog carries U+00A0 before "trait" and before "in its
  text"; the test asserts those exact bytes.
- Remaining gaps:
  - The "up to 13" upper bound is only asserted structurally (`count: 13, upTo: true`);
    no fixture seeds 14 eligible trash cards to prove the cap behaviourally.
  - The declined branch of the optional reduction (`optional: true`,
    `abortOnDecline: true`) is untested — no `autoDeclineOptional` run asserts that
    declining pays the full 16 or aborts the play.
  - ＜Reboot＞ is proven only by `hasKeyword`; no test unsuspends it during the opponent's
    turn through the real turn loop.
  - Peer/stack: the [When Digivolving] test is a real evolution-stack case (Lv6 black
    source, cost 7, memory 7 -> 0), and both delete tests are comparative across several
    opponent permanents, but no near-matching peer card is placed alongside the cost
    reduction to prove the trash filter rejects an ineligible card.

## Peer/stack proof (session 3 addition)

`BT17-060.test.ts` adds "counts only the eligible trash cards and leaves an ineligible peer
behind", which puts an ineligible peer in the cost-reduction fixture for the first time:

- BT17-053 Keramon matches by the `[Unidentified]` trait,
- BT17-100 Doomsday Clock matches only by `[Diaboromon]` in its text (it is an Option with
  no Unidentified trait), and
- BT1-009 Monodramon matches neither.

Playing Armageddemon from hand with memory 16 leaves memory 2 — exactly two reductions —
with both eligible cards at the bottom of the deck and Monodramon still the only card in the
trash. This exercises both branches of the `orPrevious` name/trait/text filter and its
negative in one fixture, beside the existing real Lv6 -> Lv7 evolution stack case.
