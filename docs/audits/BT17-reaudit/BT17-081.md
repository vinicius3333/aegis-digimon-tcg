## Q&A coverage (KB, all 2024-03-28)

- Q2855 (gain 2 with both names): COVERED — "both names present" asserts memory
  net 0 change vs a 2-cost play, i.e. +2 gained; tamer suspended.
- Q2857 (suspended Omnimon cannot attack): COVERED — suspended-Omnimon negative,
  and target filter `suspended:false`.
- Q2858 (attack again at EoT after Omnimon attacked and was unsuspended
  mid-turn): COVERED — new test drives a main-phase player-attack (Omnimon
  suspends, opponent security 2->1), `verb.unsuspend` (sanctioned plumbing for
  the Blitz/When-Digivolving self-unsuspend), then the EoT effect fires and
  attacks again (security 1->0).
- Q2856 (played Digimon self-deleted before activation; effect activates but
  gains no memory): NOT TESTED — no fixture Digimon deletes itself on play
  (DP->0). Modeling note: the IR gates activation on `fireCondition =
  anyOf(Greymon, Garurumon)`, so if the only named Digimon left play the
  subtrigger declines rather than "activating for zero gain". Game-state outcome
  matches the ruling (no memory gained); the only divergence is paying the
  optional suspend cost for nothing, which a player would never choose. Not an
  engine defect; documented as a benign modeling difference.
- Q2859 (two copies, two Omnimon: only one attack resolves): NOT TESTED — needs
  two Tamer copies plus the engine's "no new attack declaration during an
  attack" semantics; out of scope for a single-card fixture and not exercisable
  through the public intents here. Documented.
