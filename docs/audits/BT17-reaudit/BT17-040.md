# BT17-040 Kazuchimon re-audit

Lane 44. Digimon, Lv6, Yellow/Green, DP 12000, types Shaman / Abadin Electronics.

## Printed clauses

1. `[Digivolve]Lv.5 w/[Pulsemon]` (U+00A0) `in its text: Cost 3` — alternate reduced-cost route.
2. `[When Digivolving]` Suspend 1 opponent Digimon. Then, if [Leon Alexander] is in this
   Digimon's digivolution cards, all opponent Digimon gain ＜Security Attack -1＞ until end of
   their turn.
3. `[End of Your Turn] [Once Per Turn]` If ≥3 security → 1 opponent Digimon -6000 DP for the
   turn. If ≤3 security → ＜Recovery +1 (Deck)＞. Then, 1 of your Digimon may attack an
   opponent's Digimon.
4. Inherited `[All Turns] [Once Per Turn]` When a card is removed from your security stack, if
   this Digimon has [Fenriloogamon] in its name, 1 opponent Digimon -8000 DP for the turn.

No `[Security]` clause is printed or omitted. Catalog text matches the official list.

## Defect found and fixed (IR change)

The alternate digivolve route (clause 1) was entirely absent from the module: no
`digivolutionRequirement`, no `data.ts` override, no generated override, no `effects.json`
entry. The reduced cost-3 path was therefore unplayable — the player could only ever pay the
catalog cost 4. Sibling cards encode this same kind of route as a module
`digivolutionRequirement` (BT17-007, BT17-015), and `digivolutionRequirementsFor` falls back to
`compiledEffects[id].digivolutionRequirement`.

Fix (in my allowed file `BT17-040.ts`):

```ts
digivolutionRequirement: [
  { level: 5, texts: ["Pulsemon"], cost: 3, isAlternate: true },
],
```

"in its text" is the source's full card-information union (`cardData.ts` `req.texts` gate:
names + types + forms + attributes + every effect field), so `texts` is correct, not `names`.
Verified: BT17-036 Boutmon (Lv5 Yellow/Green, "Pulsemon" in its effectText) is accepted for
cost 3; BT1-057 Sirenmon (Lv5 Yellow, no Pulsemon) is rejected by the alternate gate and falls
back to catalog cost 4.

This is an IR change. `BT17-catalog-sync.test.ts` will go red until the coordinator runs the
BT17 set sync (effects.json carries `null` for this field today). Not touched, per brief.

## Behavioural notes

- Real routes exercised through `applyIntent({type:"digivolve"})` with memory deltas (5→2 alt,
  5→1 catalog/fallback) and the digivolve bonus draw (deck top → hand), plus stack identity.
- Natural turn-loop coverage via `runOneTurn`/`endPhase` for the end-of-turn effect and via a
  real attack for the inherited security-removal trigger.
- The two injected-timing tests (`advance().fire`, `fireSubTrigger`) are structural duplicates
  of natural tests that already exist; kept, but they earn no behavioural credit.
- All fixtures avoid the flagged smells: explicit inert main-deck Digimon in security
  (BT1-009/010/012/013), no numeric `security:<n>`, no Digi-Egg in security. The two
  pre-existing `security: 3` fixtures were converted to three inert cards per coordinator note.
