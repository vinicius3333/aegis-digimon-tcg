# BT17-009 Flamemon — re-audit

## Card summary

Catalog: Digimon, Lv3, Red, play cost 3, DP 1000, form `Hybrid`, type `Wizard`,
evo costs Red Lv2 / Purple Lv2 for 0.

Printed clauses:

1. `[On Play]` Reveal the top 3 cards of your deck.
2. Add 1 card with the `[Hybrid]`/`[Ten Warriors]` trait **and** 1 Tamer card
   with an inherited effect among them to the hand.
3. Return the rest to the bottom of the deck.
4. Inherited `[On Deletion]` You **may** play 1 Tamer card with inherited
   effects from your hand without paying the cost.

No catalog discrepancy. Note that `[Hybrid]` lives in the catalog's `forms`
field rather than `types`; the engine's trait set is
`types ∪ forms ∪ attributes` (`apps/api/src/engine/effects/context.ts:188`,
`detach.ts:73`), so `match: "trait"` correctly matches it — verified
behaviourally with `BT17-023` KendoGarurumon (`forms: ["Hybrid"]`).

## Remaining gaps

None for the printed text. Two notes for the record:

- The order in which the returned cards land at the bottom of the deck is not
  specified by the card ("in any order"), but the engine's order is
  deterministic and is now pinned by two tests; if that ordering ever changes,
  these tests will flag it as an engine-behaviour change rather than a card bug.
- The `[On Play]` trigger is only exercised for a play from hand; a play from a
  digivolution stack or from security would exercise the same `OnPlay` node and
  was not added.
