## Defects fixed locally (module IR — `BT17-050.ts`)

1. **Main placement landed at the top, not the bottom.** Printed "bottom digivolution card". With an existing source under the host, Parasitemon was inserted directly beneath the top card (index 1) instead of the bottom (index 0). Added `position: "bottom"` to the `Main` option[0] `PlaceUnder`. (`targetIsPermanent: true` was tried and reverted — it broke `bindHostAs`, so the host never attacked.)
2. **`[End of Attack]` relocate did nothing.** The `EndOfAttack` `PlaceUnder` lacked `targetIsPermanent`, `shedOwnCards`, and `position: "bottom"` that its twin EX2-028 carries. Without them the relocate never resolved. Added all three; the relocate now places Parasitemon as the bottom card of another Digimon and trashes its own digivolution source, matching EX2-028.

Net module diff: +4 lines. `coverage: "full"`, `residual: []` unchanged and honest. Exactly one `registerIrCard`.

## Retained red (engine seams — `it.fails`, do not weaken)

1. **Q2803 — placement is not an activation gate.** File/function: `interpreter/actions/modal.ts` `canAttemptModalAction` + the `payMemory` cost path. The Lv5+ placement is modeled as `Main` option[0]'s first action, not part of `cost`. `canAttemptModalAction` treats any non-`RawUnparsed` `PlaceUnder` as attemptable, so with no Lv5+ Digimon the modal is still offered, the 4 memory is charged, `PlaceUnder` then finds no host and places nothing. Expected: activation refused, memory untouched, card in hand. Actual: `applyIntent` → `{ok:true}`, memory 4→0, card stuck in hand, nothing placed. Fixing needs the placement to be a cost, which is an engine change — not done.
2. **Q2804 — one optional prompt covers cost+effect.** File/function: `interpreter/actions/runAction.ts` optional gate + `modal.ts availableOptionIndices`. The "you may suspend and attack" bundle should be independently declinable after the card is placed (Q2804 allows place-then-neither). The IR encodes the alternative as `Modal` option[1] = `[]`, but `option.some(...)` on an empty array is false so the empty branch is filtered out and never offered; and the effect's single optional prompt gates the whole cost+effect, so declining also skips the placement. There is no path that places and then declines the suspend/attack. Expected: place + paid, opponent neither suspended nor attacked. Not reachable.
