## Defects fixed locally (IR changed — yes)

**"by suspending this Tamer" was compiled as an ordered action, not a cost.** The IR ran
`{kind:"Suspend", …}` followed by `{kind:"GainMemory", amount:1}`. When Tomonori was already
suspended the Suspend was a silent no-op and the memory was still gained — 1 free memory per
Tamer placement for the rest of the turn. Recompiled as
`CostGatedBlock{cost:{kind:"suspend", …}}` wrapping the `GainMemory`, matching the cost path in
`engine/effects/interpreter/costs.ts:646`, which refuses payment from an already-suspended
permanent. The new negative test failed against the old IR (`expected 1 to be +0`) and passes
against the new one. Mandatory (no "you may"), so no `optional` flag on the block.

## Remaining gaps

- `[Once Per Turn]` on clause 2 is structural only. The trigger fires at most once per
  opponent turn by construction, so a same-turn refusal has no natural second window; proving
  the reset would need two consecutive opponent turns through the real loop, which the turn
  helper does not arrange without injected timing.
- The `[Your Turn]` gate on clause 1 is untested behaviourally: the only available Tamer-placing
  effect in the fixture set (BT17-086 Leon) is an own-turn Main activation, so there is no
  natural opponent-turn placement to attempt.
- The module keeps its existing comment that the public Mind Link activation does not carry the
  optional `byEffect` provenance bit into the `onAddDigivolutionCards` payload, so the "by an
  effect" qualifier is not enforced. Left as-is; a rules-based (digivolve-driven) placement of a
  Tamer card is not otherwise reachable.
