evolution cost `Blue Lv.2: 0`.

Endpoints on the placement runs: hand holds exactly the drawn card, deck holds exactly
the untouched second card, `stack` is exactly `[materialId]`, memory is 2 (play cost 3
from 5 — the placement is a card cost, not a memory cost), and `state.pendingDecision`
is undefined. The no-source and declined runs assert an empty stack, an untouched hand
and deck, and the same memory endpoint, which is what separates "the cost was skipped"
from "the cost was paid and the draw silently lost".

The once-per-turn evidence uses the real turn loop (`engine.startTurnLoop()` plus
`advance(engine).waitForMainPhase(seat)`): attack, memory `+1`; unsuspend (the only
injected plumbing, and explicitly allowed) and attack again in the same turn, memory
unchanged; pass through seat 1's turn back to seat 0; attack again, memory `+1`. Memory
is asserted as deltas because the gauge is stored turn-relative and re-framed on pass.

Evolution is proved through the public `digivolve` intent from both legal locations
(breeding and battle area), using BT13-002 Chapmon, a blue Lv.2 Digi-Egg whose only
clause is an `[Opponent's Turn]` window and so is inert on seat 0's turn. Endpoints:
memory unchanged at 5 (the route costs 0), `stack` is exactly the base card's instance
id so source-stack identity survives, the top card is the Labramon instance, the bonus
draw moved exactly one named card from deck to hand, and `s.decisions` is empty — which
also proves `[On Play]` does not fire on a digivolve. The illegal-source run uses
BT17-004 Argomon, a green Lv.2 egg: the intent is rejected with
`{ ok: false, reason: "invalid-evolution" }` and the base, hand, deck and memory are all
unchanged.

The ＜Jamming＞ source is BT17-024 Seasarmon sitting in the digivolution stack, whose
inherited clause is a bare ＜Jamming＞ grant; the test asserts the keyword is present
(and absent in the negative) with `observe(...).hasKeyword` before attacking.

## Defects fixed locally

- No catalog assertion and no IR equality existed; both were added.
- The `or 1 level 3 blue Digimon card` branch was never exercised — only the named
  Seasarmon route was. The `orFilters` clause was asserted structurally and nothing
  else. It now has its own behavioural run plus a candidate-set boundary test.
- Nothing proved the cost gates the draw: there was no "no legal source" run and no
  declined run, so `abortOnDecline` was unproven.
- `[Once Per Turn]` was asserted only as an IR string. There was no same-turn refusal
  and no reset through the turn loop.
- The `[When Attacking]` condition had no negative: a host without ＜Jamming＞ was
  never attacked with.
- The old inherited fixture used the numeric `security: 2` form, one of the smells
  named in the brief. All fixtures now list explicit inert main-deck Digimon.
- The evolution route was entirely untested: no legal digivolve, no cost proof, no
  source-stack identity, no bonus draw and no illegal-source negative. All added.
- The turn-loop run needed a spare playable card in hand for each seat; without it
  Main auto-passes as soon as the attacker suspends, which silently ended the turn
  and made the memory assertion read the re-framed gauge. Documented in a comment.
