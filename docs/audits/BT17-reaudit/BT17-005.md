## Clause -> test -> IR mapping

| Clause | IR | Test |
| --- | --- | --- |
| Catalog identity, no main effect | `compiled.effects` has exactly one entry | "matches every catalog field and carries its only printed clause in IR" |
| `[On Deletion]`, inherited | `trigger: "OnDeletion"`, `isInherited: true` | "gains 1 memory when its [Unidentified] host loses a real battle" |
| `If this Digimon had the [Unidentified] trait` | `condition: { kind: "selfHasTrait", nameOrTrait: [{ tokens: ["Unidentified"], match: "trait" }] }` | "does not gain memory when the deleted host lacks the [Unidentified] trait" (BT17-052 Agumon, Reptile/SoC) |
| `gain 1 memory` | `GainMemory { amount: 1 }` | positive test asserts `state.memory` 0 -> 1 |

Deletion is real, not injected. The host attacks a suspended 5000 DP opposing Digimon
and loses the battle, so `OnDeletion` fires from production combat resolution. Endpoints
asserted after the attack settles: the host permanent is gone from the battle area, both
`BT17-053` and `BT17-005` are in the trash, memory is exactly 1, and
`state.pendingDecision` is undefined. A third test attacks with the same
[Unidentified] host at 20000 DP: it survives, and memory stays 0 — the trigger is tied
to deletion, not to the trait alone.

The [Unidentified] host is BT17-053 Keramon, whose own printed clause only watches the
opponent playing a level 5 or higher Digimon, so it contributes nothing here.

## Peer/stack proof (added)

`carries the inherited memory gain through the real Digi-Egg route beside a non-[Unidentified] peer stack`
walks the whole Digi-Egg lifecycle with public intents only, under the production turn loop:
`hatchEgg` -> `digivolve` the Black Lv.3 [Unidentified] BT17-053 onto the egg inside the breeding
area (Lv.2 Black, cost 0, egg asserted as the stack) -> `moveFromBreeding` on the next own turn.

The comparative case stands beside it: BT17-052 Agumon carrying the same BT17-005 Digi-Egg — same
colour, same egg, [Reptile]/[SoC] instead of [Unidentified]. Both attack the same 5000 DP wall in
the same turn and both die; the peer's deletion leaves memory at 3 and the routed [Unidentified]
carrier's deletion takes it to 4, with the hatched egg instance asserted in the trash.

## Defects fixed locally

- The previous suite deleted the host with `advance(engine).verb.deletePermanent`, an
  injected verb. Under the re-audit standard that is structural plumbing, not
  behavioural proof; deletion now comes from a lost battle declared through the public
  `attack` intent.
- The previous positive fixture stacked `["BT17-005", "BT17-052", "BT17-054", "BT17-055"]`
  under a Lv.6 Diaboromon for no stated reason, mixing in three unrelated inherited
  effects. The fixture is now the minimum that proves the clause.
- No catalog assertion and no IR equality existed. Both were added; the
  `inheritedEffectText` assertion had to carry the catalog's U+00A0.
- No "survives" control existed, so nothing distinguished the trait condition from the
  deletion trigger.
