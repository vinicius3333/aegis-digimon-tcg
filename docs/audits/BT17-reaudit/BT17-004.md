Behavioural proof is a real block, not just a keyword read: seat 1 declares a player
attack, `blockWindowOpened` is observed, seat 0 answers with the public `declareBlock`

still `["BT1-009", "BT1-013"]` in order, the 20000 DP blocker survives, the 5000 DP
attacker is gone from the battle area, and `state.pendingDecision` is undefined. The
negative run uses the same board with a Terriermon host: `declareBlock` is rejected
(`ok: false`) and the attack goes through to security, leaving `["BT1-013"]`.

## Peer/stack proof (added)

`carries ＜Blocker＞ through the real Digi-Egg route beside a non-[Argomon] peer stack`
walks the whole Digi-Egg lifecycle with public intents only, under the production turn loop:
`hatchEgg` -> `digivolve` the Green Lv.3 [Argomon] BT17-042 onto the egg inside the breeding area
(egg asserted as the stack) -> `moveFromBreeding` on the next own turn.

The comparative case stands beside it for the whole test: a BT17-043 Terriermon carrying the same
BT17-004 Digi-Egg — same colour, same egg, wrong name. On the controller's own turn neither has
＜Blocker＞; on the opponent's turn only the routed [Argomon] carrier gains it. The name boundary is
therefore proven with both stacks live on the same board, not only across separate fixtures.

## Defects fixed locally

- The previous suite had no catalog assertion and no IR equality: it only used
  `toMatchObject` on the first effect, so a wrong `Aura` target or a missing
  `isInherited` would have passed. Now `compiled.effects` is asserted with `toEqual`
  and every catalog field is pinned.
- The previous suite proved Blocker only through `observe(...).hasKeyword`, a
  ledger read. A granted keyword that the combat system never consults would have
  scored the same. The block is now exercised end to end through public intents.
- The previous "only on the opponent's turn" test never asserted the grant
  disappearing again when the turn returns to the controller.
