# BT17-030 Pulsemon — re-audit

## Card summary

Digimon, Lv3, Yellow/Green, play 3, DP 2000, types Beastkin / Abadin Electronics.

Printed clauses:

1. `[Digivolve][Bibimon]: Cost 0` — alternate route off an exactly-named Bibimon base.
2. `[Start of Your Main Phase] By placing 1 [Leon Alexander] from your hand as this
   Digimon's bottom digivolution card, if you have 3 or more security cards, gain 1 memory.`
3. Same clause, low-security half: `If you have 2 or fewer security cards,
   ＜Recovery +1 (Deck)＞.`
4. Inherited `[All Turns]` — while this Digimon has `[Pulsemon]` in its text, it gets +1000 DP.

  "by placing" action — skipping the cost aborts the rest of the effect): covered
  behaviourally, twice — once by declining the prompt, once by having no legal card to place.

## Defect fixed

`[Leon Alexander]` is a printed exact-name reference but both placement costs compiled it
as `match: "name"` (substring). Changed to `match: "nameExact"` in
`apps/api/src/cards/BT17/BT17-030.ts` (both `effects[0]` and `effects[1]` cost filters).
This is the set-wide defect the coordinator flagged.

**The compiled IR changed, so `BT17-catalog-sync.test.ts` will be red until the coordinator
runs the set sync.** `effects.json` was not touched.

## Test-quality repairs

- The two behavioural tests used injected timing (`advance(...).fire(EffectTiming.OnStartMainPhase, ...)`),
  which earns no behavioural credit. Both now run the real turn flow:
  `s.engine.runOneTurn()` + `advance(s.engine).waitForMainPhase(0)` + `endMainPhaseIfOpen(0)`,
  so memory can still be read inside the open main phase.
- The numeric `security: <n>` fixture form was replaced with explicit inert main-deck
  Digimon (BT1-009 / BT1-012 / BT1-013 / BT1-014). No Digi-Egg in security or deck.
- Added the three evolution-route tests and the two Q2777 negatives.

## Remaining gaps

- `digivolutionRequirement` uses substring `names: ["Bibimon"]` rather than `namesExact`.
  Same set-wide question as BT17-025; left for the coordinator because the accepted
  exemplar BT17-007 uses `names` for its printed `[Koromon]` route.
- `effects[1]`'s placement cost has no `raw` string while `effects[0]`'s does. Cosmetic,
  not changed to keep the IR diff minimal.
- The negative for the exact-name gate uses "no matching card in hand" rather than a Tamer
  whose name merely contains "Leon Alexander" — no such printed card exists to contrast with.
