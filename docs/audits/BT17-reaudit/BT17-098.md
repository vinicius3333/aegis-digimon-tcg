## Engine seam closed

`it("refuses the Delay when the only [Pulsemon]-text host has no digivolution
cards")` — flipped from `it.fails` to `it` by the engine lane (E1); the
assertion is unchanged.

- File/function: `apps/api/src/engine/effects/interpreter/costs.ts`, `payCost`,
  the routed place-as-cost branch (`cost.destination !== undefined` with
  `cost.targetIsPermanent === true`).
- Was: candidates came from `resolvePermanentTargets(ctx, cost.target)` with no
  requirement that `permanent.stack.length > 0` when
  `cost.detachPermanentTop === true`, so a bare permanent's only card went to
  the security stack and the permanent left the battle area.
- Now: the source target is constrained with `hasDigivolutionCards: true`
  whenever `detachPermanentTop` is set, so the bare host is never offered, the
  cost is unpayable, memory stays 0 and the permanent stays on board (Q2892).
- Red-then-green: `Tests 8 passed | 1 expected fail (9)` before, then
  `Error: Expect test to fail` on the same `it.fails`, then `Tests 9 passed (9)`
  after the flip. Full write-up:
  `docs/audits/BT17-reaudit/DETACH-PERMANENT-TOP-COST-MECHANISM.md`.
