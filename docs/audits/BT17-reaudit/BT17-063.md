## Defect found and fixed

The compiled IR used `match: "name"` (substring) for the printed exact
references `[HippoGryphonmon]` and `[Murmukusmon]` — the known set-wide defect.
Both are now `match: "nameExact"`.

No card currently in the catalog carries either token as a proper substring, so
unlike BT17-062 this was latent rather than an active mis-behaviour; it is still
wrong against the printed text and is now corrected.

IR changed: **yes** — `BT17-catalog-sync.test.ts` will be red until the
coordinator runs the set sync. `effects.json` was not touched.
