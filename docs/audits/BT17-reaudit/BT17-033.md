## Defects found and fixed locally

1. **The main printed clause had no behavioural test at all.** The previous suite only
   asserted the IR shape for it. Three behavioural tests now cover the buff, the cost
   colour negative and the decline branch.
2. **The "inherited" test did not exercise this card's inherited effect.** It laid
   `{ card: "BT17-033", under: ["BT17-031"] }`, i.e. BT17-033 as the **top** card with
   BT17-031 underneath — so the only inherited effect in play was BT17-031's, and the
   assertion (a 7000 DP attacker beating a 5000 DP security Digimon) held with or
   without any DP reduction. The test proved nothing. It now puts BT17-033 **under** an
   inert host, asserts `securityDp(1) === -3000` directly, and picks DP values where
   the reduction decides the security battle.
3. No `[Your Turn]` negative existed for the inherited clause. Added.
4. IR assertions upgraded from `toMatchObject` fragments to a full `toEqual`, plus a
   catalog contract assertion.

## Remaining gaps

- The expiry test reads the battle-time 8000 DP through the `onEvent` hook rather than
  from post-attack state, because paying no memory still hands the turn over when the
  attack resolves at 0 memory. `onEvent` is the harness's documented seam for values
  that exist only during a battle, and the post-turn 5000 is asserted from state.
- Attacking a Digimon (rather than the player) with the buff up is not covered
  separately; the DP value itself is the same modifier and is asserted directly.
