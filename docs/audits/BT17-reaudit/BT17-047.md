## Defects and gaps

- No defect found in `BT17-047.ts`. The IR was not modified, so
  `BT17-catalog-sync.test.ts` is unaffected.
- Fixture smells removed/avoided: no Digi-Egg in security or deck, no numeric
  `security: <n>` form, no injected timing except one documented
  `advance(...).verb.suspend` used purely to re-suspend an attack target after
  the opponent's turn-start unsuspend (a Digimon can only be attacked while
  suspended). The battle/deletion/unsuspend chain itself is fully real.
- The previous file's only behavioural evidence for the inherited clause used
  `BT17-048` as host, whose own inherited `[When Attacking] ... unsuspend this
  Digimon` competes with the clause under test. The new once-per-turn test uses
  the inert `BT1-013` as host so the observed unsuspend can only come from
  BT17-047.
- Remaining gap: the `[Security]` clause is only exercised through the security
  check of an opponent attack; no test covers it being reached from a card that
  moves a security card to a battle instead. No known BT17 line does that.
