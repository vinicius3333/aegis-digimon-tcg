## Clause -> test -> IR mapping

| Clause | IR | Test |
| --- | --- | --- |
| "When one of your [Kosuke Kisakata] is played" | `AllTurns` -> `SubTrigger` `whenPlayed` with `sourceFilter.controller: "mine"` | "gains memory and draws when Kosuke Kisakata is played, only once in the turn" |
| "your" (controller scope) | `controller: "mine"` | "does not trigger on the opponent's own Kosuke Kisakata" |
| `[Kosuke Kisakata]` exact name | `match: "nameExact"` | IR-shape test |
| "gain 1 memory and ＜Draw 1＞" | `GainMemory 1` + `Draw mine 1` | main behavioural test (memory 9 -> 6: cost 4 paid, 1 gained; one card leaves the deck) |
| [Once Per Turn] same-turn refusal | `frequency: "OncePerTurn"` | main behavioural test (second play: memory 6 -> 2, deck unchanged) |
| [Once Per Turn] next-own-turn reset | same | "resets the once-per-turn draw on the next own turn through the public turn flow" |
| [All Turns] | trigger `AllTurns` | the opponent-turn negative runs with `turnSeat = 1` |
| Inherited ＜Reboot＞ | `Static` `isInherited` keyword `Reboot` | "grants inherited Reboot to an evolved host" |

The reset test runs the real turn loop: `startTurnLoop`, `waitForMainPhase(0)`,
play, `endPhase`, `waitForMainPhase(1)`, `endPhase`, `waitForMainPhase(0)`, play
again, then `surrender` to close the loop. No injected timing is used anywhere in
this file.

Deck length is the reset assertion rather than memory because BT16-087 carries
`[Start of Your Turn] If you have 2 or less memory, set it to 3`, which perturbs
the memory gauge across a turn boundary.

## Defect found and fixed

`sourceFilter.nameOrTrait` used `match: "name"` (substring). A printed
`[Kosuke Kisakata]` is an exact name (§2-3-1-2). Changed to `match: "nameExact"`.
No other catalog card contains "Kosuke Kisakata" as a substring, so this is
correctness-only today.

## Peer/stack proof (session 3 addition)

`BT17-052.test.ts` adds "ignores a near-miss Tamer peer and fires only for the exact
[Kosuke Kisakata]": BT26-096 "Kosuke Misono" and BT16-087 "Kosuke Kisakata" are played from
the same hand in the same turn. Misono pays its cost 3 (memory 9 -> 6) with no memory gain
and no draw; Kisakata then pays cost 4, gains 1 memory (-> 3) and draws exactly one card.

Honest caveat on the `nameExact` fix: no card in the catalog has "Kosuke Kisakata" as a
proper substring of a longer name, so `nameExact` and the substring `name` mode cannot be
told apart behaviourally for this card. The peer above is the closest available near-miss
(shared given name), and the exactness of the fix rests on the printed-bracket convention,
not on a discriminating fixture.

Combined with the existing inherited-＜Reboot＞ stack assertion on a BT17-054 host, this
earns the peer/stack column.
