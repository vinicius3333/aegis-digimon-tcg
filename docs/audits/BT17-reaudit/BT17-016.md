# BT17-016 Gallantmon — re-audit

## Card summary

Digimon, Lv6, Red, Virus, Holy Warrior / Royal Knight, DP 11000, play cost 11, digivolve Red Lv5 cost 3. No inherited effect.

Printed clauses:

1. `[When Digivolving] [When Attacking] Delete 1 of your opponent's Digimon with 8000 DP or less.`
2. `If this effect didn't delete, this Digimon gets +3000 DP and gains ＜Blocker＞ until the end of your opponent's turn.`
3. `[Your Turn] While you have 0 or less memory, this Digimon isn't affected by your opponent's effects.`

## Evolution proof

`digivolves from a Lv5 Red source for its printed cost, with the source stack and bonus draw` uses the public `digivolve` intent from a BT17-013 base carrying BT1-015 underneath: memory drops by exactly 3 (3 → 0), `Permanent.stack` is exactly `["BT1-015", "BT17-013"]` (cards beneath the top card), and the digivolution draw puts the named deck card into hand at unchanged hand size. `refuses an illegal Lv3 digivolution source` proves the negative: the intent is refused, the base keeps its top card and memory is untouched.

## Duration proof

`keeps the DP and Blocker grants through the opponent's turn` grants the pair on a real attack, runs the rest of the controller's turn and the whole opponent turn through `advance().runTurn`, and asserts the grants are still live during the opponent's turn and gone after it (DP back to 11000, no ＜Blocker＞). That confirms `untilOpponentTurnEnd` is a real `EffectDurationRef` and not a silently expiring string.

## Immunity proof

`ignores an opponent security effect at 0 memory but not at 1 memory` builds the same board twice and drives a real attack whose security check flips ST22-08 Offensive Plug-In V (`[Security] Delete 1 of your opponent's Digimon with the lowest DP`). At memory 0 Gallantmon survives; at memory 1 the identical flow deletes it. No injected timing is used anywhere in the file.
