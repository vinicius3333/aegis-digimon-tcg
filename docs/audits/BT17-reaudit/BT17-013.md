# BT17-013 WarGrowlmon — re-audit

## Card summary

Digimon, Lv5, Red, Virus, Cyborg, DP 7000, play cost 7, digivolve Red Lv4 cost 3.

Printed clauses:

1. `[When Digivolving] Delete 1 of your opponent's Digimon with 6000 DP or less.`
2. `If this effect didn't delete, this Digimon gains ＜Security Attack +1＞ for the turn.`
3. Inherited: `[All Turns] [Once Per Turn] When an effect deletes an opponent's Digimon, you may unsuspend this Digimon with [Gallantmon] in its name.`

All behavioural cases drive `s.engine.applyIntent(0, { type: "digivolve", ... })` and settle before asserting. No injected timing (`fire`, `fireSubTrigger`, `fireTiming`) is used. `advance().verb.suspend` re-suspends the host between the two real deletions, and `advance().verb.deletePermanent(..., "byEffect")` supplies the third deletion after the turn loop — both are production primitives, used as plumbing only.

## Once per turn

`unsuspends only once per turn and resets on your next turn` performs two real WarGrowlmon digivolutions in the same turn against two separate bases. The first deletion unsuspends the Gallantmon host; the host is re-suspended and the second effect deletion leaves it suspended (intermediate state asserted between the two). Two real turns then run through `advance().runTurn(0)` / `runTurn(1)`, after which a third effect deletion unsuspends it again.
