## Added this run

- `takes a blue level-5 base only when its text carries [Dark Masters]` — a comparative pair on a
  BLUE level-5 base, which the Purple catalog route can never accept, so only the printed alternate
  can carry it. BT15-027 Scorpiomon (text names [Dark Masters]) is accepted at cost 3; BT1-038
  Monzaemon (blue level 5, no printed text at all) is refused with hand and memory untouched. This
  is the missing illegal-source negative and the peer comparison.
- `stays suspended when the opponent's trash holds fewer than seven cards` — six cards in the
  opponent's trash: the cost cannot be paid, nothing is returned, the deck stays empty and Gulfmon
  stays suspended.
- Removed an unused `advance` import flagged by oxlint.
