## Defect found and fixed

`nameOrTrait` used `match: "name"` (substring;
`apps/api/src/engine/effects/interpreter/matching/definition.ts:353`). A printed
`[Terriermon]` is an exact name (§2-3-1-2). This one is observable: the catalog
holds "Terriermon (X Antibody)" (BT16-038) and "Terriermon Assistant"
(BT5-046, EX4-033), which the substring form wrongly accepted as play targets.
Changed to `match: "nameExact"`.

Mutation check: reverting the module to `match: "name"` turns the near-name test
and the IR-shape test red, so the new test has teeth.
