## Defects found and fixed locally

1. The old draw test used the numeric `security: 1` fixture form (a flagged smell) and
   only asserted `tamer.isSuspended`; the draw itself was proved solely by the settle
   predicate and hand size was never checked. It now uses an explicit inert main-deck
   Digimon in security and asserts hand and deck contents by instance id.
2. There was no negative for the Tamer colour and no decline branch. Both added.
3. The inherited test asserted `securityDp(1)` but had no `[Your Turn]` negative;
   added.
4. IR assertions upgraded from `toMatchObject` fragments to a full `toEqual`, plus a
   catalog contract assertion.
