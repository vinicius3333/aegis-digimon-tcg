## Defect found and fixed

`nameOrTrait` used `match: "name"`, which is a SUBSTRING match
(`apps/api/src/engine/effects/interpreter/matching/definition.ts:353`). A printed
`[Rhythm]` reference is an EXACT name (comprehensive §2-3-1-2). Changed both the
target filter and the `youHaveNone` condition filter to `match: "nameExact"`.

No card other than "Rhythm" currently contains "Rhythm" in its name, so this is
correctness-only for this card today; the same defect is observable on BT17-046.
