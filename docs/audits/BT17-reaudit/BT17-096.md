## IR change (defect fixed)

`effects[0].actions[0].target.filter.nameOrTrait[0].match` was `"name"`
(substring, `apps/api/src/engine/effects/interpreter/matching/definition.ts:353`).
The printed text is bracketed `[Guilmon]/[Takato Matsuki]`, which is an exact
name, so it is now `"nameExact"` (`definition.ts:355`). Without the fix
BT9-009 "Guilmon (X Antibody)" would have been a legal free play.

Consequence: `BT17-catalog-sync.test.ts` will be red until the coordinator runs
the BT17 set sync. `effects.json` was not touched.
