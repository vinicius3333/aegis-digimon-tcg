## Implementation and clause mapping

Main draws one, trashes one hand card, and then places itself. The Your Turn deletion watcher requires an effect-caused Digimon deletion and grants a separate permanent Delay keyword; the optional free digivolution payload restricts both host and trash destination to the printed Guilmon/Growlmon and Growlmon/Gallantmon/Megidramon name families. Security gains one memory and places itself. Coverage is full and residual is empty.
