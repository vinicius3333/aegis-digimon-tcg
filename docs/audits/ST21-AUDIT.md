## Verification commands

- Per-card catalog contract and KB evidence: `node tools/kb/query.mjs card <CARD-ID> --json` (executed for every ST21 card; applicable `data/kb/rules/comprehensive.md`, `manual.md`, `glossary.md`, Q&A, errata, and restrictions reviewed).
- Per-card focused proof, serial and ascending: `pnpm --filter @aegis/api exec vitest run --pool=threads --poolOptions.threads.singleThread=true src/cards/ST21/<CARD-ID>.test.ts` — 15/15 passed.
- Collection gate: `pnpm --filter @aegis/api exec vitest run --pool=threads --poolOptions.threads.singleThread=true src/cards/ST21/collection.audit.test.ts` — collection inventory/import/registration/IR gate passed.
- Affected engine mechanism regressions: `pnpm --filter @aegis/api exec vitest run --pool=threads --poolOptions.threads.singleThread=true src/engine/<affected-suite>.test.ts`.
- Workspace typecheck: `pnpm typecheck`.
- Repository lint/format: prescribed `meteor npm run quave-check-ci` where available; native `pnpm lint` and changed-file Oxfmt used when the prescribed script/runtime is unavailable.
- Diff validation: `git diff --check`.

## Collection invariants

Every ST21 catalog card has a direct module, colocated focused test, index import, exclusive `registerIrCard("ST21-NN", compiled)` registration, `coverage: "full"`, and `residual: []`; no legacy `registerCard` registration or RawUnparsed runtime clause remains. Applicable Q&A, errata, restrictions, trait-peer, targeting, optionality, and evolution-stack boundaries were reviewed; no unresolved ambiguity remains.
