# EX11-062 Shoto Kazama audit

## Contract and implementation

The catalog defines a green cost-4 LIBERATOR Tamer. At the start of the owner's turn, memory 2 or less becomes 3. All Turns, when any Digimon suspends, by suspending this Tamer, if effects suspended those Digimon, draw 1; after, one own Digimon with Avian or Bird in any trait or Vortex Warriors gains +3000 DP until the opponent's turn ends. During the owner's turn, while the opponent has no unsuspended Digimon, the controller's Vortex can also attack players. Security plays this card without cost.

The module is exclusive `registerIrCard`, full coverage, and encodes the mandatory suspension cost, effect-versus-rule draw gate, universal +3000 DP follow-up (Q6517), trait boundaries, Vortex player-attack permission, and Security play.
