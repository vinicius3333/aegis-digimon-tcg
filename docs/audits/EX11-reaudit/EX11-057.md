# EX11-057 Suzune Kazuki audit

## Contract and implementation

The catalog defines a blue/yellow cost-4 LIBERATOR Tamer. At the start of the owner's main phase, if the opponent has a Digimon, it gains 1 memory. On Play, for each own Ice-Snow Digimon, it trashes any one digivolution card from an opposing Digimon. All Turns, when an effect trashes digivolution cards from an opposing Digimon, by suspending this Tamer it gains 1 memory. Its Security effect plays this card without paying the cost.

The module is exclusive `registerIrCard`, full coverage, and encodes opponent-presence memory, pooled Ice-Snow scaling, cross-Digimon trashing, the paid suspension watcher, and Security play.
