# EX11-030 ForgeBeemon audit

## Contract and IR

The catalog defines green/black level-4 ForgeBeemon with normal level-3 green or black evolution cost 3 and alternate level-3 Royal Base cost 2. It has Insectoid metadata, a Security/Opponent's Turn effect granting Reboot to all own Royal Base Digimon, On Play/When Digivolving taking the top face-down security card to hand and then optionally placing an exact Royal Base Digimon from hand face-up at the bottom security, and an inherited all-turns +1000 DP effect.

The module is full IR and registers exclusively with `registerIrCard`. The alternate route, resident face-up security trigger, top face-down-only manipulation, optional Royal Base face-up bottom placement, exact Royal Base target, and inherited permanent DP modifier are all encoded. No IR defect was established.

| Clause | Behavioral proof | IR mapping |
|---|---|---|
| Catalog/metadata | Catalog test asserts Insectoid, colors, costs, and level | metadata and evolution data |
| Public On Play security sequence | ForgeBeemon is played from hand publicly; top face-down security is added to hand while a pre-existing face-up top card is skipped, then Royal Base is placed face-up at security bottom | `toHand amount 1 toTop faceDownOnly`, then optional `placeAsSecurity faceUp toTop:false` |
| Royal Base boundary | Royal Base is placed; plain BT1-009 remains in hand and is not eligible | exact `match: trait` Royal Base filter |
| Resident Security effect | Face-up ForgeBeemon in security during opponent turn grants Reboot only to own Royal Base, not plain or opponent Royal Base | Security + OpponentsTurn, controller mine, exact Royal Base |
| Inherited stack | ForgeBeemon under level-5 host gives permanent +1000 DP | inherited AllTurns ModifyDP |
| Evolution | Public EX11-025 Royal Base evolution spends exactly 2 memory and preserves the source stack | alternate level-3 Royal Base cost 2 |
| Face-up security check | A public attack checks face-up ForgeBeemon; its resident Reboot is live beforehand, then the checked card moves to trash and the grant disappears | Security/Opponent's Turn resident effect |

Fixtures contain no Digi-Egg in deck or security. The public play flow now carries behavioral proof for the security sequence; face-up security behavior is observed through a legal resident security fixture.
