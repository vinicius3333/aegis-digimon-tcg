## Follow-up seam investigation

The original case had two fixture problems. It omitted the public `chooseOption` decision, so
EX11-034's When Attacking effect stopped at its legal top/bottom security choice. It also used a
low-cost target, so EX11-034's own 8-cost DeleteBudget trashed the target before battle and never
published `whenDeletesInBattle`. The corrected fixture enables `autoChooseOption` and attacks a
12-cost EX11-034 target with a 13,000-DP EX11-034/EX11-033 host; the target therefore survives the
printed deletion effect, loses the real battle, and enters trash. The inherited watcher then
unsuspends the host.

The production trace confirms the public payload and identity path: `resolveDigimonBattle` emits
`subjectPermanentId`/`attackerPermanentId` for the surviving host, `buildSubTriggerSourceContext`
rebinds the inherited EX11-033 source instance to `sourcePermanentId` on that host, and
`armedSubTriggers` matches the existing `whenDeletesInBattle` self gate. No engine correction is
indicated; changing subscription matching would be an unnecessary card-specific workaround.

Q5850 is separate from this battle continuation. It concerns rule-check ordering when a linked
Maquinamon play leaves its host at 0 DP before the play's On Play effect can restore it. The
existing cross-card probe uses direct timing injection and therefore is useful diagnostic evidence
only; it is not public behavioral credit for EX11-033. The rule-check result remains separately
documented, with no new synthetic probe added here.
