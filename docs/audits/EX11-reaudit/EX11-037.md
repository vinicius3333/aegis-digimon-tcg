# EX11-037 — Espimon

Espimon is a level 3 Black/Blue Cyborg/LIBERATOR Digimon. Its printed clauses are:

- alternate digivolution over an exact `[Kapurimon]` for cost 0;
- `[When Moving]` and `[On Play]`: flip the opponent's top face-down security card face up, then draw 1 and gain 1 memory only if this effect did not flip a card;
- inherited `＜Jamming＞`.

## Q&A and boundaries

Q5861 is covered by the public flip assertions: the card remains in security and its `faceUp` state becomes true. Q5862 (checking a face-up security card), Q5863 (Security effects on that check), and Q5864 (shuffling revealed security) concern general security-rule flows after this card's effect. They have no additional Espimon-specific branch; the focused card harness does not expose a deterministic public security-check/shuffle fixture suitable for isolating those generic rules, so they remain documented as untested seams rather than synthetic timing proof.

The public evolution stack uses a real Kapurimon source and a main-deck Espimon. No Digi-Egg is placed in deck or security. The security cases use inert main-deck Digimon. The two-card security fixture proves top-card selection and prevents an implementation that flips an arbitrary or all face-down cards from passing. No Mineral/Rock filter is printed by this card, so no such filter was invented.
