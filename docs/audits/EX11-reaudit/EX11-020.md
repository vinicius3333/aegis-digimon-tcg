# EX11-020 Hanimon re-audit

The catalog identifies EX11-020 as the Yellow/Purple level 3 Hanimon with the
Puppet and LIBERATOR traits. Printed behavior is alternate Kyaromon cost 0;
On Deletion, if deleted other than in battle, optionally play one Shoemon from
hand without paying; and inherited Opponent's Turn, once per turn, when an
opponent Digimon attacks, optionally delete one of your other Digimon to end
that attack.

The card query returned Q5803-Q5805. Q5803 is covered by the protected-fodder
test: a deletion restriction prevents payment, so the attack continues. Q5804
is covered by the attack ending before security/counter/block windows. Q5805 is
covered by the unaffected Progress attacker, whose attack still ends. The
rules query returned the general attack timing and deletion behavior.

## Clause -> test -> IR

| Printed clause | Behavioural evidence | IR |
|---|---|---|
| Kyaromon cost-0 route and normal Yellow/Purple routes | Public evolution test verifies Kyaromon cost 0, Yellow/Purple level-2 cost 1, and invalid red BT1-009 rejection. | `namesExact: ["Kyaromon"]`, cost 0 alternate; catalog normal requirements. |
| On Deletion only outside battle | Public effect deletion plays Shoemon; public battle deletion leaves Shoemon in hand and no optional prompt. | `not(triggerRemovalCause byBattle)`. |
| Optional Shoemon play without cost | Acceptance removes Shoemon from hand and places it in battle; decline leaves Hanimon deleted and Shoemon in hand. | Optional `PlayWithoutCost`, exact Shoemon name, `payCost: false`. |
| Inherited Opponent's Turn once-per-turn attack ending | A real public turn loop over the inherited stack ends the first opponent attack after deleting fodder, leaves the same-turn second attack running to security without another deletion, and reuses the effect after the next own turn. | `OpponentsTurn`, `frequency: "OncePerTurn"`, `whenOpponentAttacks`, `deleteOwn` cost and `EndAttack`. |
| Q5803 payment failure | Protected fodder cannot be deleted, so the cost is unpaid and the attack reaches security instead of ending. | Cost-gated `deleteOwn`; EndAttack is processed only after payment. |
| Q5804 timing and Q5805 unaffected attacker | Assertions inspect attack state, security length, and absence of block/counter windows; BT21-025 unaffected attacker is still ended. | `EndAttack` timing action; no attacker effect targeting required. |

The stack tests use legal main-deck Digimon and exact source/target IDs. The
only restriction seam is the Q5803 fixture's continuous deletion restriction,
which models another effect preventing payment; no trigger/timing injection is
used. The former BT1-001 battle-area invalid egg fixture is replaced with
main-deck BT1-009.

## Changes

The card module already had faithful IR and exclusive `registerIrCard`; no IR
change was required. The test file only replaces the Digi-Egg battle-area
fixture. Existing tests cover all printed clauses, all three Q&As, optionality,
turn ownership, once-per-turn behavior, exact Shoemon targeting, source zones,
and invalid evolution.

removing optionality fails the decline tests. Removing `EndAttack` fails Q5804,
Q5805, and the security-window assertions. Removing the once-per-turn marker
fails the second-attack case. Changing exact Shoemon targeting or Kyaromon's
alternate cost fails the zone and evolution assertions.
