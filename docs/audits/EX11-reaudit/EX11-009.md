# EX11-009 Tyrannomon audit

## Contract and catalog discrepancy

The catalog prints: `[Digivolve] Lv.3 w/[Reptile] trait: Cost 2 [When Digivolving] If you have 1 or fewer Tamers, you may play 1 [Ryutaro Williams] from your hand without paying the cost.` The inherited text is `[All Turns] This Digimon get +1000 DP.` The official wording uses “gets”; the catalog has the grammar typo “get”. The catalog was not edited. The module correctly implements the intended +1000 DP behavior.

The card query has no knowledge-base entries. The local KB index associates Q5795/Q5796 with the adjacent EX11-010 effect, not EX11-009; those questions are therefore not applicable to this card. No EX11-009-specific Q&A was returned.
