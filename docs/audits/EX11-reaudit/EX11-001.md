# EX11-001 Koromon audit

## Card contract

Catalog source `packages/shared/src/cards/data/cards.json` prints one inherited clause:
`[When Attacking] [Once Per Turn] This Digimon may digivolve into a Digimon card with [Tyrannomon] in its name or the [Dinosaur] trait in the hand.` The card is a red level-2 Digi-Egg with no normal evolution requirements. `node tools/kb/query.mjs card EX11-001` returns Q5787.

The module is already IR-only and uses `registerIrCard("EX11-001", compiled)`. Its `WhenAttacking` effect is inherited, `OncePerTurn`, optional, paid from hand, self-targeted, and uses the OR filter `name` Tyrannomon or exact `trait` Dinosaur. No module defect was established.

## Clause to test to IR

| Clause | Behavioral proof | IR mapping |
|---|---|---|
| Inherited attack permission | `pays the printed cost...` attacks through a public intent, evolves the stack, asserts memory 10→8, source stack identity, and the standard evolution draw | `trigger: "WhenAttacking"`, `isInherited: true`, `actions[0].kind: "Digivolve"`, `payCost: true`, `from: ["hand"]` |
| Optional refusal | `may decline the inherited attack digivolution` leaves the host and card in hand with memory unchanged | `optional: true` |
| OR destination filter | `does not offer... outside ... filter` uses BT1-014 Giant Bird and proves no evolution or cost | `nameOrTrait: [{tokens:["Tyrannomon"],match:"name"},{tokens:["Dinosaur"],match:"trait"}]` |
| Once-per-turn ledger | `uses the inherited effect only once per turn...` proves the first activation consumes the card and no second synthetic timing injection is used | `frequency: "OncePerTurn"` |

Fixtures use main-deck Digimon only, no Digi-Egg in deck/security, and a 20,000 DP level-3 host so battle resolution cannot erase the evidence. The positive test asserts the standard evolution draw and final zones.

## Q&A

Q5787 is now covered for the card's once-per-turn state through a production turn loop: a first attack reaches the public optional decision and declines it, then the next own turn reaches the same decision again and accepts it, paying the printed cost. A legal simultaneous attack-digivolution peer is still unavailable in this card's public setup: the existing EX11 peer effects use different inherited permissions, and no legal public fixture exposes two same-timing attack-digivolution choices whose order can be asserted without an engine seam. That simultaneous-trigger ordering remains an explicit gap; no injected `advance.fire` claim is retained.
