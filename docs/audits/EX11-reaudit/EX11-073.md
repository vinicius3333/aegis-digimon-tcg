# EX11-073 ExMaquinamon audit

## Contract and implementation

The catalog defines ExMaquinamon as a green/black level-7 Unique LIBERATOR Digimon with DNA digivolution from green level 6 plus black level 6 for cost 0. It has Security Attack +1, Blocker, and Link +2. When DNA digivolving, it may link up to three exact [Maquinamon] cards from hand, trash, or this Digimon's digivolution cards without paying. At the end of the opponent's turn, once per turn and for each link card, it trashes the opponent's top security card and returns one opposing Digimon to the bottom of its deck.

The module uses exclusive `registerIrCard`, has full coverage, and encodes the DNA requirement, static keywords, exact name matching, DNA-only link condition, source zones, self-link scaling, once-per-turn frequency, and ordered per-link end-turn actions.
