# EX11-011 Dinomon re-audit

The catalog identifies EX11-011 as the red/green level 6 Dinosaur Digimon
Dinomon (13 play cost, 13,000 DP). Printed clauses are Security Attack +1,
Fortitude, alternate digivolution from a level 5 card with Tyrannomon in its
name or Dinosaur trait for cost 4, optional On Play/When Digivolving suspension,
then one highest-play-cost Digimon per player is chosen and all other Digimon
are deleted, plus an Opponent's Turn restriction while Dinomon is suspended.

`node tools/kb/query.mjs card EX11-011` returned Q5796-Q5799. Q5796 is proven
by the no-play-cost token case; Q5797-Q5799 are each covered by focused attack
tests. The rules query returned the play-cost rule and the local KB's general
security/attack rules.

`registerIrCard`; no module change was required. The test file replaces the

controller/turn restriction state; attack and evolution behavior uses public
intents. No engine or shared seam was changed.

making Delete optional fails the decline test; changing `highestPlayCost` fails
the high-cost and tie cases; removing `optional: true` fails the refusal path;
removing the suspension guard or Opponent's Turn trigger fails Q5797 and the
turn-boundary test. The alternate route mutation fails memory and invalid-source
assertions.
