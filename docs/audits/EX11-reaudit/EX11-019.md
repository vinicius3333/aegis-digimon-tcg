# EX11-019 Shoemon re-audit

The catalog identifies EX11-019 as the Yellow level 3 Shoemon with the Puppet
and LIBERATOR traits. Its printed effects are optional On Deletion play of one
Familiar Token (Yellow Digimon, 3000 DP, On Deletion -3000 DP for the turn),
plus inherited Barrier. There is no Puppet, Overclock, or Scapegoat keyword on
this card; the Overclock/Puppet rule query was used to confirm those mechanisms
are unrelated to this card's printed contract. The card query returned no
card-specific Q&A.
