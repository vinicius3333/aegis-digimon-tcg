# EX11-064 Altea audit

## Contract and implementation

The catalog defines black/blue cost-4 LIBERATOR Tamer. At the start of the owner's main phase, if the opponent has a Digimon, it gains 1 memory. On Play, it flips the opponent's top face-down security card face up. During the owner's turn, when an own Cyborg or Machine Digimon attacks, by suspending this Tamer, that Digimon may digivolve into a Cyborg or Machine Digimon card from hand; the cost is reduced by 1 for each opponent face-up security card. Security plays this card without paying the cost.

The module is exclusive `registerIrCard`, full coverage, and encodes opponent security face-up manipulation, trigger-subject attack scoping, hand evolution with paid cost, face-up security scaling, and Security play.
