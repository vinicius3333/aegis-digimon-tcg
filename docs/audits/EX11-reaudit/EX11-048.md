# EX11-048 Ghostmon audit

## Contract and implementation

The catalog defines purple level-3 Ghostmon, play cost 3, 1000 DP, with a purple level-2 evolution cost 0 and Ghost/LIBERATOR traits. When Moving and On Play, one of your Digimon with the exact Ghost trait gains Retaliation until the end of the opponent's turn. Its inherited On Deletion effect gains 1 memory.

The module is exclusive `registerIrCard`, full coverage, and encodes both public triggers with exact Ghost trait targeting and the required duration. The inherited On Deletion effect gains one memory and has no unnecessary target restriction.
