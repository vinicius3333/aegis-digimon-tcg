# BT26-001–BT26-036 independent re-audit

Date: 2026-09-05  
Catalog source: `packages/shared/src/cards/data/cards.json`  
Rules source: `node tools/kb/query.mjs card <ID>` plus the referenced local rules data  
Scope: direct modules and colocated tests for BT26-001 through BT26-036.

## Method and result

Each card was checked against every catalog field (identity, kinds, colors,
level, costs, evolution requirements, traits, keywords, main/inherited/security
text and Rule text), then mapped to the direct compiled IR module. The module
was inspected for trigger timing, controller and zone filters, exact numeric
boundaries, costs, optionality, duration, once-per-turn identity and stack
source. Colocated tests were read for positive, negative, refusal, cost and
evolution-stack proof. Cards with KB Q&A were cross-checked against those
rulings; cards without entries were checked against the catalog and shared
rules semantics.

All 36 modules register only with `registerIrCard`; none uses legacy
`registerCard`. Every module reports `coverage: "full"` and `residual: []`.

Focused command (after `@aegis/shared` build):

```text
pnpm --filter @aegis/api exec vitest run \
  src/cards/BT26/BT26-{001..036}.test.ts --pool=threads --no-file-parallelism
```

Initial range result, before review additions: **36 test files passed, 332 tests passed**.  
Additional checks: `pnpm --filter @aegis/api typecheck` passed; `git diff --check`
passed. No shared-engine seam was required by this range.
