# Reboot lifecycle audit

Bounded public turn-loop proof covers native compiled BT4-070 and BT5-069,
plus BT19-020's inherited Reboot on a host stack. Each holder is suspended by
a public attack, then unsuspended during the opponent's unsuspend phase while
a plain suspended Digimon remains suspended.
The inherited case uses a legal BT1-025 host with BT19-020 beneath it.
