# DUAL Option color in effect selections

When an effect can play or use a card, its color filter checks the DUAL card's Option
side if the card would be used as an Option. The activation check and the actual
selection use the same color projection as effects that only use Options. The card's
other text remains available to printed-text filters. The engine checks the live Option
use requirements separately.

EX13-012 SaviorHuckmon can use BT27-068 Gankoomon (X Antibody) from hand because its
Option side is white and references Huckmon in its use requirement. The regression
covers both trigger windows, the reduced use cost of 2, the Option's return effect
and the resulting Arts Digivolution stack.
