# Recovery parameter lifecycle

The §16-6 contract places the specified number of cards from the named area face down on top of the security stack. The bounded proof uses public evolution of BT7-038 and BT9-040, asserts exact deck and security instances, preserves deck order, and covers the five-security condition and an empty deck.

These cases establish Recovery +1 deck processing for two printed providers and do not certify other producers, larger amounts, inherited grants, or unrelated security manipulation.

Rules basis: comprehensive-0224, §16-6-1 through §16-6-2.
