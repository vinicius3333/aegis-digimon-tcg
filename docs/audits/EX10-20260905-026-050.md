## Audit changes

- EX10-031’s focused test now aims an opposing De-Digivolve at the protected level-4 control and proves it stays intact, then uses the same effect against an unprotected control and proves it strips the stack; a temporary neutral IR effect executes a controller-owned De-Digivolve against the protected control and proves own-controller scope remains legal.
- EX10-033’s scaled-cost test now uses neutral Mineral/Rock source cards. Earlier EX10-025/EX10-028 sources had inherited deletion triggers that correctly removed a reduced target during the same resolution, making a later ledger read invalid and obscuring the intended cost-floor assertion.
- EX10-041’s top-security cost test now has a distinct bottom security card and asserts only the top card is trashed.
- EX10-044 now includes a non-Bagra Army Digimon in hand and proves the placement cost cannot consume it or draw.

No unresolved card-specific ambiguity or unsupported behavior remains for this range. The audit child worktree is not marked complete and no commit was created, as directed.
