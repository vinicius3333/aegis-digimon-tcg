Lesser, X Antibody, DigiPolice, and SEEKERS traits. Its inherited text is `[Your
Turn] [Once Per Turn] When Tamer cards are placed in this Digimon's digivolution

restacking. It registers only through `registerIrCard("BT24-005", compiled)`, with
full coverage and no residuals.

A public `respondDecision` returns them in a nontrivial third/first/second order, preserving exact deck identity, the unrevealed fourth card, and no hand additions. Broadcast `cardRevealed` events contain the same three cards, proving the opponent-visible reveal channel required by Q5577. Repeating the placement event in the same turn does not reveal again.

A public Digimon play triggers the existing Witch of the System Mind Link watcher and places that Tamer under the Kyokyomon host.

The corrected negative fixtures now use inert main-deck Digimon (BT1-009..012), while the only Digi-Egg is the breeding-area Kyokyomon. Main-deck Digimon exercise both reorder destinations. No engine fix was required.
