## Defect and fidelity findings

The bracketed `[Soloogarmon]` evolution reference is encoded as exact `namesExact`, matching the printed card-name clause. The inherited `selfHasNameContaining` matcher is intentionally retained because the printed wording is “has [Fenriloogamon] in its name,” not an exact Rule Name requirement. Structural assertions cover the full catalog identity, both alternate routes, keyword, target kind/trait/level/zone, optionality, Once Per Turn, duration, and Q4404’s optional attack.

The inherited once-per-turn proof uses `startTurnLoop()` and public Gaia Force, attack, Main-phase, and surrender intents. The first target deletion occurs from public play, the same-turn second deletion occurs through a public Digimon attack, and the next own turn deletes a third target after a public opponent attack has suspended it. The third target is deliberately 1000 DP so the 9000-DP attacker can legally delete it; the previous 12000-DP fixture made the attack resolve as a battle failure, so the target never left the field and the test falsely looked like an OPT/turn-reset issue. Security removal is asserted after each deletion boundary. Fixtures use legal Digimon, Tamer, Option, and Security cards; no Digi-Egg is placed in a deck or Security.
