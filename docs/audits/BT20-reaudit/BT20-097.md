## Defect and fidelity findings

The card module already encoded the printed name/level/source/zone restrictions and ordered actions correctly. The audit expanded the test from structural-only checks to catalog identity, complete IR, exact matchers, level boundary, legal stack evolution, natural Delay timing, breeding-zone exclusion, accepted/refused cost handling, and public Security behavior.

The previous Delay tests used `placedByEffect`, directly incremented `turnCount`, and called `advance(...).verb.deletePermanent`. Those seams were removed. The replacement now uses a real `startTurnLoop`, public Main-phase Option play, public opponent ST2-16 play, explicit public responses to the Delay optional decision, and public surrender. Security proof likewise uses natural turn progression and does not mutate `turnSeat`. Fixtures contain only legal main-deck Digimon, Options, and Security cards; no Digi-Egg is used. The breeding exclusion uses a legal Dorumon → DexDorugamon → DexDoruGreymon → DexDorugoramon stack and a ready public Main play without advancing into an empty-deck lifecycle.

The Main matcher is intentionally `match: "name"`: the catalog says `[Dex]/[DeathX] in its name`, while the Delay and Security clauses name exact cards and therefore use `nameExact`. The BT20-082 level-7 negative proves the Main level ceiling independently of its matching name.
