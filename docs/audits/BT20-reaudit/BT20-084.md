## Corrections

1. The alternate evolution requirement used `names`, a substring match. Because the bracketed `[Sistermon Ciel]` requirement names an exact card, this incorrectly admitted `Sistermon Ciel (Awakened)` peers such as BT7-083. It now uses `namesExact: ["Sistermon Ciel"]`.
2. The End of All Turns fixture put Digi-Egg `BT1-001` in security, which is not a legal security card. It now uses main-deck Digimon `BT1-009`.
3. The restriction test now includes an allied permanent and checks that it remains suspendable, while checking an opposing Digimon on the play route and an opposing Tamer on the evolution route.
