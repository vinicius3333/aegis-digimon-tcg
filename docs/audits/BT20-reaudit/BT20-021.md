## Defect and fidelity findings

The prior colocated tests used direct `advance(...).fire(...)` calls at the security-trigger and On Play sites. Those structural probes have been replaced with public `attack` and `playCard` intents. The tests now wait for settled observable state, so the unsuspend/security-scaling and optional placement/deletion claims no longer depend on injected timing. Security assertions account for both mechanisms: the four-source attack removes the two effect-trash cards plus one ordinary attack check (4 → 1), while the one-source scaling case removes one effect-trash card plus one ordinary check and preserves the remaining security card in order (3 → 1).

The production IR faithfully keeps the placement/deletion action shared across all three printed timings while leaving the separate attack unsuspend/security action as its own once-per-turn effect. The relative-to-source DP ceiling is inclusive, the placement source is restricted to own Royal Knight-trait cards in hand/trash, and the placement is bottom-of-stack. DNA is not introduced into this card’s Blast Digivolve path, consistent with Q4310. The security scaler counts only digivolution cards, not the top card, and the public tests use real Royal Knight stacks including an Option source.

All deck/security fixtures use legal non-Digi-Egg cards, no `advance.fire`/`fireTiming` remains, and all effect assertions settle before inspection.
