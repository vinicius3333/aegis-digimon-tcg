## Defect and fidelity findings

The prior test relied on `runOneTurn`, direct `turnSeat`/memory mutation, and a private `mainPhase` cast. Those are timing-only or direct-state seams. The audit replaces them with `startTurnLoop`, `advance(...).waitForMainPhase`, public intents, and surrender, while retaining only direct memory assignment as a fixture for the printed start-of-turn boundary. The source IR already had the correct black, cost, trait, hand/trash, host, bottom-stack, and face-up operation constraints; no production change was required.

The placement action is intentionally optional and abortable: the printed “By placing…” payment is a controller choice under the engine's cost-processing convention used by neighboring audited cards (for example BT19-081/BT19-086). The test proves both acceptance and refusal, including the all-or-nothing boundary that refusal leaves the candidate and security unchanged.

Fixtures use legal main-deck Digimon/Tamers/Options only; no Digi-Egg appears in deck or Security. No exact card-name matcher is printed on Altea, so no near-name proof is applicable.
