## Defect and fidelity findings

Its source filter now requires an own Digimon with exact `Paildramon` or `Dinobeemon` name, preventing a near-name card from activating the replacement. Its DNA result filter now requires a Digimon in hand with exact `Imperialdramon: Dragon Mode` name. These are card-name references, not broad substring matches. The previous runtime-default hand behavior remains unchanged but is now directly inspectable in the card contract.

The bound selection is preserved across the two first actions, so the same allied Digimon receives both temporary grants. The optional attack remains separate and independently declinable (Q4297). The public deletion replacement verifies Q4299: the two source permanents disappear, while a new Dragon Mode permanent carries both source stacks instead of leaving play. A wrong-name hand card and an optional refusal prove the replacement’s failure paths. Q4298 is recorded from the linked official Q&A; the focused suite proves the attack action’s optional/public legality path, while active-attack suppression is enforced by the shared attack resolver.
