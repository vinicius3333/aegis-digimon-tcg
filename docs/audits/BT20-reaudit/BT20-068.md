## Exact matching, boundaries, and fixture audit

Bracketed `[Violet Inboots]` is an exact card-name reference. The structural
assertion and source IR use `nameExact`; the free-play test uses BT20-088, whose
printed name is exactly Violet Inboots. The 0/1/2 Tamer boundary exercises the
numeric condition and the refusal test exercises optionality. No name/trait
near-match exists in the committed catalog for this name; other same-name
Violet Inboots printings are valid exact-name matches.

The inherited test uses a public battle against a host that is suspended by a
real owner attack immediately before the opponent turn, followed by the full
public `startTurnLoop()` lifecycle rather than mutating `turnSeat` to reach the
opponent’s turn; it independently observes host deletion and the inherited
`memoryChanged` event with the expected turn-relative delta of -1 before public
surrender ends the loop.
The stack test now starts from a legal breeding-area EX7-006 Yaamon, then
digivolves through Ghostmon and Bakemon into Sandiramon. No Digi-Egg is placed
in deck or Security. There are no once-per-turn, Security, duration, or reset
clauses on BT20-068.

Q4285/Q4286 are related cross-card resolution rulings: they distinguish a
pending inherited effect on the deleted host from a pending effect on a card
that is returned from its stack. BT20-068’s own +1-memory clause is exercised
publicly; the related Ghostmon tests own the two-card ordering seam, so this
report does not claim an unsupported duplicate engine test.
