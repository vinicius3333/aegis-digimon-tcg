## Defects found and fixed

1. **C1 used a substring name gate.** `digivolutionRequirement` carried
   `names: ["Koromon"]`. `DigivolutionRequirement.names` is documented as a SUBSTRING
   match (`packages/shared/src/effects/ir/requirements/digivolve.ts:14`); the printed
   `[Koromon]` is a bracketed exact name, and the rule manual quotes this very clause as
   its example of exact matching. Changed to `namesExact: ["Koromon"]`.
   No released card has "Koromon" as a proper substring of its name (checked against the
   whole catalog: 16 cards contain the token, all named exactly "Koromon"), so the fix is
   fidelity, not a behaviour change today; a future "…Koromon" print would have been
   wrongly accepted.

2. **Illegal fixture in the previous suite.** The old C1 test placed EX10-002 (a Lv.2
   Digi-Egg) in `battleArea`. Digi-Eggs only ever sit in the breeding area. Every C1 case
   is now a breeding-area digivolution with the source-card identity, the stack contents,
   the memory paid and the bonus draw asserted.

3. **No negative source, no ordinary-route case.** The previous suite asserted
   `{ok: true}` on one route and nothing else. Added an on-colour non-Koromon egg
   (BT13-005 Dorimon) and an off-colour non-Koromon egg (BT1-005 Kyaromon) as refusals,
   plus the ordinary Lv.2 route at cost 1 to show the alternate is a real reduction. The
   green Koromon (BT7-004) case proves the alternate is name-driven, not colour-driven —
   no ordinary route reaches a green source.

4. **No turn-boundary proof for C3.** Added a case that carries the +1000 DP across the
   end of my own turn into the opponent's main phase, which is what separates `permanent`
   from `forTheTurn` in the printed `[All Turns]` text.

## Remaining gaps

- **G1 — `duration` is inert on a continuous inherited `ModifyDP`.** Setting the C3
  duration to `forTheTurn` does not change any observable DP, even across a turn end;
  only the IR assertion catches it. The continuous-effect recompute
  (`GameEngine.recomputeContinuousEffects`) re-derives inherited `AllTurns` modifiers each
  pass, so their `duration` never gates anything. Not a defect of this card, but it means
  no card of this shape can earn behavioural credit for its duration field. Coordinator:
  worth one engine-seam note — either honour the field or reject a non-`permanent`
  duration on a continuous inherited modifier at compile time.
- **G2 — `kind: ["Digimon"]` in C2 is not behaviourally provable.** The clause says
  "Digimon card"; the catalog contains no Tamer or Option card with "Greymon" in its name,
  so no fixture can distinguish the kind gate from the name gate. Asserted structurally
  only.
- **G3 — no [Virus] Greymon-named card is free of printed text.** Every candidate used
  (BT10-019, BT1-114) has effects, but all of them are trash-inert, so the fixtures cannot
  open a decision or alter the result.
