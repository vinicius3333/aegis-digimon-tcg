## What the previous audit missed

The committed test claimed 10/10 but proved almost nothing behaviourally:

1. `[On Play]` and `[When Digivolving]` were fired only through `advance().fireForPermanent`
   (injected timing). Neither the real `playCard` route nor any digivolve route was exercised,
   so C1 was never tested at all — no positive route, no cost, no bonus draw, no illegal-source
   negative.
2. `＜Rush＞` and `＜Blocker＞` were asserted only as keyword flags. Neither was played.
3. The end-of-turn clause was fired with `advance().fireForPermanent(EffectTiming.OnEndTurn, ...)`,
   so it never proved the clause reaches a real end of turn, never proved it is limited to the
   OWNER's turn, and never proved the once-per-turn reset.
4. The inherited memory watcher used `advance().verb.deletePermanent(...)` — an injected
   deletion, not a real one.
5. The DP bound was proved only by a biased `preferInstanceIds` pick; there was no case where
   the ONLY opposing Digimon is over the bound.
6. Fixtures used `BT1-010` (an `[On Play]` card) as digivolution-stack filler and
   `EX10-053`/`EX10-052` as opposing bodies, both of which carry their own effects.
   The new fixtures use the five differently named [Gammamon] cards whose OWN inherited text
   is empty (P-058, BT8-013, BT9-023, BT10-050, RB1-029) plus inert BT1-009/013/014.
7. Q5136 was covered only by the "empty trash" case, which is the trivial branch. The ruling is
   about declining the placement; that case is now covered too.

The module's IR needed no change — it was already faithful. Every gap was in the proof.

## Remaining gaps

- **Order within the placed group.** The engine places the selected cards one at a time at the
  stack bottom, so the placed group ends up in reverse selection order and the player is never
  asked to order them. The printed text only fixes that they go to the BOTTOM (which is proved
  exactly), and the comprehensive rules let the player order simultaneously placed cards. This
  is a fidelity nit in the shared `PlaceUnder` primitive, not an EX10-053 defect, and it is not
  something a card-lane edit may fix. No test is red for it.
- **C6 same-turn once-per-turn refusal is structurally unprovable.** A turn has exactly one
  "end of your turn", so no sequence of public intents can offer this clause twice in one turn.
  The reset is proved instead across three consecutive turns through the real turn loop. No
  structural `advance.fire` substitute was added.
- No engine seam is missing and no test is retained red.
