# EX10-011 MaloMyotismon — re-audit

Lv.6 Red/Purple/Blue Virus Demon Lord, DP 14000, play cost 14, SR, max 4.
Digivolution costs: Red 5 / Purple 5 / Blue 5, memory 6 each.

## Printed clauses

1. `[Digivolve] Lv.5 w/[Myotismon] in name: Cost 5` — alternate route, substring name match.
2. `[Trash] [Main] By deleting 2 of your level 5 or higher Digimon with [Myotismon] in
   their texts, play this card with the play cost reduced by 11.` — effective cost 3.
3. `[On Play] [When Digivolving] [When Attacking] [Once Per Turn] Delete 2 other
   unsuspended Digimon.` — one shared use across all three timings, either controller.
4. `[All Turns] [Once Per Turn] When any of your other Digimon or Tamers are deleted,
   trash your opponent's top security card and return 1 of their Digimon with the lowest
   DP to the bottom of the deck.`

No inherited effect and no security effect are printed; the catalog carries neither field,
so catalog and official text agree. No catalog discrepancy found.

## Defects found

None in `EX10-011.ts`. The compiled IR was left unchanged; no engine seam had to move.

The defect was in the evidence, not the implementation. The previous audit claimed 10/10 on a
test file that:

- proved `[When Attacking]` only through `advance(...).fire(EffectTiming.OnUseAttack, …)`,
  which the brief rules out for behavioural credit, and asserted only that nothing happened;
- never reset the once-per-turn use through a real turn loop, so a per-game rather than
  per-turn limit would have passed;
- never deleted one of the controller's own Digimon, so `controllerDefault: "any"` was
  unproven and Q5029 was untested;
- never declined an optional prompt, so a wrongly optional two-delete would have passed;
- proved the Q5028 negative with a level 3 Digimon, which fails the level filter, leaving the
  `match: "text"` filter itself untested on the negative side;
- proved the digivolve route only with a base named exactly "Myotismon", so `names` vs
  `namesExact` (substring vs exact) was unproven, and offered no illegal-source negative.

Five tests were added to close those. No test was weakened or skipped; nothing is retained red.

Two fixture defects were also corrected across the whole file at the coordinator's request:
Digi-Eggs (BT1-001..BT1-005) had been seeded into decks in eight places, which the brief
forbids; every one is now an inert main-deck Digimon (BT1-009..BT1-013). No assertion was
weakened to accommodate the swap — the focused run is green on the new fixtures.

## Remaining gaps

- The `[All Turns]` clause's once-per-turn identity is only proved within a single turn. It is
  not proved that the use resets on the opponent's turn, which is what `[All Turns]` plus
  `[Once Per Turn]` means. Driving a deletion on the opponent's turn needs
  `advance(...).verb.deletePermanent`, which is injected timing and earns no credit, so the
  gap is recorded rather than papered over.
- The `[All Turns]` clause's own trigger is driven by `advance(...).verb.deletePermanent` in
  the pre-existing test and, in the Q5029 test, by this card's own deletion — a Tamer deletion
  as the source is never exercised, and `superlative: "lowestDP"` is never tested against a DP
  tie.
- Only the Red printed colour route is exercised. The Purple and Blue routes carry the same
  level and memory cost and share the same `evoCosts` entry shape, so they are covered by
  construction rather than by a separate assertion.
- `trashSecurityTop` is asserted by security-stack length and by the survivor's identity, not
  by the trashed card's identity or the resulting face state of the remaining security stack.
