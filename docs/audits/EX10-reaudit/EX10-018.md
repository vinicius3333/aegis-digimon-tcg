## Defects found and fixed locally

1. **C1 used a substring name gate.** `names: ["Psychemon"]` is the "[X] in name" gate
   (`cardData.ts`, name gate: `name.includes(n)`). A bracketed `[Psychemon]` is exact,
   so it is now `namesExact`. No catalog card other than Psychemon itself contains the
   substring today, so the change is latent-only; the IR assertion pins it.
2. **C2 accepted bases that do not print ＜Save＞.** `texts: ["Save"]` is matched as a
   case-insensitive substring over the whole card-information union
   (`cardData.ts:499-516`), so it also matched `＜Material Save 1＞` (BT10-111),
   `[Savemon]` (BT21-059) and would match `[Deep Savers]`. Both false bases are Lv.4,
   so the illegal cost-3 route was reachable. The token now keeps its keyword
   delimiters, in both spellings the catalog uses (`＜Save＞` everywhere, ASCII
   `<Save>` on EX4-016).

Proof that defect 2 was real: with `texts: ["Save"]` restored, the two Q5050 negatives
fail (log `logs/EX10-018-regression-check.log`, 3 failed / 11 passed — the third is the
IR assertion).

## Notes on C4's filter

`keywords: ["Save"]` resolves through `definitionHasKeyword`: a compiled-declared keyword,
otherwise the printed `＜Save`/`<Save` token in effect or inherited text. That is narrower
than Q5050's union (it ignores security, link, dual and option text), but no play-cost-4-
or-lower card in the catalog carries ＜Save＞ only in those fields, so the two readings
select the same cards. It is also the safer gate here, because a bare "Save" text-union
match would wrongly admit the Option card EX8-068 "Deep Savers". Left as is, documented in
the module.

## Systemic finding for the coordinator

`texts: ["Save"]` is a repo-wide convention (BT12-008, BT12-011, BT12-035, BT12-048,
BT12-058, BT12-061, BT12-075, BT12-076, EX10-015 and more, plus `digiXrosRequirement`
materials). Every one of those cards has the same ＜Material Save＞ / [Savemon] /
[Deep Savers] over-match. The durable fix is either normalising the token at the
`cardData.ts` / `digiXros.ts` text gate (treat a keyword token as delimiter-anchored) or
sweeping the card modules. Out of scope for this lane; only EX10-018 was changed.
