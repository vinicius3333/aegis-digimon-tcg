## What the previous audit missed

The committed suite proved the card mostly through injected timing and direct state mutation:

- `[On Play]` was proved only by `advance.fire(EffectTiming.OnPlay, ...)`, never by playing the
  card. The cost-7 boundary was proved against a cost-12 Digimon, so cost 8 — the first value
  outside the boundary — was never tested.
- ＜Raid＞, ＜Reboot＞ and ＜Blocker＞ were proved only as `observe(...).hasKeyword(...)` reads.
  No attack, no block, no turn loop.
- ＜Blast Digivolve＞ had no behavioural test at all. Only the compiled record's
  `isFromHand: true` was asserted.
- ＜Overflow＞ 4 had no test at all. Only the catalog value was asserted.
- The 13000 DP gate was moved by writing `perm.baseDP` / `perm.currentDP` directly and by
  `advance.verb.deletePermanent`, never by a card entering or leaving through public play.
- No digivolution negative: an illegal source was never refused.
- "Effects don't affect" was proved only through the `isRestrictedByEffect` observer flag.
  Nothing showed an opposing effect actually failing to change the board.
