## Defects found in the committed audit

The committed test file passed 10/10 but did not prove what it claimed:

1. **Q5189 was not covered at all.** Every test passed `autoOrderTriggers: true`, which answers
   the order prompt with the engine's own order. Nothing asserted that a prompt was raised or
   that the choice mattered. Now proved with `autoOrderTriggers: false`, both orders driven, and
   an order-dependent endpoint (which two cards end up in the deck).
2. **A silently-timing-out `settle` hid a wrong claim.** The old Q5190 test settled on
   `topCard.cardId === "BT1-010"`, which never becomes true (`popFromStack` takes the card
   directly under the top, so the first peel exposes the LAST `under` entry). `settle` returns
   quietly after its tick budget, so the test spun and then asserted only `stack` length 2 —
   consistent with a single peel. `amount: 2` was therefore never proved. Worse, the fixture
   stacked only Lv.3 sources, and `deDigivolve`'s `levelFloor = 3` stops after one peel there.
   The new test uses Lv.4/Lv.5 sources and asserts both peeled cards by id.
3. **"to the top of the deck" was never asserted.** The old test only counted non-`BT1-001`
   cards in the trash. The new test asserts the paid cards by instance id on the deck top.
4. **Three clauses rested on injected timing.** `[When Attacking]`, the decline path and the
   Q5190 negative all used `advance().fireForPermanent(...)`, which earns no behavioural credit.
   All three now run through public intents (`attack`, `playCard`).
5. **The Q5190 negative was near-vacuous.** It fired OnPlay and asserted the stack was unchanged
   without any `settle`, so it would have passed even if the effect had never started.
6. **The substring name gate was untested.** `EX2-039` is named exactly "Impmon", so the old
   positive could not tell a substring gate from an exact one, and there was no wrong-name
   negative.

No engine or module defect was found. The module's IR is faithful; nothing in
`EX10-074.ts` was changed, so `effects.json` does not drift.

## Remaining gaps

- **`[When Digivolving]` De-Digivolve clause.** The clause is proved on the `[On Play]` copy and
  the shared IR is asserted identical for both triggers; the `[When Digivolving]` copy's mill is
  proved live through the Q5191 blast, but its De-Digivolve half is not separately driven.
- **`[When Attacking]` scaled ceiling.** Proved at the printed base of 6 through a real attack;
  the +3-per-10 scaling is proved on the `[On Play]` copy only (same compiled `playCostCeiling`).
- **Turn loop.** No clause on this card is once-per-turn or duration-bound, so nothing here
  needs a next-turn reset; the tests use single-window flows rather than `startTurnLoop`.
- **Overflow ordering (CR §4-18-5-1).** `applyOverflow` documents that a player's own
  simultaneous Overflow instances are processed in array order instead of by free choice. Not a
  defect of this card; noted because this card is an ACE.
