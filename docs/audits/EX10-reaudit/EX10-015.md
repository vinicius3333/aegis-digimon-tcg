### Engine semantics traced

- `abortOnDecline` on the **leading** action gates the whole clause: `interpreter/effect.ts:809`
  (activation gate) and `actions/runAction.ts` (ordered abort). This is what makes Q5045 true —
  the `Suspend` action never runs when the trash cost is impossible or refused.
- `textContains` union: `interpreter/matching/definition.ts:213-228`.
- `[Start of Your Main Phase]` is real production timing: `TurnStateMachine.ts:264` fires
  `EffectTiming.OnStartMainPhase` on entering Main, so the clause is provable through
  `startTurnLoop()` without injected timing.

## Defects found and fixed (test file only)

The module itself was correct; the previous lane's **evidence** was not. Fixed here:

1. **Injected timing.** All three `[Start of Your Main Phase]` proofs used
   `advance(engine).fire(EffectTiming.StartOfYourMainPhase, …)`, which the brief scores 0 for
   behaviour. Rewritten to `startTurnLoop()` + `advance.waitForMainPhase(0)`, so the clause is
   proved on the production phase transition.
2. **Injected deletion.** The ＜Save＞ proof used `advance.verb.deletePermanent(...)`. Rewritten as
   a real attack into a suspended 3000 DP opposing Digimon, so the [On Deletion] trigger comes
   from battle resolution.
3. **Missing turn-owner proof.** Nothing showed the clause staying silent on the opponent's main
   phase. Added.
4. **Missing Digimon-only boundary.** Nothing showed the suspension refusing a Tamer. Added an
   opposing Tamer to the Q5044 board and asserted exactly one suspended permanent.
5. **Missing bonus-draw proof.** The digivolve test asserted cost and stack identity but not the
   digivolution draw. Added.
6. **Illegal fixture.** Two decks held BT1-001, a Digi-Egg, against the brief's fixture rule.
   Replaced with inert main-deck Digimon.

Assertions were tightened from `arrayContaining` to exact hand/deck instance-id lists, which also
records a production fact worth knowing: the opening turn skips the Draw phase card, so the only
card leaving the deck in the Q5044 test is this effect's ＜Draw 1＞.

## Remaining gaps

- **Engine (not fixed, out of allowed files).** `textContains` builds its union from
  `nameEn ∪ types ∪ forms ∪ attributes ∪ effectText ∪ inheritedEffectText`
  (`apps/api/src/engine/effects/interpreter/matching/definition.ts:216`). Q5044 also names
  Security text and (Rule) text. No card in the current catalog carries ＜Save＞ only in its
  security text, so the gap is latent rather than live for this card; a future Save card with a
  security-text-only icon would be wrongly rejected as a cost.
- Not proved: suspending an already-suspended opposing Digimon, and the clause with an empty
  opposing board (the `Suspend` action has no `abortOnDecline`, so the draw should still happen).
  Both are outside the two assigned rulings.
- DigiXros material sources other than the hand are not exercised; the printed recipe names no
  other zone.
