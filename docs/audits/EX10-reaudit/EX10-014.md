# EX10-014 Weatherdramon — re-audit

## Card summary

Catalog (`packages/shared/src/cards/data/cards.json`): Yellow Digimon, Lv.4, play cost 4,
DP 4000, forms `Sup.` / `Appmon`, attribute `Navi`, type `Weather`, rarity C, max 4 per deck.
Digivolve: Yellow Lv.3 for 2. Link: `[Link] [Appmon] trait: Cost 2`, link DP 3000.

Printed clauses:

1. `[Security] At the end of the battle, play this card without paying the cost.`
2. `[On Play] [When Digivolving] Give 2 of your opponent's Digimon ＜Security A. -1＞ until
   their turn ends.` (two separate triggers, one shared body)
3. Link effect: `[When Attacking] By trashing 1 of this Digimon's link cards, 1 of your
   opponent's Digimon gets -6000 DP for the turn.`

No errata. Catalog matches the official text; no discrepancy found.

## Defects fixed locally

1. **Injected timing replaced by public intents.** The committed test proved the `[On Play]`
   debuff and both link Q&A rulings only through `advance(engine).fire(EffectTiming.OnPlay …)`
   and `advance(engine).fire(EffectTiming.OnUseAttack …)`. Per the brief that is structural
   proof worth 0 in the Behavior column. All three now run through real intents: `playCard`
   for On Play, and a declared `attack` on the opponent player for every link case.
2. **Real fixture defect exposed by the change.** Under a real attack the host loses its
   link DP the moment the link card is trashed, so the original 2000-DP host died in the
   security battle. The fixtures now give the host `dp: 20_000` and a single inert security
   card, so the battle resolves without deleting the source of the effect. This is a genuine
   interaction the injected-timing test could not see.
3. **New negative for the cost filter.** Added
   `scopes the link cost to this Digimon's own link cards, not another host's`: a second
   Appmon host carries its own link card, the decision responder is biased toward it, and the
   assertion is that it is never trashed. This is what makes `isSelfRef: true` on the cost
   filter load-bearing rather than incidental — Q5043 alone would pass with a filter scoped
   to any link card on the board.
4. **Digi-Egg removed from a main deck.** The When Digivolving fixture seeded seat 0's deck
   with `BT1-001`, a Digi-Egg, which the brief forbids in deck or security. Replaced with the
   inert main-deck Digimon `BT1-012`. The deck is only there so the bonus draw has a card to
   take; no assertion was weakened.
5. **Duration expiry moved onto the real turn loop.** The `[On Play]` test now runs inside
   `s.engine.startTurnLoop()`. It plays the card in seat 0's Main, ends that phase, waits for
   seat 1's Main and asserts the ＜Security A. -1＞ grant is still `-1` there (it survives my own
   turn end), then ends seat 1's Main, waits for seat 0's next Main and asserts the grant is
   gone. Two real turn ends, no `ledger.sweep`. Both endpoints matter: an `untilOwnerTurnEnd`
   duration would fail the first, an unknown duration string would fail it too, and a permanent
   grant would fail the second.
6. **Advance Surface link grant replaces the engine reach.** The Q5043 two-link board now calls
   `advance(engine).verb.grantLinkMax(hostId, 1, EffectDuration.UntilEachTurnEnd)` (engine lane 1
   seam 7) instead of casting to `engine.continuous.addLinkMaxGrant`. The verb routes through the
   production primitive `fx.grantLinkMax` that every printed ＜Link +N＞ compiles to. No
   `as unknown as` cast remains in either file.
7. **Stale seam comment removed from the module.** The header claimed
   `event: "whenSecurityBattleEnded"` was missing from the shared `SubTriggerEvent` union and
   that the module "cannot typecheck without editing shared". The union now carries it
   (`packages/shared/src/effects/ir/actions/subTrigger.ts:65`) and typecheck reports no error
   in this file. The comment was rewritten to keep only the still-true warning (the SubTrigger
   is what defers the play; deleting it would resolve during the security check). No IR
   changed, so `effects.json` does not drift.

## Remaining gaps

- **＜Link +X＞ still needs a testkit verb, not a printed host.** The Q5043 board raises the link
  maximum with `advance().verb.grantLinkMax`, inside the seam but still an arranged board rather
  than a printed ＜Link +1＞ Digimon (BT21-101 Gaiamon). A printed host is not usable here:
  Weatherdramon's own link requirement is `[Appmon]`, and neither BT21-101 nor BT26-086 is an
  Appmon, so the rule sweep would trash Weatherdramon off that host before the attack. The verb
  is the correct affordance for this card.
- **Security clause proved once.** There is no case where the checked card is played into a
  board where the On Play debuff has fewer than 2 legal opponent targets (the "up to what
  exists" boundary). The `count: 2` cap is proved from above (3 candidates, exactly 2 taken)
  but not from below (1 candidate).
