## Defect found and fixed

The committed module compiled C2 (＜Save＞) **without** `position: "bottom"`.
`runPlaceUnder` reads `belowTop: action.position !== "bottom"`
(`apps/api/src/engine/effects/interpreter/actions/placeUnder.ts:340`), so a
positionless ＜Save＞ tucks the saved card directly beneath the Tamer instead of at
the bottom of its stack. That contradicts Q5119 and CR 4-3, and it disagreed with
the accepted shape in the same set (`EX10-026.ts`, `EX10-027.ts`).

The previous test could not see the defect: it saved onto a Tamer with an **empty**
stack, where both positions produce the same result.

Fix: `position: "bottom"` on the `OnDeletion` `PlaceUnder`, with the rules
citation in a comment, matching EX10-026 / EX10-027.

Mutation check (`logs/EX10-039-mutation.log`): removing that one key again makes
the behavioural ＜Save＞ test fail with
`['u1','u2','chuu']` instead of `['chuu','u1','u2']` — the saved card lands
closest to the Tamer, not at the bottom. The IR-shape test fails too.

C1 already carried `position: "bottom"` and was correct.

## Catalog discrepancies

`cards.json` stores a **non-breaking space** (U+00A0) after every `[Bagra Army]`
token in both `effectText` (offsets 77, 135, 211) and `inheritedEffectText`
(offset 48): `"[Bagra Army] trait"`. The official text uses an ordinary
space. It renders identically and does not affect the compiled IR (trait matching
reads `types`, not the text), but any future text-based tooling — a text-to-IR
generator, a `nameOrTrait match:"text"` filter, a diff against the official list —
will mismatch on it. The test asserts the catalog exactly, U+00A0 included, so the
quirk is pinned rather than hidden. Not fixed here: `cards.json` is out of lane.
The quirk is present in `HEAD` (base 46810fe), so it is pre-existing. `cards.json`
is modified in this worktree by another lane, but EX10-039's entry is
byte-identical to `HEAD` — the assertions above are not reading someone else's
uncommitted edit.

  The Advance Surface test is kept as a structural companion, clearly labelled.
- `underFilter.or` branches do not carry `excludeToken: true` (the ＜Save＞ branch
  does). No implemented token has the [Bagra Army] trait, so nothing is observably
  wrong today; worth normalising if a [Bagra Army] token ever ships.
- C1's own-self case is proved only incidentally: the recorded candidate list shows
  ChuuChuumon itself is a legal host (it is a [Bagra Army] Digimon), and steering
  had to be added to avoid it. There is no dedicated assertion that a card placed
