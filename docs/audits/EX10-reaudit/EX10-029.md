Printed clauses:

## Defects found and fixed locally

1. **Security timing (carried over from the cancelled lane, verified and kept).** HEAD compiled
   the `[Security]` clause as an immediate `PlayWithoutCost` with no `timing` and no `from`.
   That pulls the card out of security *before* the security battle, so the battle never
   happens. The worktree version now matches the canonical shape used by every other
   "At the end of the battle, play this card" printing (BT21-015, BT23-052, BT18-035):
   `timing: "endOfBattle"` + `SubTrigger whenSecurityBattleEnded (once)` +
   `PlayWithoutCost from: ["trash"]`. Test asserts the attacker dies in the security battle
   and only then Warpmon arrives.
2. **Test reached past the seam (fixed by the cancelled lane, verified).** The committed test
   built its multi-link board with `advance(accepted.engine).ledgers.continuous.addLinkMaxGrant(...)`
   (HEAD copy line 181, saved in `logs/EX10-029.test.ts.HEAD`). It now uses BT21-101 Gaiamon's
   printed ＜Link +1＞ instead, and the test additionally asserts Gaiamon's own
   "when your Digimon get linked" clause fired (host unsuspended, opponent security 2 -> 1),
   which proves the host really held two link cards at once.
3. **Restriction was proved only as a flag.** Every previous assertion was
   `observe(...).isRestricted(perm, "cantBeDeDigivolved")`. That is engine state, not
   behaviour. Added `a real ＜De-Digivolve＞ cannot demote the protected Digimon, but demotes it
   without the link`: inside the real turn loop, the opponent plays EX7-046 Jazarichmon
   (`[On Play] ＜De-Digivolve 1＞ 1 of your opponent's Digimon`) against a Lv.5 BT10-081 over
   Lv.4 BT10-074 stack. With Warpmon linked the stack is untouched (`BT10-081` still on top,
   `[BT10-074]` still underneath, seat 0 trash holds only the spent Warpmon). The control run
   is the identical board and identical opponent play with Warpmon never linked: the Lv.5 top
   is trashed and BT10-074 becomes the top. The Lv.4 floor is respected (the brief's
   `levelFloor = 3` note), so this is a real demotion, not a floor no-op.
4. **Catalog quirk found.** `linkRequirement` separates `[Appmon]` from `trait` with a
   non-breaking space (U+00A0), not a normal space. Not edited (catalog is read-only for this
   lane); the test normalises before comparing and the report records it.
5. **Numeric `security: <n>` fixtures removed (coordinator correction).** The ＜Blocker＞ test
   used `security: 1` / `security: 2`, which the brief forbids. Both are now explicit inert
   main-deck Digimon arrays (`BT1-013`, `BT1-014`), and the "no security was checked"
   assertion was upgraded from a length check to an exact aliased instance-id order check.
6. **Assertions strengthened.** Added digivolution-stack identity and DP after each evolution
   route, and explicit `inheritedEffectText`/`securityEffectText` absence.

The invented `digivolutionRequirement` alternate `{cost: 2, traits: ["StandardApp"]}` was
already removed at HEAD; `StandardApp` is not a trait any catalog card carries. Confirmed and
asserted (`compiled.digivolutionRequirement` is undefined).

## Remaining gaps

1. **No opponent-controller negative for the `SelectBind` pool.** The restriction filter is
   `controller: "mine"`, and the tests assert a second *own* Digimon is left unrestricted, but
   no case forces the choice against an opponent's Digimon. The host permanent is always a
   legal own candidate, so a board where only opponent Digimon are selectable cannot be built
   through public intents.
2. **IR shape inconsistency across the set (not a defect here).** This card models
   `[When Linking]` as `trigger: "Static", isLinked: true` + `SubTrigger whenLinked`. Peers use
   `AllTurns` (BT23-033) or `YourTurn` (BT23-021) with the same SubTrigger, and BT23-021 also
   carries a native `trigger: "WhenLinking"` effect alongside it. Behaviour here is proven
   correct through public intents; the divergence is a coordinator-level normalisation
   question, not an EX10-029 bug.
3. **Warpmon is never itself digivolved into.** Its behaviour as a digivolution card under a
   Lv.5 top is not exercised; it prints no inherited effect, so there is nothing to assert.
