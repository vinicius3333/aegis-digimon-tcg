## Defect fixed locally

`apps/api/src/cards/EX10/EX10-021.ts` used `match: "name"` for the bracketed `[Belphemon: Rage Mode]`
reference in both the `OnPlay` and `WhenDigivolving` costs. `match: "name"` is a **substring** match
(`matching/definition.ts:352`), so any future printing whose name merely contained
"Belphemon: Rage Mode" would have been an acceptable cost. The bracketed form is an exact-name
reference, and the peer printing of the identical clause, `apps/api/src/cards/BT13/BT13-088.ts`,
already uses `nameExact`. Changed both to `match: "nameExact"` and covered it with the
three-printings test. No card in the current catalog is a superstring of that name, so the defect
was latent, not live.

This changes the compiled IR, so `packages/shared/src/effects/effects.json` now drifts for
EX10-021 — the coordinator runs the sync.

## Retained red (engine seam)

`it.fails("KB Q5067: an immune Digimon is still offered as a candidate for an opponent's effect")`.

- Seam: `apps/api/src/engine/effects/interpreter/targeting/permanents.ts:138` (and `:507`) skip any
  permanent for which `isPermanentUnaffectable` (`interpreter/matching/permanent.ts:840`) is true,
  which resolves through `primitives.ts:5072` `isUnaffectableByOpponentEffects`.
- Expected (CR 15-15-5-3 / Q5067): an unaffectable permanent is still a legal choice for an
  opponent effect; it is simply not affected once chosen.
- Actual: it is filtered out of the candidate list, so the choice never appears.
- Impact: the end state matches the rules whenever another legal target exists or the effect has
  no follow-on clause. It diverges when the choice itself matters — e.g. "delete 1 of your
  opponent's Digimon. Then, <do X>" with one immune and one normal Digimon: by the rules the
  opponent may burn the effect on the immune one; here the effect is forced onto the normal one.
  Engine-wide, not card-local, so it was not fixed in this lane.

## Remaining gaps

- Q5068, Q5069, Q5071 are documented, not tested (see the table). Each needs a fixture card that
  grants an effect to an opponent's Digimon; none is reachable from EX10-021's own text.
- "Suspend 2" is not proved against a board holding exactly one legal opponent permanent
  ("as many as possible"), because no ruling on this card fixes that case.
- The `[Opponent's Turn]` watcher is proved only through attack-declaration suspension. Effect-driven
  opponent suspension (`whenEffectSuspends` sibling path) is not exercised.
