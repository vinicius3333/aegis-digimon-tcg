# EX10-016 Mirrormon — re-audit

## Card summary

Catalog (`packages/shared/src/cards/data/cards.json`): Green Lv.3 Digimon, play cost 3,
DP 1000, evo cost Green Lv.2 for 0, forms `Stnd.`/`Appmon`, attribute `Tool`, type
`Mirror`, `linkDp` 2000, rarity C, max 4 per deck.

Printed clauses:

1. `[Digivolve] Lv.2 w/[Appmon] trait: Cost 0` — alternate digivolution route.
2. `[Your Turn] [Once Per Turn] When this Digimon gets linked, you may suspend 1 of your
   opponent's Digimon.`
3. `[Link] [Appmon] trait: Cost 1` — link requirement.
4. Link DP `+2000`.
5. Link effect: `[When Attacking] By trashing 1 of this Digimon's link cards, suspend 2 of
   your opponent's Digimon.`

No inherited effect and no Security effect are printed; the catalog carries neither field,
so there is nothing missing there.

## What changed

Only `apps/api/src/cards/EX10/EX10-016.test.ts`. The module IR was left as committed; the
re-audit found no IR defect.

1. **Natural origin for the link effect.** `advance().fire(EffectTiming.OnUseAttack, ...)`
   in both Q&A tests was replaced by `applyIntent(0, { type: "attack", target: { kind:
   "player" } })`. The host now needs to survive its own security battle after the link card
   is trashed as cost, so the host permanent is seeded at `dp: 20_000` and the opponent gets
   real security.
2. **Natural origin for the once-per-turn gate.** `advance().fireSubTrigger("whenLinked",
   ...)` was replaced by a second *real* `linkCard` intent onto Mirrormon, made legal by a
   ＜Link +1＞ grant. The grant arms board state, not timing: the event that reaches the
   watcher is produced by the link primitive itself.
3. **Real reset proof.** The test now runs under `startTurnLoop()`: use on own turn, refusal
   on the same turn, a full round trip through the opponent's turn, then a third link that
   fires again.

Round 2 added two things:

4. **The ledger reach is gone.** All three ＜Link +1＞ grants now run through the Advance
   Surface verb `advance(engine).verb.grantLinkMax(permanentId, 1, EffectDuration.UntilEachTurnEnd)`
   (`apps/api/src/engine/testkit/advance.ts`, seam 7 in `ENGINE-LANE-1.md`), the same
   production primitive every printed ＜Link +N＞ clause compiles to. No test line reaches
   `engine.continuous`, `engine.ledger` or `engine.primitives` any more. A printed host
   (BT21-101 ＜Link +1＞, BT26-086 ＜Link +6＞) could not be used here: the once-per-turn gate is
   on Mirrormon itself, so the capacity has to be raised on *Mirrormon*, not on a neighbour.
5. **A real breeding-stack build.** New test
   `builds Mirrormon through a real breeding stack: hatch, digivolve in breeding, move out`
   runs the whole route through public intents — `hatchEgg` on a BT1-007 Tanemon egg deck,
   `digivolve` into Mirrormon inside breeding at zero memory, `moveFromBreeding` into the
   battle area — and asserts stack identity by instance id at every step
   (`breeding.stack === [eggInstanceId]`, then `battleArea[0].stack === [eggInstanceId]` with
   `topCard.cardId === "EX10-016"`). It then fires the self-linked watcher on that bred
   permanent, so clause 2 is proved on the card as it is actually built.

## Defect found and fixed in the proof

The count-based assertion the previous test shape invited is not sound for this card.
`Suspend` does not exclude already-suspended candidates, so a *second* firing that
re-suspends the same Digimon leaves the suspended count at 1 and looks exactly like a
refused use. With a count-only assertion, deleting `frequency: "OncePerTurn"` from the
module left the behavioural test green — the printed gate was not load-bearing in the proof.

The test now names the target of each step through a live `preferInstanceIds` bias
(`firstTarget`, then `secondTarget`, then `thirdTarget`). Re-running the same mutation with
the strengthened assertions fails as it should:

```
FAIL src/cards/EX10/EX10-016.test.ts > suspends 1 only when this Digimon gets linked, ...
AssertionError: expected true to be false
```

(`docs/audits/EX10-reaudit/logs/EX10-016-mutation-opt.log`; the module was restored
immediately afterwards and is byte-identical to HEAD.)

## Remaining gaps

- The second same-turn link needs a ＜Link +1＞ grant on Mirrormon itself to be legal, and no
  card prints ＜Link +X＞ onto another Digimon, so the capacity comes from the sanctioned
  Advance Surface verb `advance().verb.grantLinkMax`. The link intents and the resulting
  `whenLinked` events are fully public; only the link-capacity state is armed, through the
  same primitive a printed ＜Link +N＞ clause uses.
- The link `[When Attacking]` effect is proved on an attack declared against the player. An
  attack declared against a Digimon is not separately covered; the effect has no target
  dependency on the attack target, so the risk is low.
- "Suspend 2" is proved with 3 and with 2 legal opposing Digimon. The behaviour with exactly
  1 (partial resolution) is not covered.
- No engine defect found; nothing is retained red.
