IR checks against the engine source:

- `scaling.unit: "trash"` is handled by `scaleFactor` in
  `apps/api/src/engine/effects/interpreter/scaling.ts` (case `"trash"`), which counts the
  controller's trash and floors by `per`. Matches "for every 10".
- `duration: "permanent"` is a real `EffectDurationRef`
  (`packages/shared/src/effects/ir/durations.ts`). The clause is still turn-scoped because
  `turnOwnerGuard` gates `YourTurn` on `state.turnSeat === source.ownerSeat`
  (`interpreter/effect.ts:486`) and the continuous ledger is re-derived every recompute —
  proved behaviourally by the DP dropping back to base on the opponent's turn.
- `StartOfYourMainPhase` maps to `EffectTiming.OnStartMainPhase`, fired by
  `TurnStateMachine.ts:264`, so the turn loop is the production route for clause 2.

## Defects found and fixed locally

The committed state had **no module defect**; `EX10-037.ts` is unchanged. The defects were in
the test file, which the previous audit scored 10/10:

1. **Clause 2 was proved only by injected timing.** The old test called
   `advance(s.engine).fireForPermanent(EffectTiming.StartOfYourMainPhase, ...)`, which the
   brief scores 0 for behaviour. Replaced with the real turn loop.
2. **Q5116 was claimed but not tested.** The old test named Q5116 in its title while only
   exercising a normal deck trash. There was no reveal/search case at all — the exact thing
   the ruling denies. Added the BT11-046 reveal case.
3. **The inherited clause reached outside the test seam.** The old test mutated
   `s.state.turnSeat` by hand and called `s.engine.recomputeContinuousEffects()` to fake the
   turn change. Replaced with `startTurnLoop` + `waitForMainPhase(0)` -> `endMainPhaseIfOpen(0)`
   -> `waitForMainPhase(1)`.
4. **Non-inert fixtures.** The old test used EX10-028 and EX10-030 (both effect-carrying EX10
   cards owned by other lanes) as the opponent board and as the inherited-clause host. Replaced
   with inert BT1-014 (Lv.4), BT1-020 (Lv.5) and BT1-009 / BT1-013.
5. **No scaling boundary.** The old test only checked 20 trash cards -> +2000. Added the 19 ->
   +1000 boundary, which is what distinguishes "for every 10" from "per card".
6. **No optional-refusal path and no empty-candidate path.** Both added.

## Round-2 additions (Peer/stack 1 -> 2)

   matches the printed text.

## Catalog note (reported, not edited)

The catalog effect text reads "When this card is trashed from **the top of** the deck", while
Q5116 phrases the same clause as "trashed from the deck". The engine fires
`whenTrashedFromDeck` from the `TrashTopDeck` seam only (`primitives.ts:2956`), so both
readings behave identically for every currently implemented mill. Flagging the wording for the
coordinator; no catalog edit made.
