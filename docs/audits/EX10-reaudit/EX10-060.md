## What changed

Only `apps/api/src/cards/EX10/EX10-060.test.ts`. The module was already correct; no change to
`EX10-060.ts` was needed, so the compiled IR and `effects.json` do not drift.

The previous test file proved C2 and C3 with `advance().fireForPermanent(...)` injected timing,
which earns no behavioural credit. Every behavioural case is now driven by `playCard`,
`digivolve`, `attack` and the real turn loop. Three small structural assertions (catalog, the
Larva-gate action shape, the shared once-per-turn key) are kept as documentation of the IR.
