### What each behavioral test pins

- **Player attack, delete on suspension.** Golemon attacks the player through the `attack`
  intent. The Alliance prompt is declined, the exact 4000-DP opponent permanent id is gone,
  the 2000-DP and 4001-DP permanents remain (battle area length 2), the deleted card's
  instance id is in the opponent trash, Golemon is suspended, the opponent's own board is
  untouched (length 2), security drops 3 -> 2, and no decision is pending.
- **DP boundary and controller boundary.** With only a 4001-DP opponent Digimon, nothing is
  deleted (its instance id is not in trash, trash holds only the checked security card) and
  neither of the controller's own Digimon leaves.
- **Once per turn, same turn.** After the first attack deletes one, the board is arranged
  with the effect verb `unsuspend` (no public intent unsuspends mid-turn on this board) and
  a second public `attack` re-suspends Golemon. The second Digimon survives; security dropped
  to 1, proving two attacks actually happened.
- **Once per turn, reset.** Through `startTurnLoop()`: own Main -> attack (first delete),
  the turn passes, opponent ends their Main, own Main again with Golemon unsuspended and the
  second Digimon still present (asserted), then a second attack deletes it.
- **Blocker on the opponent's turn.** The opponent attacks the player, `declareBlock` puts
  Golemon in the way; Golemon suspends, its delete removes the 4000-DP bystander, combat then
  removes the 3000-DP attacker, Golemon survives suspended, and security stays at 3.
- **Alliance, both directions.** Golemon's own Alliance offers the other Digimon and not
  itself, suspends the ally, and Golemon reaches 8000 DP with `securityAttack` 2 while the
  block window is held open by a 9000-DP ＜Blocker＞ wall. In the other direction, a
  Cendrillmon (EX11-024) Alliance that suspends Golemon fires Golemon's own delete.
- **Digivolution.** The alternate CS route pays exactly 2 (memory 2 -> 0) from an off-color
  Lv.3 CS source (BT23-062 Dracmon, Purple), keeps the source as the only stack card, and
  draws the one card the deck was staged with. The normal route pays the printed 3 from a
  red Lv.3. A plain blue Lv.3 (BT1-029) is rejected on both routes with `invalid-evolution`
  and no memory spent; a Lv.4 CS card (BT23-041) is rejected on the alternate route.

Fixture note: `BT23-037` Tentomon was the previous alternate-route source. It carries
"reduce the digivolution cost by 1" for CS targets, so it could never prove the printed
cost 2. The suite now uses BT23-062, which has no cost modifier.

## Defects found

1. **Prior suite proved nothing behavioral for the suspension trigger.** It drove the
   trigger with `advance().verb.suspend`, an injected-timing call. Replaced with public
   `attack`, `declareBlock` and `respondAlliance` intents.
2. **Prior digivolve test never pinned a cost.** It asserted `{ok: true}` only, and used a
   source (BT23-037) whose own text reduces the CS digivolution cost by 1, so the printed
   "Cost 2" was never exercised. Both routes now pin memory paid, stack identity and the
   bonus draw.
3. **Prior once-per-turn test never proved the reset.** No turn loop ran, and the second
   suspension was injected. Both the same-turn refusal and the next-own-turn reset are now
   driven by real intents, with the intermediate state asserted at each step.

No card-module change was needed: `apps/api/src/cards/BT23/BT23-051.ts` is correct as
compiled. It still carries the generator's `// @ts-nocheck` header, which is the
auto-generated marker the whole IR-card family shares; removing it is a generator-lane
decision, not a card fix.

## Remaining gaps

- The `[Your Turn]` qualifier on the attack restriction cannot be falsified from the other
  side: no rule lets a Digimon attack during the opponent's turn, so "the restriction is
  absent on the opponent's turn" has no observable consequence. The block test shows the
  restriction does not leak into blocking, which is the only adjacent behavior.
- Mid-turn re-suspension has no public route on a minimal board, so the same-turn refusal
  arranges the board with the `unsuspend` effect verb. The suspension being tested is still
  produced by a public attack intent.
- The delete has no target-choice branch to refuse (it is mandatory and not "up to"), so
  there is no optional-refusal test; the no-legal-target case is covered instead.
