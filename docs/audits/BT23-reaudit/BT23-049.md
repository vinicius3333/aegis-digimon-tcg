## Defect found and fixed

The `[Start of Your Main Phase]` cost was **not declinable**. `BT23-049.ts` set
`abortOnDecline: true` but not `optional: true`, so the engine paid the trash cost with no
prompt whenever a matching card was in hand. That contradicts §15-7-4: the controller may
always choose not to execute an optional processing condition. Fixed locally by adding
`optional: true` to the cost-bearing `Draw` action, matching the house pattern for the same
prose shape (`apps/api/src/cards/BT13/BT13-062.ts:44-46`). The decline test failed before
the fix and passes after it.

## Fixture defects fixed

The previous suite placed Digi-Egg cards (BT23-002 Yokomon, BT1-003 Upamon) directly in the
battle area to prove the digivolution routes. Digi-Eggs belong in breeding; both routes now
start from a breeding permanent and assert source-stack identity, the 0 memory cost, and the
digivolution bonus draw.

The previous alternate-route test also asserted only `{ ok: true }`, which proves nothing
about the cost. The route now passes `useAlternateCost: true` from an off-color (Green)
Lv.2 CS source, where the printed Black EvoCost cannot apply, and pins memory at 3 before
and after.
