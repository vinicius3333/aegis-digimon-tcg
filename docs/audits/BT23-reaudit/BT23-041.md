## Evidence detail

- The behavioral core is one attack chain. Kabuterimon attacks the player, so it suspends
  through the production combat path; the trigger's target prompt is biased to the ally
  (BT1-009, 3000 DP). Endpoints asserted: Kabuterimon suspended, ally has ＜Piercing＞ and
  6000 DP, Kabuterimon unchanged at 5000, one security card gone. The ally then attacks a
  suspended 4000 DP BT1-014 — a battle it wins only because of the +3000 — and its
  ＜Piercing＞ removes a second security card. Final endpoints: opponent battle area empty,
  ally still on the board, opponent security 3 -> 1, no pending decision.
- Every attack by Kabuterimon opens an ＜Alliance＞ prompt (§16-24-1 puts the keyword on the
  attacker), so each test answers it explicitly with `respondAlliance`. The Alliance test
  accepts and asserts the ally suspends, the opponent takes 2 security checks instead of 1
  (the extra ＜Security A. +1＞), and the suspension clause still fired exactly once — the
  ally's suspension is not the source's own.
- The turn test drives real turns (`runOneTurn` + `waitForMainPhase` + `endPhase`). It
  asserts the grant is present during the granting turn, gone once that turn closes, still
  gone through the opponent's whole turn, and granted again after a fresh attack on the next
  own turn.
- The invalid-target branch does not use auto-selection. It reads the live `chooseTargets`
  request, asserts the candidate list holds both own Digimon and not the opponent's, and
  shows the engine refusing a forged opponent id. Note the refusal code is the generic
  `decision-pending`: `engine/decisions/index.ts` `satisfiesMin` drops ids outside the
  candidate set, so the response never reaches a target validator. The decision stays open
  and the legal answer then resolves it. This is an engine-wide reporting coarseness, not a
  card defect, and is left as-is (engine files are out of this lane's scope).
- Fixtures are legal: security stacks hold main-deck Digimon (BT1-010), no Digi-Eggs are
  placed outside breeding, and every pre-laid battle-area Digimon is a card that could have
  been played from hand.
