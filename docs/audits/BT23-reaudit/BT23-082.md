## Defects found and fixed (local, in `BT23-082.ts`)

1. **`[Lopmon]` matched as a substring.** The target filter compiled the bracketed name with `match: "name"`, which `matchNameOrTrait` (`apps/api/src/engine/effects/interpreter/matching/definition.ts:352`) implements as `name.includes(token)`. `BT16-067 Lopmon (X Antibody)` therefore qualified. Fixed to `match: "nameExact"`. Proof: `refuses [Lopmon (X Antibody)]` was red before the fix (the X Antibody card was played from hand onto the battle area) and green after.
2. **`// @ts-nocheck` and an `as any` cast removed.** The module now typechecks unmodified; `tsc --noEmit` reports no error for either BT23-082 file. Removing the suppression is what the brief asks so that bad `duration:` strings and similar errors surface. This module has no `duration:` field.

No change was needed for the trait gate: `sourceFilter` on a `whenOneOfYoursDigivolves` watcher is evaluated against the event subject, which is the resulting permanent, so the printed "digivolve **into** a Digimon with the ... trait" is enforced correctly. `match: "trait"` is exact trait equality, so `CS` cannot leak onto a different trait.
