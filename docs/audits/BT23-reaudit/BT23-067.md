## Defects found and fixed

Both are in `apps/api/src/cards/BT23/BT23-067.ts`, both local to the card module.

1. **Substring name matching.** The reduction gate used `match: "name"`, which
   `apps/api/src/engine/effects/interpreter/matching/definition.ts` implements as substring
   matching. The printed reference is bracket-only, so §2-3-1-2 requires the exact printed name.
   With the old IR, "Angewomon (X Antibody)" (BT9-040) wrongly enabled the -3.
   Fix: `match: "nameExact"`. Proved red-then-green by reverting the token: the near-name control
   then ended on memory 6 instead of 3.

2. **Breeding area counted as "you have".** The `youHave` filter carried no zone.
   `countMatching` (`apps/api/src/engine/effects/interpreter/scaling.ts:13`) includes the
   breeding-area permanent when no zone is given, which §3-4-5-8 forbids.
   Fix: `zone: "battleArea"`.
   No behavioral test is attached: neither named card can legally sit in a breeding area
   ([Angewomon] is Lv.5, [Mirei Mikagura] is a Tamer), so no legal fixture can reach the wrong
   branch. The fix is proved at the IR level and by the unchanged battle-area positives.

`// @ts-nocheck` was removed from the module; it typechecks without it.

The `Delete` target needs no zone: permanent targeting already defaults to the battle area
(`apps/api/src/engine/effects/interpreter/targeting/permanents.ts:110-119`), and the "level 5
opponent Digimon only" and "own level 4 Digimon" negatives pin that behavior.

  the opponent's Lv.6 still on the board, and no pending decision. The alternate route costs the

## Remaining gap (engine, not fixed here)

Same latent gap the BT23-031 audit recorded: the printed clause says "would be played **from the
hand**", but the reducer carries no origin-zone condition and
`GameEngine.fireBeforePayCost` does not pass `originZone` into
`wouldBePlayedSelfReducersFor`. The `WouldBePlayedSelfReducer` shape
(`apps/api/src/engine/effects/interpreter/registration/reducers.ts:25`) has no zone field, so the
gate cannot be added inside the card module. No retained red is attached because the gap is
unreachable today: every catalog effect that plays a Digimon from another zone does so without
paying the cost. Recommended engine work: carry `originZone` into self-reducer evaluation and
compile an `originZone: "hand"` gate for "would be played from the hand" text.
