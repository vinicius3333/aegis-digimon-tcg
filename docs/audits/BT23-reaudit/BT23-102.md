## Defects found and fixed in the module

1. **Missing printed cost headers.** The module carried no `digivolutionRequirement` and no
   `dnaDigivolveRequirement`, so neither printed route existed: the Blue Lv.5 [CS] base was
   illegal and DNA digivolution was impossible. Added both, matching the BT23-032 shape.
   `traits: ["CS"]` is exact trait matching (CR 2-3-2-3); a substring gate would be
   case-insensitive and would also accept "Abadin Electronics".
2. **The removal watcher only saw its own security stack.** The `SubTrigger` action had no
   `sourceFilter`, and `securityRemovalGate` in
   `apps/api/src/engine/effects/interpreter/actions/subTrigger.ts` (~line 226) reads
   `sourceFilter.controller` as the watched stack direction, **defaulting to `"mine"`**. The
   printed text says "when security stacks are removed from" — both stacks. Added
   `sourceFilter: { controller: "any" }`. Proven red then green by the natural-attack test:
   before the fix a security check on the opponent's stack raised no prompt at all.
3. Removed the module's `// @ts-nocheck`; it typechecks without it.
