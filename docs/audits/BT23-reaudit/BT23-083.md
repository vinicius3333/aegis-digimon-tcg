# BT23-083 Fei — re-audit

## Card summary

Green/Black Tamer, play cost 4. Traits: Zaxon, CS.

Printed clauses:

1. `[Start of Your Main Phase] If you have a Digimon with the [Royal Base] or [CS] trait, gain 1 memory.`
2. `[All Turns] When cards are placed face up in your security stack, if any of them have the [Zaxon] or [Royal Base] trait, by suspending this Tamer, gain 1 memory. Then, if you have 7 or fewer cards in your hand, <Draw 1>.`
3. `[Security] Play this card without paying the cost.`

Catalog text matches the compiled IR. No catalog discrepancy. BT23-042's report uses Fei as its
"[Royal Base] in text, not in traits" fixture; that remains true after this audit — Fei's traits
are still `Zaxon`/`CS` and only its effect text names `[Royal Base]`.

## Rulings covered

- **Q5356** — the part after "then" cannot be processed without the "by" condition. Proved by
  the decline test: refusing the suspend yields no memory and no `<Draw 1>`, and Fei stays
  unsuspended. The already-suspended test proves the same gate from the other side: an
  unpayable cost resolves nothing.

## Defects found and fixed

- **`youHave` counted the breeding area.** `BT23-083.ts`'s start-of-main condition had a
  zone-less filter, so a `[CS]` Digimon in the breeding area satisfied "if you have a Digimon
  with the [Royal Base] or [CS] trait". Comprehensive Rules 3-4-5-3 and 3-4-5-8 say breeding-area
  cards can't be referenced by an effect that does not name the breeding area. Fixed locally by
  adding `zone: "battleArea"`. Proved red-then-green: without the fix the breeding test reads 4
  memory instead of 3.
- **`// @ts-nocheck` removed** from `BT23-083.ts`. The module typechecks without it, so type
  errors in this card now surface (per the set-wide `EffectDurationRef` lesson).
- **The previous test file was structural.** It reached past the seam into
  `engine.primitives.addSecurity(...)` and `engine.fireTiming(...)`, so it never proved the
  clauses through any route a player can take, and never touched the `[Security]` clause. It is
  replaced.

## Remaining gaps

- The `[All Turns]` label is proved only on the controller's own turn: no fixture grows the
  controller's security face up during the opponent's turn. The available public route for that
  is BT23-015's `[On Deletion]` self-place after an opponent's attack, which needs an 11000-DP
  board to set up.
- Multi-card face-up adds (several cards placed at once, only some matching) are untested — no
  implemented card places more than one card face up in one operation.
- The `[Security]` clause is proved with an unopposed player attack; it is not proved after a
  security battle or with a full stack beneath it.
