# BT23-027 Angemon independent re-audit

Status: incomplete; no accepted ledger credit yet. Sources: committed catalog BT23-027, local KB Q5256/Q5257/Q6250, direct compiled IR, and the official Shakkoumon requirements recorded in SOURCE-RECONCILIATION.md.

Angemon has direct and inherited Barrier, ordinary yellow/black level-3 evolution for 3, and alternate Patamon or level-3 CS evolution for 2. On Play and When Digivolving draw one, then optionally DNA evolve two own Digimon into an exact Shakkoumon in hand on the controller's turn. Both DNA filters are corrected from substring to exact-name matching. Production registration remains exclusively registerIrCard.

The dependent BT23-032 module now carries the official CS level-4 alternate for 3 and both zero-cost DNA recipes (yellow level 4 plus black or blue level 4). Before correction, its missing requirements let the legacy fallback accept an invalid level-3 material and charge ordinary evolution cost. That behavior is not accepted evidence.

## Reviewed evidence

The focused suite has 24 passing cases, including supplemental structural/injected-timing checks and these public proofs:

- Angemon hard play costs 5, draws its own effect card, and DNA evolves with legal Ankylomon for zero additional memory. Both physical materials, resulting top, On Play draw and DNA bonus draw are asserted.
- Normal yellow and black level-3 evolution pays 3; Patamon and off-color CS alternate routes pay 2. Each uses one hand Angemon and exactly two named deck cards, asserting both the evolution bonus and effect draw. Invalid alternate sources reject without mutation.
- Public On Play negative cases isolate one own material, an enemy-only second material, an invalid level-3 second material, Shakkoumon only in trash and Shakkoumon only in opponent hand. The result is present in own hand for the material-boundary cases. Draw, memory, exact unaffected material/hand/trash zones and no pending decision are asserted. A separate legal DNA choice is explicitly refused.
- Q5256 originates from a public Garurumon attack with inherited Betamon. It plays Angemon, which draws but cannot DNA evolve while restricted; the attacking blue level-4 Garurumon is otherwise a legal second material. Shakkoumon remains in hand and both battle-area Digimon remain. The first player's first-turn draw is skipped, so the asserted deck reduction is Angemon's own effect draw.
- Actual combat against direct Angemon and a Shakkoumon with inherited Angemon covers Barrier acceptance/refusal. The inherited refusal case explicitly declines its live source-play replacement choice before asserting quiet combat and final survival/security state.

## Exact-name sweep (session 2)

The printed route reads "[Digivolve] [Patamon]/Lv.3 w/[CS] trait: Cost 2". The bracketed name with no "in name" wording is an EQUALITY gate, but the module used `names`, a substring gate in `engine/cards/cardData.ts` `matchGatedRequirement` (~line 481). Changed to `namesExact: ["Patamon"]`. No released card's name merely contains "Patamon", so the near-name negative uses a synthetic level-3 base without the [CS] trait ("BlackPatamon") passed straight to `matchingAlternateDigivolutionRequirement`: red before the fix (it matched the cost-2 route), green after. The positive [Patamon] route (BT1-048) and the level-3 [CS] route stay green. The DNA target [Shakkoumon] already used `match: "nameExact"`.

### What changed

1. **Q5257 is now a full public proof.** The old test stopped at the `orderTriggers` prompt.
   It now drives the whole ruling: one window offering both `＜Alliance＞` instances plus the
   `[When Attacking]` effect; the 1st Alliance suspends Ankylomon (Hudiemon 7000 -> 12000);
   `[When Attacking]` returns the CS Tamer and replays `[On Play]` to play this Angemon free;
   Angemon's derived `[On Play]` draws and DNA digivolves Angemon + the suspended Ankylomon
   into Shakkoumon, which **arrives unsuspended**; the 2nd Alliance then suspends that
   Shakkoumon. Endpoints: max attacker DP during battle 20000 (so the 1st Alliance's +5000
   survived its ally becoming a digivolution card), opponent security 5 -> 2 by exact instance
   ids, no pending decision. `preferInstanceIds` pins the material pair, because
   Hudiemon + Ankylomon is also a legal Shakkoumon recipe.
2. **The opponent-turn DNA gate is public.** Previously only `advance.fire`. Angemon now
   reaches the board during the opponent's turn the one way the rules allow: seat 1 attacks
   inside the real turn loop, seat 0 answers the `[Counter]` window with `respondCounter` +
   `blast-digivolve:` (EX6-035 Cherubimon over BT23-029 Antylamon), and Cherubimon's
   `[When Digivolving]` plays Angemon free. Angemon draws; the DNA half is never offered even
   though Angemon + Ankylomon is a legal recipe and the `[Shakkoumon]` card is in hand.
   Two draws are asserted: the ＜Blast Digivolve＞ evolution bonus and Angemon's own.
3. **Q6250 is green.** The `barrier-then-source-play` seam was fixed by the engine lane
   (BARRIER-SOURCE-PLAY-MECHANISM.md). The test is a plain `it` and passes; the stale
   RETAINED RED comment was replaced with the mechanism reference.
4. **Defect found and fixed in the module.** Both DNA actions carried `from: ["hand"]`, which
   is **not a field of `DnaDigivolveAction`** — the result zone is read from
   `into.filter.zone` (`interpreter/actions/dna.ts` ~line 33, defaulting to `hand`). The key
   was silently ignored and only agreed with the default by luck. It is now `zone: "hand"` on
   the `into` filter, with a red-then-green proof: with `zone: "deck"` the new deck test fails
   (the DNA fires from the deck); with `zone: "hand"` it passes.
5. **`// @ts-nocheck` removed** from `BT23-027.ts`. That header was hiding defect 4 —
   `pnpm --filter @aegis/api typecheck` reports it as TS2353 as soon as the header is gone.
   The whole API package now typechecks clean, including the previously noted
   `combat/controller.ts:617` failure, which the engine lane fixed.
