## Card

Source: committed catalog record `BT23-053`. Black Digimon, level 4, play cost 5, DP 5000, Champion, Vaccine, traits Dragonkin/CS. Printed digivolution cost Black level 3 for 2.

Printed clauses:

1. `[Digivolve] Lv.3 w/[CS] trait: Cost 2` — an alternate, colour-free recipe.
2. `[Your Turn] When any of your Option cards are placed in the battle area, this Digimon may digivolve into a Digimon card with [Cyberdramon] in its name or the [CS] in the hand with the digivolution cost reduced by 2.`
3. Inherited: `[All Turns] This Digimon gets +1000 DP.`

The catalog `effectText` carries two U+00A0 characters (`[CS] trait` and `[Cyberdramon] in`). The exact-text assertion escapes both. No catalog discrepancy against the official card text.

Rulings: `node tools/kb/query.mjs card BT23-053` returns no knowledge-base entries, matching KB-INDEX (`BT23-053 | 0 | None`). No Q&A ids to cover.

Peer with the identical printed wording: `BT22-037` Chirinmon (`... may digivolve into a Digimon card with [Kentaurosmon] or [Mitamamon] in its name or the [CS] trait in the hand with the digivolution cost reduced by 2`). It is used as the live [CS]-branch target below, so the shared shape is exercised, not just asserted.

## How the clause is driven publicly

`BT23-100` Hudie Net Café is a White Option whose printed `[Main]` body draws 1 and then places itself in the battle area. A plain public `playCard` intent therefore reaches `primitives.placeOptionAsPermanent` (`apps/api/src/engine/effects/primitives.ts:1239`), the only production site that fires `whenOptionPlayed`. Strikedramon itself supplies the on-field [CS] Digimon that waives BT23-100's colour requirement, so no extra board is needed. Every positive test runs inside a real `startTurnLoop()` with `advance().waitForMainPhase(0)` and a neutral playable card (`BT1-020`) in hand so Main stays open.

Two negatives cannot be reached by any public intent and say so in the file:

- an opponent's Option placed while seat 0's Main is open (the opponent cannot play a card on seat 0's turn), and
- seat 0's own Option placed on the opponent's turn (BT23-100's placement rides its own `[Main]` body).

Both drive only `advance().verb.placeOptionAsPermanent`; the turn, the phase and the watcher are production.

## Cost evidence

`BT23-055` Cyberdramon costs 3 from a Black level 4. The reduced run pays `10 - 3 (Option play cost) - 1 = 6`; the control run, with no Option, pays `10 - 3 = 7`. The pair pins the reduction at exactly 2 rather than asserting `{ok:true}`.

The [CS] branch uses `BT22-037` Chirinmon, a **Yellow** level 5. Its only recipe that fits a Black Strikedramon is its own alternate `Lv.4 w/[CS] trait: Cost 3`, so the observed 1 also pins that the alternate requirement — not a colour recipe — was the one charged.

Note on the `[Your Turn]` keyword: with the earlier, weaker version of the opponent-turn test the `YourTurn` -> `AllTurns` mutation stayed green, because the engine independently blocks an off-turn digivolution. The clause is therefore redundantly enforced — the trigger keyword is not the only thing holding it.

## Remaining gaps

- No retained reds and no skips. No engine seam was hit.
- The clause has no printed once-per-turn cap, so repeated Option placements in one turn should each offer the digivolution. That repeat case is not tested: the second placement would need a second Option in hand and a legal further route from the level 5 the first placement produced, which no clean fixture in this set provides. Behaviour is unmodelled rather than known-wrong.
