# BT23-062 Dracmon — re-audit

## Card

Lv.3 Purple Rookie/Virus, DP 1000, play cost 3, digivolve cost 0 from Lv.2 Purple.
Types: `Undead`, `CS`.

Printed text (official card list, `docs/audits/BT23-reaudit/logs/official-bt23.html`):

| # | Clause |
| - | ------ |
| C1 | `[Digivolve] Lv.2 w/[CS] trait: Cost 0` |
| C2 | `[Start of Your Main Phase] By trashing 1 card with the [Undead], [Dark Animal] or [CS] trait from your hand, gain 1 memory.` |
| C3 | inherited: `[When Attacking] [Once Per Turn] 1 of your Digimon may digivolve into a Digimon card with the [Undead] or [Dark Animal] trait in the trash.` |

The catalog record matches the official card list field by field (colors, level, DP, cost,

## Rulings covered

| Q&A | Statement | Test |
| --- | --------- | ---- |
| Q5333 | A Digimon that attacks with BT23-062 in its digivolution cards and digivolves through BT23-062's inherited effect can **not** then activate its own — now inherited — `[When Attacking]` effect. | `does not activate the newly inherited When Attacking effect after digivolving mid-window (Q5333)` |

Rules basis: CR 15-16-5-1 (`[When Attacking]` triggers at the point of the attack
declaration), so a card that only gains the effect later never triggered at all.
CR 15-4-4-3/15-4-4-4 cover the neighbouring case where an already-pending effect is lost
because its card became a new card.

The Q5333 test isolates the ruling: BT24-069 Vilemon has an inherited (and only inherited)
`[When Attacking]` effect — "trash the top card of both players' decks" — with no upper
`[When Attacking]`. Dracmon's inherited effect turns Vilemon into a digivolution card
mid-window; the test asserts neither deck loses a card.

The companion test `still resolves its own inherited effect after the top card's When
Attacking digivolution` pins the neighbouring, legal case on Q5333's literal board
(BT23-063 Sangloupmon over BT23-062): both `[When Attacking]` effects trigger at the
declaration, Dracmon stays a digivolution card throughout, so **two** digivolutions happen
(Myotismon for 2, then SkullMammothmon for 4). This is not the ruling's case and the engine
handles it correctly; the test exists so a future "fix" cannot silently break it.

## Clause -> test -> IR map

| Clause | IR | Tests |
| ------ | -- | ----- |
| identity | catalog record | `matches every catalog field and printed text` |
| C1 | `digivolutionRequirement: [{ level: 2, traits: ["CS"], cost: 0, isAlternate: true }]` | `digivolves from a level 2 CS source of another colour for 0` (both `useAlternateCost` branches), `refuses a level 2 source that is neither purple nor CS` (both branches) |
| C2 | `StartOfYourMainPhase` -> `GainMemory 1`, mandatory `trash` cost, `abortOnDecline: true` | `compiles the main-phase clause as a mandatory trash cost, not an optional effect`; `gains 1 memory at the start of your own main phase by trashing a matching hand card`; `accepts %s as the %s trait cost` (Undead / Dark Animal / CS); `does not gain memory when no hand card carries a matching trait`; `stays silent on the opponent's main phase and fires again on your next turn` |
| C3 | inherited `WhenAttacking`, `frequency: "OncePerTurn"`, `Digivolve` `from: ["trash"]`, `payCost: true`, `optional: true` | `compiles the inherited clause as a once-per-turn optional trash digivolution`; `digivolves a carrier into an Undead card from the trash when attacking`; `leaves the board untouched when the optional inherited digivolution is declined`; `is once per turn and resets on your next turn`; the two Q5333 tests |

All behavioral tests drive public intents (`attack`, `digivolve`, `endPhase`, `surrender`)
through the real turn loop. No injected timing API is used; the previous suite's
`fireTiming(OnStartMainPhase)` calls are gone.

Notes on specific proofs:

- **C1 route.** The alternate route's cost (0) equals the printed purple Lv.2 route's cost,
  so memory cannot separate them. The discriminator used is colour: BT23-003 Motimon is
  **Black** with `[CS]`, so only the alternate clause makes it a legal source. Both
  `useAlternateCost` branches are pinned; both succeed at cost 0 and draw 1, because the
  clause is a legality route, not a cost reduction. BT1-005 Kyaromon (Yellow, no `[CS]`) is
  refused with `invalid-evolution` on both branches.
- **C1 fixture.** The source is placed in the **breeding area**. A Lv.2 permanent has no
  legal battle-area route, and the engine correctly refuses to digivolve one there — the
  previous suite asserted `{ ok: true }` on a battle-area Lv.2 source, which the engine
  returns while doing nothing at all (no stack change, no memory, card still in hand). That
  assertion proved nothing.
- **C2 turn boundary.** One test runs three main phases (yours, the opponent's, yours) and
  asserts the trash contents at each: one cost card spent on your first main phase, nothing
  on the opponent's, the second cost card spent on your next one.
- **C3 once per turn.** The same turn's second attack (after
  `advance.verb.unsuspend`) leaves the stack and memory untouched with a legal Lv.6 Undead
  card sitting in the trash; the next own turn's attack digivolves into it, so both the
  refusal and the reset are proved against real state, not an absence of errors.

## Defects found

1. **`// @ts-nocheck` on the module** — removed. The module typechecks without it, so type
   errors in this card's IR now surface (per the BT23-047 `duration:` lesson). The module has
   no `duration:` field, so nothing else needed checking. This is the only module change; the
   compiled IR itself is correct as written.
2. **Weak prior evidence** (fixed in the test file, not a product defect):
   - the main-phase clause was proved through the injected `fireTiming` seam;
   - the alternate digivolution "proof" asserted `{ ok: true }` on a battle-area Lv.2 source
     while the engine performed no digivolution at all;
   - no once-per-turn refusal/reset, no controller boundary, no decline branch, and no Q5333
     coverage existed.

No engine defect found. No retained red tests, no skips.

## Remaining gaps

- The alternate route's `cost: 0` is not distinguishable from the printed route's `cost: 0`
  by any observable. If a later engine change makes `useAlternateCost` a cost selector rather
  than a legality flag, this card cannot detect it.
- `[Once Per Turn]` is proved per source card on one carrier. Two separate Dracmon copies
  each granting their own use is not tested (no ruling asks for it).
