`[Sakuyamon]` (offset 112) and after `[Plug-In]` (offset 157), where the printed card has a
plain space. No edit made; the catalog test asserts the NBSP is present and that the text
matches the print once normalised, so the discrepancy is pinned rather than hidden.

Nothing else diverges: name, colours, kinds, cost, DP, `evoCosts: []`, `maxCountInDeck`,
`securityEffectText` all match the print.

## Clause -> test -> IR

- **Clause 1** -> `effects[0]` `OnPlay` / `RevealAdd { revealCount: 3, add: [Digimon
  name-substring, Option name-substring], rest: "deckBottom" }`.
  - Positive: a real `playCard` intent from hand pays 3 (memory 3 -> 0), the Tamer lands on
    the battle area, both hits reach the hand, and the single non-hit is the **last** card of
    the deck (asserted by instance id, behind the pre-existing bottom marker).
  - Near-miss (name): two Green Digimon carrying none of the four names and a Yellow Option
    without `[Plug-In]` ⇒ nothing added, all three at the bottom in reveal order.
  - Partial: only the Digimon hit present ⇒ exactly one card added, the Option near-miss
    returned.
  - The gates are `match: "name"` (substring), which is the printed `"in its name"` form. A
    `namesExact` gate here would be **wrong** — it would refuse `[Sakuyamon: Maid Mode]`. The
    IR test states this.
- **Clause 2** -> `effects[1]` `YourTurn` / `SubTrigger { event: "whenOptionUsed",
  fireCondition: { kind: "triggerOptionCostAtLeast", value: 2 } }` -> `GainMemory { amount: 1,
  cost: { kind: "suspend", target: { filter: { isSelfRef: true }, isSelf: true } },
  optional: true }`.
  - Threshold: a real cost-2 Option play (BT1-102) suspends the Tamer and gains 1; the cost-1
    peer (ST3-13) does neither. Both runs assert the exact memory arithmetic
    (`5 − cost + gain`) and the suspend flag.
  - Declined: with `autoDeclineOptional` the cost is not paid, memory is only `5 − 2 = 3` and
    the Tamer stays unsuspended.
  - Repeat within one turn: the Tamer is already suspended, so the second cost-2 Option in the
    same turn yields no memory; the opponent's whole turn passes through the real loop
    (`startTurnLoop` + `waitForMainPhase` + `endPhase`) and the Tamer stands back up at our own
    unsuspend phase, after which a third Option pays again.
  - `[Your Turn]` gate: seat 1 plays BT1-102 on its own turn (with its own yellow permanent for
    the colour requirement) and nothing fires; `state.memory` moves only by seat 1's payment.
  - `abortOnDecline: true` is present on the sole action of the effect and is therefore dead
    (brief's known trap for 008/016). Left untouched — removing it would churn the IR for no
    behavioural change.
- **Clause 3** -> `effects[2]` `Security` / `PlayWithoutCost { target: { isSelfRef: true },
  payCost: false }`, `isSecurity: true`.
  - Proved through a **real security check**: seat 0 attacks the player with a 3000 DP
    Monodramon, seat 1's top security card is BT19-083, and it arrives on seat 1's battle area
    with `state.memory` unchanged (no cost paid) and the rest of the security stack intact.
    Its own `[On Play]` also resolves off that play — both name hits reach seat 1's hand and
    the non-hit goes to seat 1's deck bottom.
