## Clause → test → IR

- **Clause 1** → `effects[0]` `OnDeletion` with two actions:
  - `GainKeyword` on `controller: "opponent", kind: ["Digimon"]`, `count: 1`,
    `keyword: { keyword: "SecurityAttack", amount: -1 }`,
    `duration: "untilOpponentTurnEnd"` — a real `EffectDurationRef`
    (`packages/shared/src/effects/ir/durations.ts:8`), so it cannot silently
    expire at the wrong boundary.
  - `SecurityManipulation` `op: "addTop"`, `controller: "mine"`,
    `source: "deck"`, `amount: 1`, gated by
    `condition: { kind: "zoneCount", seat: "mine", zone: "security", op: "lte", value: 2 }`.
  - Exactly-one target: with two opposing Digimon and one of the controller's own
    on the board, exactly one opposing Digimon ends at `-1` and the controller's
    own stays at `0`.
  - Threshold above: 3 security → no recovery, deck untouched (asserted by
    instance id).
  - Threshold at: 2 security → the deck's top card goes to the **top** of
    security (order asserted by instance id, `faceUp === false`), deck loses
    exactly that card.
  - Threshold at 0 security: recovery still fires; the deleted Airdramon is the
    only card in the trash.
  - Whole clause through the real turn loop: seat 0's Airdramon (4000 DP) attacks
    a suspended 4000 DP Liollmon, both die in the battle (CR §11-4), the
    [On Deletion] lands `-1` on the opponent's other Digimon and recovers one card
    (security order asserted by instance id). Seat 1's whole turn is then driven
    through the loop: the reduction is still present during seat 1's Main and is
    gone by seat 0's next Main — the "until the end of their turn" boundary
    proved at a real turn end, not by an injected `turnSeat`.
- **Clause 2** → `effects[1]` `trigger: "Static"`, `isInherited: true`,
  `keywords: [{ keyword: "Barrier" }]`.
  - Realistic stack: BT19-032 (Yellow Lv4) under BT19-037 Taomon (Yellow Lv5).
    Near-miss peer: the same Taomon over an inert Yellow Lv4 (BT3-032) instead —
    it has no ＜Barrier＞.
  - Rules consequence rather than a flag: a `byBattle` deletion raises the real
    `barrierPrompt`, the public `respondBarrier` intent accepts, `deletePermanent`
    returns 0, the host stays on the board, and the **top** security card moves to
    the trash (both asserted by instance id).
