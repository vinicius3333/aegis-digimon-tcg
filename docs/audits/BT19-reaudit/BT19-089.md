- Clause 1 -> `Static` / `WaiveColorRequirement` with
  `condition: { kind: "opponentHas", filter: { controllerDefault: "opponent",
  colors: ["White"], kind: ["Digimon", "Tamer"] } }`.
  - `refuses the play with no red permanent and no white opponent permanent`
    (`{ ok: false, reason: "color-requirement-unmet" }`, memory untouched at 3,
    the card still in hand).
  - `still refuses when the WHITE permanent is the caster's own` — the
    near-miss that separates `opponentHas` from a self-side count.
  - `waives the colour requirement while the opponent has a white DIGIMON, and
    charges the printed 2` (memory 3 -> 1, card in trash, no `actionRejected`).
  - `waives the colour requirement while the opponent has a white TAMER` — the
    other half of the `kind: ["Digimon", "Tamer"]` union.
  - `needs no waiver at all once the caster has a red permanent`.
- Clause 2 -> `Main` / two `Restrict` actions, `beAffected` with
  `fromSourceKind: ["Option"]` + `byOpponentEffectsOnly: true`, then `dpImmune`
  with `sameTarget: true`; both `duration: "untilOpponentTurnEnd"`.
  - `shrugs off an opponent OPTION that would reduce DP, while the untargeted

    BT2-097 in its real Main phase (the window the duration exists for). Peer

  - `blocks a NON-DP opponent Option effect: the chosen Digimon is not deleted`
    (BT2-091 Fire Wall) plus `CONTROL: the same Option deletes the chosen
    Digimon when Red Card is never played` — isolates `beAffected` from
    `dpImmune`.

    Starmons, a Digimon [On Play]) plus its CONTROL run (5000 -> 3000 without
    the grant) — isolates `dpImmune` from `beAffected`.
  - `CONTROL: the opponent Option reduction lands on BOTH Digimon when Red Card
    is never played`.
- Clause 3 -> `Security` / `AddToHandSelf`, `isSecurity: true`.
  - `reaches the defender's hand out of a real security check` — seat 0 attacks
    the player, the card lands in seat 1's hand (not the trash) and the rest of
    the security stack is unchanged.

## Defects fixed locally

- `BT19-089.ts`: removed `byOpponentEffectsOnly: true` from the `dpImmune`
  restriction. The printed clause qualifies only its first half ("the effects of
  your opponent's Option cards"); "and it can't have its DP reduced" carries no
  source qualifier, unlike BT11-069 and BT16-055, which print "by your
  opponent's effects" and are what that flag exists for
  (`interpreter/maps.ts:38`). Behaviour is unchanged either way — the DP seams
  (`modifiers.ts:414`, `primitives.ts:773`) call `hasRestriction` without
  `byOpponentEffect`, and only `beDeleted` is ever read with
  `{ byOpponentEffect: false }` — so this is a text-fidelity fix, proved
  correct by the non-Option reduction test. **The IR changed: `effects.json`
  needs a resync.**
- `BT19-089.test.ts` was rewritten. The previous single test reached into
  `s.engine.continuous.hasRestriction(...)` through a cast and asserted the
  ledger entry, never a rules consequence, and never touched the colour waiver,
  the [Security] clause or Q3158.

## Engine notes worth recording

- The two protections bite where the effect **lands**, not at targeting: the
  opponent still chooses the protected Digimon, and the DP modifier
  (`primitives.ts:773`) or the deletion is then dropped. Both protection tests
  are therefore paired with a control run that omits Red Card.
- Trap avoided: an opponent play whose cost drives their memory negative hands
  the turn straight back, and any "for the turn" value is expired before it can
  be read. BT5-035 (cost 3) is used instead of BT1-055 (cost 5) for exactly
  this reason.
- `settle` cannot be used to wait for these flows: every observable a predicate
  could name (the Option in the trash, the Digimon on the board) is already
  true before the [On Play] body resolves, so the tests drain the microtask
  queue and then read.

## Remaining gaps

- No test asserts the `untilOpponentTurnEnd` **expiry**. The behavioural half
  that matters — that the grant survives seat 0's turn end and is still live in
  seat 1's Main phase — is proved; observing the tick after that would need a
  third turn and adds no clause coverage.
