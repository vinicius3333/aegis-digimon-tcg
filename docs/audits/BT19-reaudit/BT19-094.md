## Defects fixed locally

1. `security: 1` (the forbidden numeric fixture form) is gone; every stack is an explicit list of
   inert main-deck Digimon, and no Digi-Egg is seeded in any deck or security stack.
2. `[Lucemon (X Antibody)]` and `[Lucemon]` both used `match: "name"` (substring). Both are
   bracketed exact references, changed to `"nameExact"`. The `[Security]` change is
   behaviourally load-bearing: under the substring form, "Lucemon: Chaos Mode" and
   "Lucemon (X Antibody)" would both be playable off it. The two near-miss tests are the proof.
3. The pre-existing test file was one behavioural test plus one IR snapshot; it is replaced with
   15 tests.

## Correction to the lane brief

The brief asked for "for the multicolour card acceptance with each single colour". That is not the
rule and not this engine's behaviour. CR 4-22-3: "An Option card with multiple colors can't be
used unless the color requirements are met for all of its colors"; CR 4-22-4 lets one multicolour
permanent satisfy several. Probed directly on this fixture:

| Board | Result |
| --- | --- |
| Blue only | `color-requirement-unmet` |
| Yellow only | `color-requirement-unmet` |
| Purple only | `color-requirement-unmet` |
| Yellow + Purple | `ok: true` |
| One Purple/Yellow permanent (BT18-082) | `ok: true` |

The tests assert this matrix.
