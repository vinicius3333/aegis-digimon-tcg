## Clause -> test -> IR

### Clause 1 — `[When Digivolving]` free `[Rika Nonaka]`

IR: `trigger: "WhenDigivolving"`, one `PlayWithoutCost` action, `from: ["hand"]`,
`payCost: false`, `optional: true`, `condition: permanentCount lte 1 over kind
["Tamer"]`, target `nameOrTrait [{ tokens: ["Rika Nonaka"], match: "nameExact" }]`.

- `digivolves from a yellow Lv3 for 2 memory, stacks the source, draws 1, and plays
  Rika free` — public `digivolve` intent from BT1-050 Liollmon (Yellow Lv3, inert).
  Endpoints: memory 3 -> 1 (the printed evolution cost of 2, and nothing for Rika),
  top card is the Kyubimon instance, `stack` is exactly `["BT1-050"]`, hand holds
  only the evolution bonus draw, BT19-083 is a second permanent.
- `only plays the exact [Rika Nonaka] and leaves the near-miss [Erika Mishima] in
  hand` — near-miss peer BT23-084 (a Tamer whose name contains "rika") stays in
  hand and never reaches the battle area.
- `does not play Rika while 2 Tamers are already out` — BT19-081 + BT17-085 seated;
  Rika stays in hand, board stays at 3 permanents, memory still 1.
- `leaves Rika in hand when the optional play is declined` — `autoDeclineOptional`.
- `refuses an illegal evolution source (red Lv3, and yellow Lv4)` — BT1-009
  (Red Lv3) and BT9-035 (Yellow Lv4) both return
  `{ ok: false, reason: "invalid-evolution" }`; memory and hand unchanged.

### Clause 2 — inherited `[Your Turn] [Once Per Turn]` Option watcher

IR: `trigger: "YourTurn"`, `isInherited: true`, `frequency: "OncePerTurn"`, a
`SubTrigger` on `whenOptionUsed` with
`fireCondition: { kind: "triggerOptionCostAtLeast", value: 2 }` and a `ModifyDP`
of -2000 for `duration: "forTheTurn"` against 1 opponent Digimon.

- `runs the inherited Option watcher from a real Lv3 -> Kyubimon -> Lv5 stack, once
  per turn` — the stack is BUILT by two public digivolve intents (BT1-050 ->
  BT19-034 -> BT1-057 Sirenmon) and asserted as `stack == ["BT1-050", "BT19-034"]`.
  Two BT1-102 (Yellow Option, cost 2) plays in the same turn: the pinned target
  goes 6000 -> 4000 once and the bystander stays at its printed 5000 both times.
- `resets the once-per-turn limit on the next own turn and never fires on the
  opponent's` — real `startTurnLoop()`: fires on turn 1, the debuff is gone during
  the opponent's Main (read inside the open phase, not after the loop), and fires
  again on the next own turn.
- Q5466 / Q5467 / Q5468 tests as tabled above.
- `does not fire for an Option resolving as a security effect on the opponent's
  turn (Q5465)` — the opponent attacks through the real loop, BT1-102 is checked
  from security, resolves, reaches the trash, and no DP moves.
