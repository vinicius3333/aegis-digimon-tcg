## Defects

No IR defect found. The three trap classes this set has been showing were checked and the
module was already right:

- The printed `[All Turns]` uses the `AllTurns` trigger, not `Static`.
- The would-leave replacement carries `sourceFilter: { isSelfRef: true }`, so it does not take
  the generic branch that protects every seat (`replacement.ts:238-241`, lane 13 / BT19-029).
- `[Lucemon] in its name` is correctly a substring `names` / `match: "name"` gate here, unlike a
  bare bracketed `[Name]` — BT19-043's route legitimately accepts [Lucemon: Chaos Mode].

Only the test file was rebuilt. The prior suite proved clause 3 through
`advance().fireForPermanent` (injected timing, no behavioural credit) and had no near-miss for
the deletion's controller filter or for the route's name/level gates. The module changed only by
exporting `compiled` for IR assertions and gaining two explanatory comments; its IR is
byte-identical, and `BT19-catalog-sync.test.ts` still passes for BT19-043.

No test is retained red; no engine gap was found.

## Remaining gaps

- The `[End of Your Turn]` clause's own `[Once Per Turn]` is structurally asserted but not
  behaviourally separated: nothing in the public intent surface fires a second end-of-your-turn
  window within one turn (the §6-6-4 postponement path would need a memory-manipulating peer
  card, which is out of this lane's edit scope).
- The prevention is exercised by a real battle loss and by the production `deletePermanent`
  verb. A "returned to hand / placed under" flavour of "would leave" is not separately asserted.
