## Clause -> test -> IR

Clause 1 -> `compiled.effects[0]`: `trigger: "OpponentsTurn"`, `isInherited: true`, one
`Aura` action with `target.filter: { isSelfRef: true }`, `isSelf: true`,
`effect: { kind: "keyword", keyword: { keyword: "Reboot" } }`, and
`while: { kind: "opponentHas", filter: { controllerDefault: "opponent", kind: ["Digimon"] } }`.

- `isSelf` / `isSelfRef` — "grants only its host ＜Reboot＞...": the host BT2-052
  Hagurumon has the keyword; a second own BT2-052 without the egg does not, and the
  opponent's own BT1-028 Elecmon does not.
- `trigger: "OpponentsTurn"` — same test (keyword absent on your turn) and, through the
  real turn loop, the two unsuspend tests below.
- `kind: ["Digimon"]` on the opponent side — same test: after the opponent's only
  Digimon is deleted, their remaining permanent is the Tamer BT1-088 Izzy Izumi and the
  keyword is gone. The battle-area contents are asserted by permanent id so the
  near-miss peer is provably still there.
- `keyword: "Reboot"` — proved by its printed §16-11-1 consequence, not just the flag:
  "actually unsuspends the host during the opponent's unsuspend phase, while a plain
  peer stays suspended". Through `engine.startTurnLoop()`, the host and an identical
  BT2-052 peer (both at 20 000 DP so they survive the security check) each attack the
  player on your turn; both are asserted suspended with `turnSeat` still 0; at the
  opponent's main phase the host is unsuspended and the peer is still suspended.
- `while` condition, negative — "leaves the host suspended through the opponent's turn
  when the opponent has no Digimon": the same flow with only the Tamer BT1-088 on the
  opponent's board leaves the host down and the keyword absent.

Both turn-loop tests keep a spare playable card (BT1-013) in hand so the Main phase
stays open after the attacks instead of auto-passing.

## Peer / stack proof

"carries ＜Reboot＞ through the real Digi-Egg route: hatch -> digivolve in breeding ->
battle area" exercises the full lifecycle through public intents only:

1. `hatchEgg` moves BT19-005 from the egg deck into breeding (egg deck emptied,
   breeding top card asserted).
2. `digivolve` puts the Black Lv3 BT2-052 Hagurumon onto the egg inside the breeding
   area (Black Lv2, cost 0); the egg instance id is the sole `breeding.stack` entry,
   BT2-052 has left the hand, and the battle area is still empty.
3. `moveFromBreeding` on the next own turn carries the stack into the battle area; top
   card and stack identity asserted again.
4. On your own main phase the carrier has no ＜Reboot＞; on the following opponent turn
   it does, while the opponent's own BT1-028 does not.

Near-miss peers: BT1-028 Elecmon (opponent Digimon that satisfies the condition but
gains nothing itself), BT1-088 Izzy Izumi (opponent permanent that is not a Digimon),
and a bare BT2-052 with no Hopmon under it (identical card, no keyword, stays
suspended).

## Defects

None in the module. The IR was correct on the single printed clause.

The **pre-existing test** is replaced. Its weaknesses:

- It only asserted `observe(...).hasKeyword(host, "Reboot")` — the keyword flag, never
  the §16-11-1 unsuspend that the keyword actually does. A keyword granted but never
  honoured by the unsuspend phase would have passed.
- Turn switching was done by writing `s.state.turnSeat` directly plus
  `advance().recompute()`, not through the turn loop.
- Its host BT19-056 Monodramon carries its own `[On Play]` deck-reveal effect and an
  `[All Turns] +1000 DP` inherited effect, and its opponent-side peer BT19-080 Takato
  Matsuki has a `[Start of Your Turn]` memory effect — noisy fixtures for a keyword
  assertion.
- No lifecycle: BT19-005 appeared only as a seeded `under:` entry.

No red tests retained. No engine gap found: the engine's own
`unsuspendRebootForSeat` (`apps/api/src/engine/GameEngine.ts:1720`) picks up the
granted keyword through `continuous.hasKeyword` exactly as the printed rule requires.

## Remaining gaps

- The clause is proved on a battle-area host. ＜Reboot＞ on a breeding-area permanent is
  a separate engine branch (`GameEngine.ts:1734`); no legal line puts a Hopmon-hosting
  stack in breeding during the opponent's unsuspend phase in a way this card's text
  distinguishes, so it is not asserted here.
