## Fixture and method defects fixed locally (test only)

1. **Digi-Egg in security.** The When-Attacking test seeded
   `security: ["BT1-001"]`; BT1-001 is a Digi-Egg and can never legally sit in
   a security stack. Replaced with the inert main-deck Digimon BT1-009.
2. **Numeric `security: <n>` form.** The Overclock test used
   `1: { security: 2 }`. Replaced with an explicit two-card inert stack so the
   security check has a real, non-zero-DP card.
3. **Injected turn state.** The `[All Turns]` immunity test set
   `s.state.turnSeat = 1` directly and then played the opponent's Suspend
   card. Replaced with the real turn loop
   (`s.engine.startTurnLoop()` -> `waitForMainPhase(0)` -> `endMainPhaseIfOpen(0)`
   -> `waitForMainPhase(1)` -> play -> `surrender` -> `await loop`).
4. **Vacuous suspension assertion.** After `settle`, the turn had already
   passed back to seat 0 and seat 0's unsuspend phase had stood every
   permanent up, so `expect(isSuspended).toBe(false)` was true regardless of
   the protection. Confirmed by a scratch run: an *unprotected* peer also read
   `false` after `settle`. Both the protected and the control run now snapshot
   `isSuspended` through the `onEvent` hook at `effectResolved` for BT1-070,
   i.e. inside the opponent's open turn.
5. **No control for the protection.** Per the lane-38 finding, protections
   apply where the effect lands, not at targeting. Added the control run where
   BT1-070's Suspend does hit an unprotected BT1-009, and the stack run where a
   Zeed *with* a digivolution card underneath is suspended and is no longer
   `beAffected`-restricted.
6. **Evolution route proved only by `{ok:true}`.** The alternate route now
   asserts the memory delta is exactly 2 (not the printed Lv6 evoCost of 6 —
   the lane-9 silent-fallback trap), the digivolution draw of 1, and the source
   stack identity by instance id. Added a real illegal source: BT18-019
   *Millenniummon* (a genuinely near-miss printed name) is refused with memory
   and hand unchanged.
7. **Exact endpoints.** Every return assertion now pins the opponent's deck
   order by *instance id* (cost card on top, sentinel, returned battle-area
   Digimon at the bottom) instead of by card id, and asserts the trash is
   emptied and no decision is pending.

## Route naming check (lane 31 follow-up)

`digivolutionRequirement` already uses `namesExact: ["MoonMillenniummon"]`, so
this card is not affected by the substring defect lane 31 found on BT19-075.
No printed card other than BT19-075 contains the substring
"MoonMillenniummon", so only a synthetic definition
("MoonMillenniummon (Variant)") can separate `namesExact` from a substring
`names` gate; the test asserts both the reject and the exact-name accept.

Two notes on the module, deliberately left alone:

- `abortOnDecline: true` is present on each of the three `Return` actions.
  Each is the sole action of its effect, so per the standing finding (lanes 4,
  8, 17 — cards 008/016) the flag is dead. Behaviourally confirmed: the decline
  run leaves the trash, deck and battle area untouched, which is what the
  optional cost alone already produces. Not removed, to avoid churning the IR
  and forcing a resync for a no-op.
- `trigger: "Static"` carries the ＜Overclock＞ keyword marker. This is a
  keyword marker, not a printed `[All Turns]` clause, so the
  `Static`-vs-`AllTurns` trap does not apply; the printed `[All Turns]` clause
  is correctly on an `AllTurns` effect.
