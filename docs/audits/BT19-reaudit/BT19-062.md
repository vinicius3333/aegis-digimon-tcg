## Defects

**Fixed locally — substring name gate on an exact printed route.** The module compiled
`[Digivolve][Strikedramon]` to `names: ["Strikedramon"]`. `names` is the SUBSTRING gate
(`apps/api/src/engine/cards/cardData.ts:483-486`, "[X] in name"); a bracketed `[Name]` route is
the exact gate `namesExact` (`cardData.ts:490-494`, which additionally reads only the exact
alias channel, so a "treated as having [X] in its name" card is refused). Changed to
`namesExact: ["Strikedramon"]`.

No card currently in the catalog carries "Strikedramon" as a proper substring of its name or as
a name alias, so the fix is not falsifiable by a fixture today; it is required by the printing's
semantics and by the same trap already fixed on BT19-012 (whose `[Digivolve][Shoutmon]` route is
`namesExact` and whose near-miss, Shoutmon X4, exists). The test pins the compiled shape and
proves the three real Strikedramon printings still take the Cost 3 route while Black Lv.4 and
Red Lv.4 peers do not.

**IR CHANGED — `packages/shared/src/effects/effects.json` is now stale for BT19-062** (its
persisted record still holds `names`). `BT19-catalog-sync.test.ts` will fail for this card until
the coordinator resyncs.

The pre-existing test asserted the IR shape and two behaviours; it did not prove ＜Rush＞,
either ＜Collision＞, the mandatory-ness of the Option trash, the controller scoping, the
digivolve routes, or Q3121/Q3123 at all.
