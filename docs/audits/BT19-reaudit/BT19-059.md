## Clause -> test -> IR

- Clause 1 -> `effects[0]`: `Static` with `keywords: [{ keyword: "Retaliation" }]`.
  A bare printed keyword, not an `[All Turns]` clause, so `Static` is right.
  - Proof by rules consequence: a 5000 DP attacker attacks the suspended
    DeadlyAxemon. It loses the battle and is deleted, and §16-13 takes the attacker
    with it. Endpoints: both battle areas empty, DeadlyAxemon's instance id is the
    only card in seat 1's trash, seat 0's trash holds exactly the attacker card, and
    seat 1's security is untouched (a permanent-target attack does not check
    security).
  - Negative control: an identical 4000 DP peer (BT1-014 Kokatorimon) in the same
    position leaves the attacker alive and seat 0's trash empty.
- Clause 2 -> `effects[1]`: `OnDeletion`, `keywords: [{ keyword: "Save" }]`,
  `PlaceUnder` with `underFilter { controller: "mine", kind: ["Tamer"],
  excludeToken: true }`, `optional: true`. With the keyword present,
  `withSavePlacementDefaults` applies and the card lands at the BOTTOM (CR 4-3-2).
  - Positive: the resulting Tamer stack is `[self, pre-existing]` by instance id, the
    card is not in the trash, and an opponent-controlled Tamer (BT19-083) on the same
    board stays empty — the `controller: "mine"` gate.
  - Decline: the card is in the trash and the Tamer stack is empty.
- Clause 3 -> `effects[2]`: `Static`, `isInherited: true`, `keywords: [{ keyword:
  "Reboot" }]`. `interpreter/effect.ts:636-643` treats this as the Reboot marker and
  grants the keyword permanently; the engine consumes it in
  `GameEngine.unsuspendRebootForSeat`.
  - Realistic stack case through the real turn loop: two identical BT1-014
    permanents on seat 0, one carrying a BT19-059 digivolution card. Both are
    suspended the real way — by attacking on their controller's turn — then
    `startTurnLoop()` + `endMainPhaseIfOpen(0)` + `waitForMainPhase(1)` reaches seat
    1's genuine unsuspend phase. Only the host stands back up; the bare twin stays
    suspended. No `turnSeat` write, no injected unsuspend.
- Evolution routes -> the printed evo costs. Black Lv.3 (BT2-052) and Purple Lv.3
  (BT2-067) both cost exactly 3 (9 -> 6 -> 3) with the base's instance id as the
  single stack entry and the two bonus draws visible in hand and deck; Green Lv.3
  (BT1-064) is refused on both the plain and the `useAlternateCost: true` intent.

The only Advance-Surface uses are `advance().verb.deletePermanent(..., "byEffect")`
for the ＜Save＞ tests and the turn-loop helpers `waitForMainPhase` /
`endMainPhaseIfOpen`. No `fire` / `fireTiming` / `fireSubTrigger`. Fixtures carry no
Digi-Egg and no numeric `security: <n>`.

### Testkit note recorded during this lane

In the ＜Reboot＞ test, seat 0's Main auto-passes as soon as its last legal action is
spent, and the turn hand-over happens inside the very `settle` that observes the final
suspension — so reading `isSuspended` after that settle sees the post-unsuspend value
and proves nothing. The test therefore samples the mid-turn state through the
`onEvent` hook while `state.turnSeat === 0`, the same technique
`BT17-033.test.ts` uses for a during-battle DP value. This is the same class of trap
as the brief's "Start-of-Main tests that read memory only after `runTurn` completes".
