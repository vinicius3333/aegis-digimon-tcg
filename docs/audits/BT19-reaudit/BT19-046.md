## Clause -> test -> IR

- `compiled.effects[0]` (`OnPlay`) and `compiled.effects[1]` (`WhenDigivolving`) carry the same
  two ordered actions, asserted in a loop:
  1. `Suspend`, count 1, filter `{ controller: "opponent", kind: ["Digimon"] }` — no
     `suspended` key anywhere in the compiled card.
  2. `Restrict`, `restriction: "unsuspend"`, `duration: "untilOpponentTurnEnd"`, count 1,
     filter `controller: "opponent"`, `kind: ["Digimon"]`,
     `nameOrTrait: [{ tokens: ["Data"], match: "trait" }]`. `[Data]` is an attribute, which
     `cardData.staticTraitsOf` folds into traits, so `match: "trait"` (exact token) is right.
  `untilOpponentTurnEnd` is a real `EffectDurationRef` and is proved to expire at that boundary
  rather than silently at the next turn end.
- `[On Play]`: public `playCard` intent inside a real `startTurnLoop` main phase. Endpoints:
  memory 4 -> 0, card gone from hand, played permanent unsuspended with an empty stack, the
  scripted [Data] target both suspended and restricted, and three peers untouched — a second
  [Data] Digimon (BT1-028 Elecmon), a Vaccine (BT1-009) and a Virus (BT1-045). The near misses
  prove the attribute filter is exact and the counts are 1, not "all".
- Restriction consequence, not just the ledger flag: across three real turns the restricted
  BT1-013 stays suspended through seat 1's own unsuspend phase while an unrestricted suspended
  [Data] control (BT1-028, seeded `suspended: true`) stands up in the same phase. The
  restriction is gone once seat 1's turn ends, and the Digimon is still suspended on our next
  turn. Turn changes are driven by `waitForMainPhase` / `endPhase`, never by writing
  `state.turnSeat`.
- Q845: with `preferInstanceIds` scripted onto the already-suspended peer, that peer takes the
  suspension and the fresh peer stays unsuspended and unrestricted. This is the assertion the
  removed `suspended: false` filter used to fail.
- Independence of the two halves: with no [Data] Digimon at all, the suspension still lands and
  nothing is restricted; with no opponent Digimon at all, the play still resolves (memory 0,
  one permanent on our board) and nothing errors.
- `[When Digivolving]`: public `digivolve` intent from BT1-067 Palmon (Green Lv3) inside a real
  main phase — memory 5 -> 3 (printed cost 2), the source retained as the only digivolution
  card, the card gone from hand, the suspension steered onto the Vaccine peer while the
  restriction still lands only on the [Data] peer (proving the two filters are independent).
  Illegal source: BT1-010 Agumon (Red Lv3) refused on both the normal and the
  `useAlternateCost: true` intent, with board, hand, memory and the opponent's board unchanged.
- Stack case: Chamblemon has no inherited effect, so under a realistic stack
  (Palmon -> Chamblemon -> BT19-052 Vespamon) a real attack by the host suspends nothing and
  restricts nothing while still checking one security card. `inheritedEffectText` is asserted
  `undefined` in the catalog test.

the ruling. Same decision as the coordinator's ruling for BT19-044 / BT19-038.
