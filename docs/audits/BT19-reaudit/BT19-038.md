## Defects found and fixed (both in `BT19-038.ts`, both change the IR)

1. **`suspended: false` on both Suspend targets (introduced by the prior audit).**
   The printed text is "Suspend 1 of your opponent's Digimon" with no "unsuspended"
   qualifier, and selection is never gated on whether the action will change
   anything — comprehensive §15-15-5-1 explicitly chooses a card that cannot even be
   affected for this exact effect ("Even if a card that isn't affected by effects is
   chosen for an '[On Play] Suspend 1 of your opponent's Digimon' effect, it isn't
   suspended"). The filter removed an already-suspended Digimon from the candidate
   set, which is a rules error and also a strategic one (the controller may want to
   spend the choice on the suspended Digimon and leave the fresh one alone).
   Proof: `may choose an ALREADY suspended Digimon for the suspension` asserts the
   already-suspended permanent is IN the offered candidate set and that picking it
   leaves the unsuspended peer untouched. Under the old IR the candidate set excludes
   it and the test fails.

2. **`grant: "nameForDigiXros"` made the printed alias dead.** `grantStatic.ts:49`
   accepts both spellings for the board-side ledger, but the DigiXros MATERIAL check
   reads `digiXrosOnlyNameAliasesFor` (`interpreter/compiledCards.ts:46-57`), which
   only recognises `grant: "name"` + `digiXrosOnly: true` — the BT19-012 form. With
   the old IR, DigiXrosing BT19-010 with BT19-038 in the [Dorulumon] slot is refused
   `invalid-material`, i.e. the card's second printed line did nothing. Switched to
   the BT19-012 form; behaviour is otherwise identical (`grantStatic.ts` routes both
   to `grantNameTrait(..., { digiXrosOnly: true })`).

Not changed, deliberately: the two `Restrict` targets keep `controllerDefault:
"opponent"` rather than `controller: "opponent"`. `matching/permanent.ts:149` reads
`filter.controller ?? filter.controllerDefault`, so the seat scope is enforced either
way; the test proves it instead of churning the IR — both recorded candidate sets are
asserted to exclude my own Digimon.
