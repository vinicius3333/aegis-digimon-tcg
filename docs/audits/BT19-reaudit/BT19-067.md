## Clause -> test -> IR

- Clause 1 -> `effects[0]`: `OnPlay` / `PlayWithoutCost`,
  `target.filter { controller: "mine", kind: ["Tamer"], colors: ["Purple"],
  playCostLte: 4 }`, `from: ["trash"]`, `payCost: false`,
  `condition { kind: "permanentCount", seat: "mine", op: "lte", value: 1,
  filter: { kind: ["Tamer"] } }`, `optional: true`.
  The trash zone is a LOOSE-card matcher, which reads the scalar `playCostLte` key;
  the object `playCost: { op, value }` form is silently dropped there (brief trap,
  lane 6 / BT19-013; `interpreter/matching/definition.ts:148-157`). The IR uses the
  scalar form, which is correct — and the boundary test proves it is actually read.
  - Positive, 0 Tamers: a public `playCard` intent for 4 memory (10 -> 6) puts
    BT18-093 Violet Inboots (Purple Tamer, play cost 4 — the exact boundary) on the
    battle area as a fresh permanent with an empty stack; it is gone from the trash
    by instance id and the board is exactly Impmon + the Tamer. No `actionRejected`.
  - Boundary on the condition, exactly 1 Tamer: "1 or fewer" still fires; the board
    ends with Impmon plus both Tamers, memory 6.
  - Negative, 2 Tamers: nothing is played, the Violet copy stays in trash by
    instance id, the battle area still has 3 permanents, memory 6.
  - Near-miss peers in the trash: BT11-094 Mirei Mikagura (Purple Tamer, play cost 5
    — over the cap) and ST1-12 Tai Kamiya (play cost 2 but RED). Neither is played;
    both trash instance ids are asserted still present and the board is Impmon alone.
  - Decline (`autoDeclineOptional`): the Tamer stays in the trash, board is Impmon
    alone, memory 6.
- Clause 2 -> `effects[1]`: `Static`, `isInherited: true`,
  `keywords: [{ keyword: "Retaliation" }]`. `Static` is correct — the printed line is
  a bare keyword with no `[All Turns]` bracket, so that trap does not apply.
  - Keyword grant proved by its rules consequence, not a test-only flag, and on a
    realistic stack: two identical 3000 DP BT1-009 permanents, one carrying a
    BT19-067 digivolution card. The carrier reads ＜Retaliation＞ and the bare twin
    does not. The carrier attacks a suspended 5000 DP wall, loses the battle, and
    ＜Retaliation＞ takes the winning defender with it (seat 1 drops from 2 to 1
    permanent). Control in the same test: the bare twin attacks the second identical
    5000 DP wall, dies, and THAT wall survives by permanent id.
- Evolution routes -> the single printed evo cost. A breeding BT2-007 Pagumon
  (Purple Lv.2) digivolves for exactly 0 (memory 5 -> 5) with the egg instance id as
  the single stack entry and the bonus draw in hand. BT1-007 Tanemon (Green Lv.2) is
  refused on both the plain and the `useAlternateCost: true` intent, with hand,
  memory and the base's top card unchanged.

Every behavioural test uses public intents (`playCard`, `digivolve`, `attack`) —
this card needs no opponent turn, so no turn loop was required. No Advance-Surface
verb, no injected timing, no `turnSeat` write. Fixtures use inert main-deck Digimon
in deck and security; the only Digi-Eggs are the breeding evolution sources, never in
deck or security, and no numeric `security: <n>` form is used.

## Remaining gaps

- The play-cost cap is proved at 4 (accepted) and 5 (rejected). "Without paying the
  cost" is proved only by the memory endpoint (exactly Impmon's own 4 moved); a
  positive case where the Tamer's own cost would have been unaffordable would sharpen
  it further.
- The Tamer count is proved at 0, 1 and 2. Whether the condition is evaluated before
  or after Impmon itself lands is not isolated — Impmon is a Digimon, so it cannot
  change a Tamer count either way.
- ＜Retaliation＞ is proved on the attacking side (the carrier attacks and dies).
  The defending side (the carrier is attacked on the opponent's turn and dies) uses
  the same keyword seam and is not separately exercised.
