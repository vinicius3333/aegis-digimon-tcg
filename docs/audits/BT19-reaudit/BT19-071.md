Evidence notes:

- The once-per-turn test drives two mills in one turn from two different sources (this card's
  own `[When Digivolving]`, then a played `P-017` whose `[On Play]` trashes the top 2). With the
  gate honoured, three opponent Lv5 Digimon lose exactly one on the first mill and none on the
  second; the next own turn's mill deletes again. Without the gate the second mill would have
  deleted a second Digimon.
- The ＜Blocker＞ duration is read inside three real Main phases opened by `startTurnLoop()` +
  `waitForMainPhase`, not by injected timing.
- The digivolution test asserts the source-stack identity by instance id
  (`BT3-076 / BT3-083 / BT3-085`, seeded base last), the memory delta 3, and the digivolution
  draw landing before the two milled cards.
- Peer/stack coverage: an own Lv5 and an opponent Lv6 sit on the board during the delete; the
  digivolution runs off a three-card realistic stack.
