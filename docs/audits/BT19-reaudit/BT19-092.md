## Clause -> test -> IR

- **Clause 1, upgraded branch** -> `effects[0].actions[0]`:
  `Return { to: "deckBottom", bindResultAs: "upgraded", optional: true,
  target.filter { controller: opponent, kind: [Digimon], levelComparison lte 6 },
  cost: { kind: "return", to: "deckBottom", target.filter { controller: mine,
  kind: [Digimon], colors: [Blue] } } }`.
  `optional: true` is required by CR 15-7-4 ("by <paying>" is the controller's
  choice); `abortOnDecline` is left `false` because the base clause must still run.
  - Endpoints: with a blue Tamer (colour requirement) and BT1-038 Monzaemon (the
    payer) against BT1-080 Titamon (Lv.6), the play charges 5 (memory 8 -> 3),
    Monzaemon's instance id ends at the bottom of **seat 0's** deck and is not in
    hand, Titamon's instance id ends at the bottom of **seat 1's** deck, and both
    battle areas hold only the Tamer / nothing.
- **Clause 1, base branch** -> `effects[0].actions[1]`:
  `Return { to: "deckBottom", target.filter { controller: opponent,
  kind: [Digimon], levelComparison lte 4 }, condition: bindingEmpty("upgraded") }`.
  - Endpoints: with only a blue **Tamer** on the caster's board (no blue Digimon,
    so the cost has no payer), BT1-014 (Lv.4) is bottom-decked by instance id and
    BT1-020 (Lv.5) is untouched; with only a Lv.5 opposite, nothing is returned.
  - `instead`, not "in addition": with both a Lv.4 and a Lv.6 opposite and a legal
    payer, exactly one opposing Digimon leaves and the opponent's deck grows by one.
  - Declining the optional cost (`autoDeclineOptional`) leaves the caster's blue
    Digimon on the board, leaves the Lv.6 alone, and takes the Lv.4 instead — the
    `bindingEmpty` fallback working through a real decision.
- **Clause 2 ([Security])** -> `effects[1]`: `ActivateMain`, `isSecurity: true`.
  - Proven through a real security check: seat 0 attacks at `{ kind: "player" }`
    into a stack topped by BT19-092. Seat 1 is "you", so seat 0 is "your opponent":
    seat 0's Lv.4 BT1-014 is bottom-decked by instance id while the Lv.5 attacker
    stays. Seat 1 has no blue Digimon, so only the base clause could resolve.

## Defects fixed locally

1. `apps/api/src/cards/BT19/BT19-092.ts` — the return **cost** carried no `to`.
   The permanent branch of `case "return"` in
   `apps/api/src/engine/effects/interpreter/costs.ts` (around line 1533) only
   bottom-decks on an explicit `cost.to === "deckBottom"` and otherwise falls
   through to `returnToHand`. The card printed "By returning 1 of your blue Digimon
   **to the bottom of the deck**", but the engine put the payer back in the
   caster's hand — a strictly better cost. Added `to: "deckBottom"`.
   (The `raw` string's "to the bottom of the deck" is only consulted by the
   *loose-card* branches via `returnToTop`, never by the permanent branch.)
2. `apps/api/src/cards/BT19/BT19-092.test.ts` — the previous file had one
   behavioural test that asserted only "the opponent's board is empty" and one IR
   snapshot; it covered neither branch separately, neither destination, nor Q3165.

No retained reds; no `it.fails` / `it.skip`.
