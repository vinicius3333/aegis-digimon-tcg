## Defect fixed locally

`sourceFilter` had no self-gate. `interpreter/actions/replacement.ts:238-241`
computes `protectsSelf` from `target.isSelf` / `filter.isSelfRef`; with neither
present the reaction installs with `protectsSelf === false` and falls to the
generic branch, which gates only on `protectsFilter.controller` — undefined here
(only `controllerDefault` was set). The clause therefore protected EVERY yellow
[Data]/[Witchelny] Digimon on either seat, contradicting Q3087. Adding
`isSelfRef: true` restores the printed "this Digimon" scope.

Verified load-bearing: with the line commented out, the Q3087 test fails
(`settle` never sees the sibling leave the board).
