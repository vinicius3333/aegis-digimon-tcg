## Clause -> test -> IR

- Clause 1 -> `effects[0]`: `WhenDigivolving` / `PlayWithoutCost`,
  `target.filter { controller: "mine", nameOrTrait: [{ tokens: ["Ryo Akiyama"],
  match: "nameExact" }] }`, `from: ["hand"]`, `payCost: false`,
  `condition { kind: "permanentCount", seat: "mine", op: "lte", value: 1,
  filter: { kind: ["Tamer"] } }`, `optional: true`.
  The bracketed `[Ryo Akiyama]` is an exact-name reference and the IR uses
  `nameExact`, not the substring `match: "name"` trap. `optional: true` is the
  printed "you may".
  - Positive, 0 Tamers: a public `digivolve` intent onto a Black Lv.3 base. BT19-086
    Ryo Akiyama enters the battle area as a fresh permanent with an empty stack,
    memory moves 6 -> 4 (the digivolve cost of 2 only — the Tamer was free), the base
    permanent's stack is exactly the base instance id, the hand holds only the
    digivolve draw, and no `actionRejected` event was emitted.
  - Boundary, exactly 1 Tamer: "1 or fewer" still fires; the board ends with
    Strikedramon plus both Tamers and memory 4.
  - Negative, 2 Tamers: nothing is played, the Ryo copy stays in hand by instance id,
    the battle area still has 3 permanents, memory 4.
  - Near-miss peer for the exact-name gate: the hand instead holds BT19-083 Rika
    Nonaka — also a Tamer, wrong name. Nothing is played, the card stays in hand.
  - Decline (`autoDeclineOptional`): the Ryo copy stays in hand, board is
    Strikedramon alone, memory 4.
- Clause 2 -> `effects[1]`: `AllTurns`, `isInherited: true`, `ModifyDP` amount 1000
  with `duration: "permanent"`, targeting `isSelfRef` + `isSelf: true`. The printed
  `[All Turns]` compiles to `AllTurns`, not `Static` — the trap named in the brief is
  not present here.
  - Realistic stack case through the real turn loop: two identical BT1-014
    permanents (4000 DP printed), one carrying a BT19-060 digivolution card. Inside

    `endMainPhaseIfOpen(0)` + `waitForMainPhase(1)` the same values hold on seat 1's
    turn, which is what makes it `[All Turns]` rather than `[Your Turn]`. No
    `turnSeat` write.
