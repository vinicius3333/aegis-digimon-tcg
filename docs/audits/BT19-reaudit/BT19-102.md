## Card summary

`Vaccine`, types `[Composite]` / `[Xros Heart]`, rarity UR, max 4. `evoCosts` lists all seven

Printed clauses:

1. `[Digivolve][Luminamon]: Cost 2` — exact-name alternate route.
2. `[Digivolve][Nene Amano] w/ [Shademon] under: Cost 3` — exact-name alternate route with a
   stack requirement.
3. `[On Play] [When Digivolving] Choose 1 other Digimon. By playing level 4 or lower Digimon
   card from it's digivolution cards, delete the chosen Digimon.`
4. `[On Deletion] You may play 1 card with a play cost of 5 or less from under any of your
   Tamers without paying the cost.`
5. `[DigiXros -1] [Nene Amano] x [Luminamon] or [Shademon]`

## Clause -> test -> IR

- **Clauses 1 and 2** -> `compiled.digivolutionRequirement`:
  `[{ namesExact: ["Luminamon"], cost: 2, isAlternate: true },
    { namesExact: ["Nene Amano"], minNameStackNames: ["Shademon"], minNameStackCount: 1,
      cost: 3, isAlternate: true }]`.
  A printed `[Digivolve][Name]` route is the EXACT gate (`namesExact`), never the substring
  `names:` form (lane 5's BT19-012 trap).
  - Route 1 positive: BT19-076 Luminamon base, `alternateRequirementIndex: 0`, memory 2 -> 0,
    the exact base **instance id** is the single digivolution card, DP 6000, and the
    digivolution bonus draw moved the recorded top-of-deck instance into hand.
  - Route 2 positive: BT19-087 Nene Amano with BT19-068 Shademon under her,
    `alternateRequirementIndex: 1`, memory 3 -> 0, stack `[BT19-068, BT19-087]` bottom-first.
  - Route 2 negative: the same Nene without Shademon under -> `invalid-evolution`.
  - Ordinary route discriminator: off BT19-068 (Lv.4) with no
    `alternateRequirementIndex`, memory 4 -> 0. This is what stops `{ok:true}` alone from
    proving an alternate route: 2, 3 and 4 memory are three distinct outcomes.
  - Illegal source: a copy of BT19-102 itself ("Luminamon (Nene Version)" *contains*
    "Luminamon") is refused on route 1; EX10-064 "Yuu Amano & Nene Amano" (a name containing
    "Nene Amano", with no "also treated as" line) is refused on route 2.
- **Clause 3** -> `effects[0]` (`OnPlay`) and `effects[1]` (`WhenDigivolving`), identical
  bodies:
  - `SelectBind` on `{ controller: "any", kind: ["Digimon"], excludeSelf: true }`,
    `bindAs: "chosenHost"`. `controller: "any"` is Q3186; `excludeSelf` is the printed
    "other".
  - `Delete` with `target.fromSelectionRef: "chosenHost"` and
    `cost.kind: "playFromDigivolutionCards"` whose `hostTarget.fromSelectionRef` is the SAME
    binding. This is the point the prior audit made and it holds: without the shared binding
    each action would re-choose, and the printed clause deletes the Digimon whose sources paid.
    `optional: true` on the Delete is required by comprehensive 15-7-4 — a "by doing X"
    condition is the controller's choice.
  - Positive (opponent host): BT1-012 Biyomon with BT1-009 Monodramon under it. Endpoints:
    Monodramon is a permanent on the opponent's board, Biyomon's top card is the **only** card
    in the opponent's trash, an identical BT1-013 bystander is untouched, memory 6 -> 0
    (the printed play cost), no pending decision.
  - Positive (own host): same shape on seat 0's own board.
  - `other` proof: with BT19-102 as the only Digimon anywhere, the clause is silent — it does
    not choose and delete itself; board `["BT19-102"]`, trash empty.
  - Cost near-miss: a host whose only digivolution card is BT1-024 (Lv.5) cannot pay the
    "level 4 or lower" cost, so the deletion it gates never happens — host permanent id and
    stack instance id unchanged, trash empty.
  - Decline branch: `autoDeclineOptional` raises the prompt and leaves host and source intact.
  - `[When Digivolving]` half proved on a real evolution stack: digivolve BT19-102 onto
    BT19-076 via route 1, then the clause fires from the freshly digivolved permanent (its own
    stack still `[BT19-076 instance]`) and deletes the opponent's bound Biyomon.
- **Clause 4** -> `effects[2]` (`OnDeletion`): `PlayWithoutCost` from `["underTamers"]`,
  `payCost: false`, `optional: true`, filter `{ controller: "mine", playCostLte: 5,
  zone: "underTamers" }`. Two details verified rather than assumed: the printed "1 **card**"
  carries no `kind` gate (a Tamer or Option under a Tamer qualifies), and the scalar
  `playCostLte` is the form loose-card matching reads — the object
  `playCost: { op, value }` form is silently dropped for loose cards
  (`interpreter/matching/definition.ts:148-157`, lane 6's BT19-013 trap).
  - Positive through a **real battle deletion**: seat 0 (turn player) attacks the suspended
    BT19-102 with a 10000 DP MetalTyrannomon; the 6000 DP Digimon loses, its `[On Deletion]`
    fires, and the BT1-009 under seat 1's Nene Amano is played free. Endpoints: the victim's
    permanent id is gone, BT19-102 is in the trash, the Tamer's stack is empty, memory
    unchanged.
  - Double near-miss in one run: BT1-024 (play cost 7) under **our** Tamer is over the
    ceiling, and an eligible BT1-009 under the **opponent's** Tamer is not ours to play.
    Both stay under their own Tamers and our board is just the Tamer afterwards.
  - Decline branch asserted separately.
- **Clause 5** -> `compiled.digiXrosRequirement`
  `[{ materials: [{ names: ["Nene Amano"] }, { names: ["Luminamon","Shademon"] }], count: 1 }]`.
  - Positive for **both** second materials (BT19-068 and BT19-076): both materials become the
    played Digimon's digivolution cards (asserted by instance id) and memory drops by 4, not 6.
    Comprehensive 7-2-2-1 / 7-2-3-3: `[DigiXros -1]` reduces the play cost by 1 **for each
    card placed**, so two materials turn the printed 6 into 4. (The prior test asserted a
    bare `memory === 0` from a starting 4 and could not tell 4 from 5 or 6.)
  - Near-miss materials: EX10-064 in the `[Nene Amano]` slot and a second BT19-102 in the
    `[Luminamon] or [Shademon]` slot are both rejected as `invalid-material`.

## Defects fixed locally (test-side only)

- The `[On Deletion]` test used to set `s.state.turnSeat = 1` directly — injected state, the
  lane-15/BT19-015 trap. Replaced: the card's controller is seated as seat 1 and seat 0
  attacks on its own real turn, so the deletion comes out of a genuine battle.
- No seat had a security stack, so several digivolve fixtures were one intent away from the
  security win check. Every board now seeds inert security and deck padding
  (BT1-009 / BT1-013 only — no Digi-Eggs in either zone).
- The DigiXros memory assertion was uninformative (see clause 5).
- Added the missing catalog test, the `[When Digivolving]` behavioural half, the own-Digimon
  Q3186 branch, the `other`/`excludeSelf` proof, the level-4 cost near-miss, the ordinary
  4-memory route discriminator, and both `[On Deletion]` near-misses.
