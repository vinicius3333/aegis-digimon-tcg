## Clause -> test -> IR

- Clause 1 -> `compiled.digivolutionRequirement`
  `[{ level: 2, traits: ["Twilight", "Xros Heart"], cost: 0, isAlternate: true }]`.
  `matchGatedRequirement` (`apps/api/src/engine/cards/cardData.ts`) treats `traits`
  as "base has at least one", which is the printed `w/[A]/[B] trait` semantics, and
  `level` as an exact gate.
  - Positive, on-colour: BT10-005 Monimon (Black Lv.2, Twilight + Xros Heart) in
    breeding, memory 0 before and after — the printed Black Lv.2 route would have
    cost 1, so the memory delta is what names the route.
  - Positive, off-colour: BT10-003 Pickmons (Yellow Lv.2, Xros Heart) — Yellow is
    neither printed evo colour, so only the trait route can legalize the source;
    memory 3 before and after.
  - Near-miss peer: BT11-005 Koromon (Black Lv.2, `Lesser` only). `useAlternateCost:
    true` silently falls back to the normal route, so the test discriminates on the
    memory delta alone: 3 -> 2 (cost 1), proving the trait gate held.
  - Illegal sources: BT1-005 Kyaromon (Yellow Lv.2, no named trait) refused on both
    intents, and BT2-052 Hagurumon (Black Lv.3) refused on both intents; base top
    card, hand and memory unchanged in each case.
- Clause 2 -> `effects[0]`: `WhenAttacking` / `Digivolve`, `target.filter.isSelfRef`
  + `isSelf: true`, `into.nameOrTrait [{ tokens: ["RaptorSparrowmon"], match:
  "nameExact" }]` (bracketed name = exact, not the substring `match: "name"` trap),
  `from: ["digivolutionCardsUnderTamers"]`, `payCost: false`, `optional: true`.
  - Positive through a public `attack` intent: the attacking permanent keeps its
    identity, its top card becomes BT19-061, Sparrowmon's instance id is the single
    entry in `stack`, the Tamer's stack is emptied, memory is unchanged, and no
    `actionRejected` event was emitted.
  - Decline branch (`autoDeclineOptional`): Sparrowmon stays top card, the
    RaptorSparrowmon stays under the Tamer, and the attack proceeds to security.
  - Near-miss on both axes in one fixture: a BT19-058 SkullKnightmon under the Tamer
    (wrong name) and a BT19-061 in HAND (right name, wrong zone). Neither is used.
- Clause 3 -> `effects[1]`: `OnDeletion` with `keywords: [{ keyword: "Save" }]` and a
  `PlaceUnder` whose `underFilter` is `controller: "mine", kind: ["Tamer"],
  excludeToken: true`, `optional: true`.
  - Positive: deleted by effect, the card lands at index 0 of the Tamer's stack, i.e.
    the BOTTOM (CR 4-3-2) beneath the pre-seeded card, asserted by instance id; it is
    not in the trash. An opponent-controlled Tamer on the same board stays empty,
    proving the `controller: "mine"` gate.
  - Decline: the card is in the trash and the Tamer stack is empty.
- Clause 4 -> `effects[2]`: `YourTurn`, `isInherited: true`, `Aura` granting the
  `Collision` keyword to `isSelfRef` while `selfHasTrait` with
  `[{ tokens: ["Xros Heart"], match: "trait" }]` (exact trait, correct for
  "with the [Xros Heart] trait").
  - Realistic stack case through the real turn loop: BT19-061 (Xros Heart) and
    BT19-046 Chamblemon (Green, no Xros Heart) each carry a BT19-057 digivolution
    card. On seat 0's Main only the Xros Heart host has `Collision`; after the turn
    hands over (`startTurnLoop` + `waitForMainPhase(1)`, no `turnSeat` write)
    neither has it.
  - Consequence proof rather than a flag read: Q3117's test drives ＜Collision＞
    through the real block window (`eligibleBlockerIds`, `mustBlock`, refused
    `declineBlock`), per CR 16-30-1.

Every behavioural test uses public intents (`attack`, `digivolve`, `declineBlock`)
or the real turn loop. The only Advance-Surface uses are
`advance().verb.deletePermanent(..., "byEffect")` for the two ＜Save＞ tests (no
public intent deletes a Digimon by effect) and the turn-loop helpers
`waitForMainPhase` / `endMainPhaseIfOpen`. No `fire` / `fireTiming` /
`fireSubTrigger` injected timing is used anywhere, and no `s.state.turnSeat` write.
Fixtures carry no Digi-Egg in deck or security and no numeric `security: <n>` form;
`s.state.memory = n` before `ready()` is the only arranged state.

## Defects

None in the module. The IR was already correct on all four clauses, including the
`nameExact` gate for `[RaptorSparrowmon]` and the exact-trait `match: "trait"` gate
for `[Xros Heart]`.

The pre-existing test file was weak and is fully replaced:

- the [When Attacking] clause was proved with `advance().fireForPermanent(
  EffectTiming.OnUseAttack, ...)` — injected timing, worth at most 1 in Behaviour;
- the printed `[Digivolve] Lv.2 w/[Twilight]/[Xros Heart]` route was never exercised
  at all, so neither the trait gate nor the cost 0 was proved;
- the inherited-Collision test wrote `s.state.turnSeat = 1` directly (an injected
  state trap) and read `observe().hasKeyword` only, never the rules consequence;
- ＜Save＞ was asserted as "somewhere in the stack" with no order and no
  opponent-Tamer control;
- the fixture used `BT19-083` as the Tamer, and Sparrowmon at printed 2000 DP dies to
  the 3000 DP inert security card, which silently removed the permanent mid-test.

No red tests retained.

## Remaining gaps

- The alternate route's `traits` OR is proved through the Xros Heart branch on both
  an on-colour and an off-colour base. Monimon carries BOTH named traits, so no
  fixture isolates `Twilight` alone — no Lv.2 card in the catalog has `Twilight`
  without `Xros Heart`.
- Q3117 is proved at the block window. The finer claim in its answer ("＜Collision＞
  will already be activated while the Digimon with this effect is attacking") is
  observed as the window state, not as a separate ordering assertion.
