## Clause -> test -> IR

- Clause 1 -> `compiled.digivolutionRequirement = [{ namesExact: ["Wizardmon"], cost: 0,
  isAlternate: true }]`.
  - Positive: BT18-036 (Lv4 Yellow, named exactly `Wizardmon`) digivolved into with
    `useAlternateCost: true`; memory stays at 3 (the Lv3 evoCost of 3 was never charged),
    stack identity is the base instance, and the digivolution bonus draw landed.
  - Name near miss: BT12-078 `Wizardmon (X Antibody)` — a substring gate accepts it, the
    printed bracketed name does not. Refused; base unchanged, memory unchanged.
  - Illegal source: BT1-014 (Lv4 Red Kokatorimon) refused on the normal intent.
  - Normal route: BT1-045 (Lv3 Yellow) charges the printed 3 memory (5 -> 2).
- Clause 2 -> `SecurityManipulation { op: "toHand", toTop: true, amount: 1 }` on both
  `OnPlay` and `WhenDigivolving`. Proved through a public `playCard` intent (memory
  10 -> 4, top security instance id moves to hand, the second security card is now the
  only one left) and through public `digivolve` intents.
- Clause 3 -> `SecurityManipulation { op: "addBottom", optional: true, source.filter =
  { zone: "hand", kind: ["Option"], playCostLte: 5, colors: ["Yellow","Purple"] } }`
  gated by `selfHasInDigivolutionCards` over `[{ tokens:["Wizardmon"], match:"nameExact" },
  { tokens:["X Antibody"], match:"trait" }]`.
  - Name branch: digivolve from BT18-036. Bottom placement asserted by instance id —
    security ends `[second, option]`, not `[option, second]`.
  - Trait branch: digivolve from BT12-073 `Impmon (X Antibody)` (Lv3 Purple, normal
    route) — the trait alone satisfies the gate with no `Wizardmon` name anywhere.
  - Negative: digivolve from BT1-045 Tsukaimon (neither) — the Option stays in hand and
    only the security card moved.
  - Played from hand there are no digivolution cards, so the gate is false; the
    `plays on a public play` test asserts the Option is still in hand.
  - Optional: `autoDeclineOptional` leaves the Option in hand while clause 2 still runs.
- Clause 4 -> `AllTurns` / `isInherited` / `frequency: "OncePerTurn"` `Replacement`
  (`event: "wouldLeavePlay"`, `leaveCause: "opponentEffect"`, cost = trash own top
  security). Every case drives a REAL opponent effect: seat 1 plays BT14-100 Pummel
  Whack (`[Main] Delete 1 of your opponent's level 4 or lower Digimon`) inside their own
  Main phase through `startTurnLoop` + `waitForMainPhase(1)`; seat 1 also controls an
  inert purple Candlemon so the Option's colour requirement is met.
  - Protected: BT10-033 (Yellow, Data) with BT19-036 under it survives; `sec1` is in the
    trash and `sec2` is the only security card left.
  - `isSelfRef` proof: with a second yellow [Data] Digimon (BT3-037) on the same board
    and the deletion aimed at IT, that peer dies and no security is paid.
  - Trait negative: BT1-051 Reppamon (Yellow, Holy Beast / Vaccine) is deleted with
    security untouched.
  - Once per turn: two Pummel Whacks in one opponent Main — the first is prevented
    (one security card paid), the second deletes.
  - Cause negative: a real battle deletion on the opponent's turn (host attacks on its
    own turn to become suspended, then is attacked) is not prevented and costs no
    security.

## Defects found and fixed locally

1. `match: "name"` for the bracketed `[Wizardmon]` reference in both timing effects ->
   `nameExact`. Not separately observable in today's catalog (every card whose name
   contains `Wizardmon` as a substring also carries the `X Antibody` trait, so the OR
   still passes), but it is the printed semantics and the same token feeds the
   digivolution route below.
2. `digivolutionRequirement.names` (substring) -> `namesExact`. Behaviourally proved:
   before the fix BT12-078 `Wizardmon (X Antibody)` could take the cost-0 route.
3. The inherited would-leave replacement had no `isSelfRef`, so it protected EVERY
   yellow [Data]/[Witchelny] Digimon its controller had, not "this Digimon"
   (printed text and KB Q3092). Added `isSelfRef: true`.

Mutation check: reverting fixes 2 and 3 in the module fails
`refuses the [Wizardmon] route for the name-substring peer Wizardmon (X Antibody)` and
`does not protect the controller's OTHER yellow [Data] Digimon`, so both fixes are
proved by behaviour, not only by IR shape.
