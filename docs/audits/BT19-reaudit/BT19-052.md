### Evidence notes

- **Route cost.** The alternate route is discriminated by the memory delta, not by
  `{ok:true}`: memory 5 -> 2 (cost 3) on the Royal Base source, memory 5 -> 1 (cost 4)
  on the colour route. Digivolution-card identity is asserted by instance id, and the
  bonus draw is asserted by hand and deck contents.
- **Near miss vs illegal source.** BT1-073 Kabuterimon is Green, Lv.4 and `[Insectoid]` —
  everything the route wants except `[Royal Base]` — and the route intent is rejected
  with `invalid-evolution` while the colour route still works. BT1-014 Kokatorimon (Red
  Lv.4) is rejected on both, with board, memory and hand unchanged.
- **Blocker is proved by its rules consequence, not by a flag.** Inside the opponent's
  real Main phase (turn loop, no `turnSeat` injection) the opponent attacks the player;
  `declareBlock` with BT1-066 Tentomon (Green `[Insectoid]`, no `[Royal Base]`) is
  rejected, `declareBlock` with BT19-045 FunBeemon is accepted, and the endpoint is the
  redirected battle: FunBeemon in the trash, security count unchanged. The same board on
  my own turn grants nothing, and a face-down copy of the card grants nothing.
- **Deletion ceiling.** Three parameterised boards (0, 1, 2 face-up security cards) each
  assert both endpoints: the play-cost-at-the-ceiling target is in the opponent's trash
  and the next cost up is still on the board, with the played Vespamon on my board and
  memory at 0. The `When Digivolving` copy is proved through a real `digivolve` intent.
- **`[Rule]` trait.** The catalog already prints `Insectoid` in `types`, so the
  `GrantStatic` node is redundant with the catalog rather than load-bearing (recorded as
  a catalog observation below, not a defect). The consequence is still proved
  cross-card: BT9-100 Grandis Scissor unsuspends "1 of your Digimon with `[Insectoid]`
  in its traits" (`match: "trait"`, exact) and forces it to attack. Vespamon is chosen
  and attacks; BT1-013 Muchomon, suspended and available but not `[Insectoid]`, is never
  a candidate and stays suspended.
- **Peer / stack.** The inherited clause runs under a realistic host: BT19-053
  QueenBeemon with `BT18-044 / BT18-046 / BT19-052` beneath it — the printed
  FunBeemon -> Waspmon -> Vespamon -> QueenBeemon line. Battle 1 of the turn trashes the
  opponent's top security card (asserted by instance id); a second battle in the same
  turn, reached publicly by playing BT9-100, trashes nothing; after a real opponent turn
  the budget refreshes and a third battle trashes again. The opponent's survivor is put
  back into an attackable state by having it attack during the intervening turn, per the
  set brief.

## Defects fixed locally

The previous test file scored no behavioural credit for three clauses and injected state
for a fourth:

- `advance().fireForPermanent(EffectTiming.OnPlay | WhenDigivolving, ...)` for clause 3 —
  replaced by a real `playCard` intent inside an open Main phase and a real `digivolve`
  intent.
- `advance().fireSubTrigger("whenDeletesInBattle", ...)` for clause 5 — replaced by real
  attacks that delete in battle, including a real second attack in the same turn and a
  real next own turn for the once-per-turn reset.
- `s.state.turnSeat = 1` plus `advance().recompute()` for clause 2 — replaced by the real
  turn loop (`startTurnLoop` + `waitForMainPhase` + `endPhase`), and the keyword is now
  proved by an actual block declaration rather than `observe().hasKeyword` alone.
- The old fixtures seeded no security or deck for either seat and no near-miss peers.

No IR change was needed: every clause behaves correctly as compiled.
