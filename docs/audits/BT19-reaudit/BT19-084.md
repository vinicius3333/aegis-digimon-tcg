## Clause -> test -> IR

- **Clause 1** -> `effects[0]` `StartOfYourMainPhase` / `GainMemory { amount: 1, condition:
  { kind: "youHave", filter: { controllerDefault: "mine", zone: "security", faceUp: true } } }`.
  - `zone: "security"` + `faceUp: true` is read by the loose-zone branch of `countMatching`
    (`interpreter/scaling.ts:58-66`); the `youHave` default would count battle-area permanents
    and never see a security card. Verified by reading that branch and by behaviour.
  - Positive/negative: two identical boards differing only in the top security card's
    orientation, memory read **inside** the open Main phase (`startTurnLoop` +
    `waitForMainPhase(0)`), face-up run is exactly +1.
  - Simultaneous-trigger case: Q3146 above.
- **Clause 2** -> `effects[1]` `Main` (`optional: true`) with two actions:
  - `Digivolve { target: your Digimon, into: Digimon, from: ["security"], payCost: true,
    cost: { kind: "suspend" } }`.
    - Positive, through the **public** `activateEffect` intent (effect key read from
      `activatableEffectsJson`): Goblimon (Green Lv.3, 3000 DP) digivolves into the face-up
      Vegiemon (Green Lv.4, 6000 DP) sitting in security. Endpoints asserted: the new top card
      is the security card's instance, `stack` is exactly `[goblimon]`, `currentDP` is 6000,
      memory falls by Vegiemon's printed evolution cost of 1, the Tamer is suspended, and the
      digivolution draw put one deck card in hand.
    - Face-down negative: the same board with the Vegiemon face **down**. `runDigivolve` drops
      face-down security candidates (`interpreter/actions/digivolve.ts:186/254`,
      `faceDownSecurityOk`), so the ability is not offered at all —
      `activatableEffectsJson` is empty and a direct `activateEffect` is refused. Board,
      security stack and hand are unchanged and the Tamer never suspends.
    - Cost gate: while the Tamer is suspended the ability is withdrawn from
      `activatableEffectsJson` and an `activateEffect` with the previously captured key is
      refused; the second candidate source is untouched. After the opponent's whole turn
      through the real loop and our own unsuspend phase, the ability is payable again and a
      second digivolve lands.
  - `SecurityManipulation { op: "placeAsSecurity", from: ["hand"], toTop: false, faceUp: true,
    optional: true, source: { trait "Royal Base" exact, upTo: true },
    condition: { kind: "ifThisEffectDigivolved" } }`.
    - Positive: BT19-045 FunBeemon (`[Royal Base]`) leaves the hand and becomes the **bottom**
      security card face up, asserted by instance id and by the whole stack's card ids.
    - Trait near-miss: BT1-065 Mushroomon (Green Lv.3, no `[Royal Base]`) is in the same hand
      throughout and is never placed. "with the [Royal Base] trait" is the exact-trait form,
      so `match: "trait"` is correct here (not `traitContains`).
    - Result binding: on the face-down run nothing digivolved, and the `[Royal Base]` card
      stays in hand — the tail really is gated on the digivolve.
- **Clause 3** -> `effects[2]` `Security` / `PlayWithoutCost { target: { isSelfRef: true },
  payCost: false }`, `isSecurity: true`.
  - Proved through a **real security check** on a face-up copy: seat 0 attacks the player,
    seat 1's revealed BT19-084 plays itself onto seat 1's battle area, memory is unchanged
    (cost 3 not paid) and the remaining security card is intact.

## Defects fixed locally

None in the module.

The pre-existing test file was replaced wholesale. It built a hand-rolled `EffectContext` with
fake `Primitives` (`digivolveFromInstance`, `addSecurity`, `suspend` all counted calls) and
drove the module through `effectsForTiming(EffectTiming.OnDeclaration, …)` — injected timing
against a mocked engine, which earns no behavioural credit. Its two "public" tests also used
`advance().fire(EffectTiming.OnDeclaration, …)` (injected) and asserted only `isSuspended`.
Every case now runs through `startTurnLoop` / `waitForMainPhase` / `activateEffect` /
`attack` intents against the real engine, and the face-up-vs-face-down and
digivolved-vs-not levers that the fakes simulated are now produced by the real board.
