## Clause -> test -> IR

- Clause 1 -> `compiled.effects[0]`: `trigger: "StartOfYourMainPhase"`, `GainMemory` 1 with
  `condition.kind: "youHave"`, filter `controllerDefault: "mine"`,
  `nameOrTrait: [{ tokens: ["Henry Wong", "Calumon"], match: "nameExact" }]`.
  `[Name]` is bracketed, so `nameExact` is correct (the lane-3 substring trap does not apply).
  - Positive, real turn loop, value read INSIDE the open Main phase: ST17-10 [Henry Wong] and
    BT19-077 [Calumon], memory 0 -> 1 each.
  - Near miss on the exact name: EX4-063 [Henry Wong & Shu-Chong Wong] (substring only; it
    prints no "also treated as [Henry Wong]" line) -> 0 memory. Unrelated Tamer BT19-081
    [Kiriha Aonuma] -> 0.
  - Controller near miss: the OPPONENT's ST17-10 [Henry Wong] -> 0 memory.
- Clause 2 -> `compiled.effects[1]`: `trigger: "WhenAttacking"`, `isInherited: true`,
  `frequency: "OncePerTurn"`, `Suspend` count 1 with filter
  `{ controller: "opponent", kind: ["Digimon"] }`.
  - Positive through a public `attack` intent inside a real `startTurnLoop` turn, under a
    legal stack (BT19-044 under BT19-049 Gargomon, Green Lv3 -> Green Lv4): the opponent
    Digimon suspends, their Tamer does not, our own Digimon does not, the attacker suspends
    and exactly one security card is checked.
  - Q845: with `preferInstanceIds` scripted onto the already-suspended peer, that peer is
    chosen and the unsuspended peer stays unsuspended. This is the assertion the removed
    `suspended: false` filter used to fail.
  - Once per turn: after the real attack, a second firing of the same window in the same turn
    suspends nothing more; the opponent's real turn is then driven through the loop
    (`waitForMainPhase(1)` / `endPhase`, never `state.turnSeat = 1`), and on our next own turn
    the host has unsuspended, both opponent Digimon stood up, and a fresh attack suspends one
    again.
- Evolution routes: legal Green Lv2 source (BT1-007 Tanemon in breeding) digivolves for cost 0
  with the source retained as the only digivolution card and the card gone from hand; illegal
  off-color Lv2 source (BT1-005 Kyaromon, Yellow) is refused on both the normal and the
  `useAlternateCost: true` intent with board, hand and memory unchanged.

## Defect fixed locally

`BT19-044.ts` carried `suspended: false` on the inherited Suspend target filter (added by the
prior audit). The printed text says only "1 of your opponent's Digimon"; Q845 and Q1219 confirm
an already-suspended Digimon is a legal choice, and BT17's re-audited equivalents
(`BT17-034.ts`, `BT17-047.ts`) carry no such filter. Removed, with a comment naming the ruling.
The coordinator independently reached the same decision (lane 17 reversed it on BT19-038).

resynced.**
