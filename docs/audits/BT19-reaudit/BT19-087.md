## Clause -> test -> IR

- **Clause 1** -> `effects[0]`: `trigger: "StartOfYourTurn"`,
  `SetMemory value 3` with `condition { kind: "memoryAtMost", value: 2 }`.
  - `[Start of Your Turn] sets memory to 3 from 2, read inside the open Main phase`
    reads `state.memory` between `runOneTurn()` and `endMainPhaseIfOpen(0)`, not
    after the turn completes.
  - Negative: at 6 memory the clause never lowers memory.
  - Peer control: BT19-086 Ryo Akiyama (the only BT19 Tamer with no memory clause)
    on the same board leaves memory at 2. BT19-080 Takato is unusable as this
    control — it prints the same "2 or less → 3" clause.
- **Clause 2** -> `effects[1]`: `trigger: "AllTurns"` (not `Static`),
  a `Replacement` on `event: "wouldBePlayed"`, `mode: "instead"`, with
  `sourceFilter { controller: "mine", kind: ["Digimon"],
  nameOrTrait: [{ tokens: ["Composite","Twilight"], match: "trait" }],
  hasDigiXrosRequirement: true }`, whose single action is
  `DigiXrosMaterialZoneExpansion { zones: ["underTamers","trash"],
  duration: "forTheTurn", cost: suspend isSelfRef }`.
  The live quota comes from `packages/shared/src/cards/zoneExpanders.ts`
  (`underTamerMax: 1`, `trashMax: 1`, no `underTamerHostScope`), consumed by
  `apps/api/src/engine/actions/digiXros.ts:207-260`.
  - Positive, both areas at once: BT10-009 Shoutmon X4 ([Composite], cost 9,
    DigiXros -2) played with an under-Tamer BT10-008 and a trash BT10-049.
    Endpoints: both instance ids in `played.stack`, Nene's `stack` empty, the
    trashed card gone from `trash`, `isSuspended === true`, memory 5 → 0.
  - Positive, [Twilight] gate: BT10-066 DarkKnightmon (cost 8, DigiXros -2) with
    an under-Tamer BT7-058 and a trash BT7-059; memory 4 → 0.
  - Q3153 "one area only": one trash material alone, Tamer suspended, memory 7 → 0.
  - Q3153 "additive": with no `expanderPermanentIds` a hand material still works
    and the Tamer stays unsuspended.
  - Negatives with full endpoints (nothing moved, memory unchanged):
    - the same trash material without naming the expander -> `invalid-material`;
    - an already-suspended Nene -> `invalid-expander`;
    - 2 trash materials -> `invalid-material` (trash cap 1);
    - 2 under-Tamer materials -> `invalid-material` (under-Tamer cap 1);
    - naming the plain host Tamer (BT19-080) as the expander -> `invalid-expander`;
    - a [Bagra Army]-only DigiXros card (BT10-077) -> `invalid-expander`.
  - Peer/stack: BT10-088 Kiriha (registered expander, no trait gate, under-Tamer
    only) legalizes the same [Bagra Army] play that BT19-087 refuses, and is
    itself refused for a trash material — the two expanders separate the trait
    gate from the trash quota.
- **Clause 3** -> `effects[2]`: `trigger: "Security"`, `isSecurity: true`,
  `PlayWithoutCost` on `isSelfRef` with `payCost: false`.
  - Real security check: seat 0 attacks the player with BT1-015; the defending
    seat's BT19-087 is the top security card and lands on the battle area by
    instance id, is not in security and not in the trash, and no memory moved
    (its printed cost of 4 was not paid).
  - Other outcome: with BT19-087 second in the stack, the plain top card is
    trashed and BT19-087 stays face down in security; battle area empty.
- **Tamer play cost** -> catalog `playCost: 4`. Played from hand inside a real
  `startTurnLoop()` Main phase: memory 6 → 2, hand reduced to the spare card,
  battle area length 1, turn closed with `surrender` + `await loop`.
