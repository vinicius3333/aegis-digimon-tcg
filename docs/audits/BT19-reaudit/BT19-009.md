# BT19-009 Growlmon — re-audit

Lane 3, card lane. Independent re-audit; the 10/10 claim in
`docs/audits/BT19-AUDIT.md` was not used as evidence.

## Card summary

- Red Digimon, Lv.4 Champion, play cost 5, DP 5000, Virus / Dark Dragon.
- Digivolve cost: Red Lv.3 for 2.
- Printed clause 1: `[When Digivolving] If you have 1 or fewer Tamers, you may
  play 1 [Takato Matsuki] from your hand without paying the cost.`
- Printed clause 2 (inherited): `[All Turns] While you have 0 or less memory,
  add 2000 to this Digimon's DP deletion effects' maximums.`

## Q&A ids

| id | ruling | covered by |
| --- | --- | --- |
| Q3064 | "while you have 0 or less memory" is fulfilled when the gauge is at 0 through 10 on the OWNER's side at the moment a DP-based deletion effect activates | `applies the +2000 maximum only while its owner has 0 or less memory (memory 0 / memory 1)` — the 0 edge deletes, the 1 edge does not |
| Q3065 | "add X000 to the maximum" raises the printed numeric maximum of a DP-based deletion effect | `applies the +2000 maximum ... (memory 0)` and `still raises the printed maximum for a target the bonus alone brings into range` (8000 -> 10000: 10000 DP deleted, 11000 DP not) |
| Q3066 | the maximum is NOT raised for an effect that references a Digimon's DP instead of a printed number | `does not add to a DP maximum that references the source Digimon's DP (Q3066)` |

## Clause -> test -> IR

### `[When Digivolving] If you have 1 or fewer Tamers, you may play 1 [Takato Matsuki] from your hand without paying the cost.`

IR: `effects[0]` — trigger `WhenDigivolving`, action `PlayWithoutCost
{ optional: true, payCost: false, from: ["hand"], target: nameExact
["Takato Matsuki"], condition: youHave kind ["Tamer"] countMax 1 }`.

- `plays Takato for free through the digivolve intent with 0 / 1 Tamer(s)` —
  the real `digivolve` intent onto a BT19-007 base. Endpoints: memory 2 -> 0
  (only the digivolution cost of 2 paid; Takato's play cost 3 was not), top
  card `BT19-009`, stack `["BT19-007"]`, Takato's exact instance on the board,
  hand holding only the digivolve bonus draw, no pending decision. The bonus
  draw itself confirms a legal digivolve route rather than a bare `{ok:true}`.
- `does not play Takato when it already has 2 Tamers` — the `countMax: 1`
  boundary; Takato stays in hand and the battle area keeps 3 permanents.
- `does not play a near-miss Tamer that is not Takato Matsuki` — BT19-079
  Taiki Kudo in hand instead; nothing is played (the `nameExact` leg).
- `declines the optional play when the controller says no` — `autoDeclineOptional`;
  Takato stays in hand, proving the clause is a "may".

### Inherited `[All Turns] While you have 0 or less memory, add 2000 ...`

IR: `effects[1]` — trigger `AllTurns`, `isInherited: true`, action
`DeletionMaxDpModifier { amount: 2000, scope: "self", duration: "permanent",
condition: memoryAtMost 0 controller "mine" }`.

The deletion effect used for proof is a different card's printed clause reached
through a public intent, never injected timing: BT19-015 Gallantmon's
`[When Digivolving] Delete 1 of your opponent's Digimon with 8000 DP or less`,
digivolved onto a BT19-012 stack that carries BT19-009 in its digivolution
cards.

- `applies the +2000 maximum only while its owner has 0 or less memory` — the
  Gallantmon route costs 4, so the gauge lands on exactly 0 or exactly 1 when
  the effect resolves. At 0 the 9000 DP target is deleted (8000 + 2000); at 1
  it survives. Endpoints asserted: memory, top card `BT19-015`, stack
  `["BT19-009", "BT19-012"]`, opponent battle area, no pending decision.
- `leaves the printed 8000 maximum alone without Growlmon in the digivolution
  cards` — identical board with an inert BT1-009 under the stack; the 9000 DP
  target survives. Peer/stack near-miss attributing the deletion to Growlmon.
- `still raises the printed maximum for a target the bonus alone brings into
  range` — 10000 DP deleted, 11000 DP survives, pinning the new maximum at
  exactly 10000.
- `does not add to a DP maximum that references the source Digimon's DP
  (Q3066)` — BT19-014 Shoutmon EX6's `[When Attacking] delete 1 of your
  opponent's Digimon with as much or less DP as this Digimon` with Growlmon
  underneath; its 12000 DP does not become 14000 against a 13000 DP target.

## Defects fixed locally

1. IR `match: "name"` (substring) for the bracketed `[Takato Matsuki]` name.
   Corrected to `nameExact`. No catalog card currently makes the two modes
   diverge for this token, so the fix is fidelity, not a behaviour change.
2. Fixture defect: the Q3066 test seeded `security: ["BT1-001"]` and
   `deck: ["BT1-002"]`, both Digi-Eggs, in main-deck zones no game can reach.
   Replaced with the inert BT1-009 Monodramon.
3. Fixtures gave the opponent no security, so every digivolve test tripped the
   security win check mid-test. Seeded one inert security card.
4. The Tamer tests asserted only `hand` contents; they did not pin the
   digivolution cost, the resulting stack, Takato's instance identity, or the
   absence of a pending decision. Endpoints added.
5. No decline case and no near-miss name case existed for the optional play.
   Both added.

## Remaining gaps

- Same as BT19-007: the `controller: "mine"` leg of the memory condition is not
  separable from the raw gauge behaviourally, because every reachable numeric
  DP-deletion effect activates on its controller's own turn.
- The `[When Digivolving]` clause is proved only from the Guilmon (Lv.3 Red)
  route, which is the only printed digivolve requirement this card has.
