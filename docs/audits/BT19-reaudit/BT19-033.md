## Defects found and fixed locally

1. **IR defect.** `into.nameOrTrait` used the substring `match: "name"` for the
   bracketed exact reference `[JaegerDorulumon]`; corrected to `nameExact`
   (worker-brief trap). Note the substring form was actively wrong here in
   principle: `"Dorulumon"` is a strict substring of `"JaegerDorulumon"`, so the
   family is exactly the kind that a substring gate over-accepts.
2. **Test defect.** The previous test proved `[Your Turn]` by setting
   `s.state.turnSeat = 1` — injected state, which earns no credit. Replaced with
   a real turn loop.
3. `compiled` is now exported so the test can assert the IR.

Checked and deliberately not changed: ＜Save＞ already carries
`optional: true` **and** `keywords: [{ keyword: "Save" }]`, which is the correct
shape (comprehensive 16-20-3); no `abortOnDecline` was added to the sole action
(dead flag, traps 008/016).
