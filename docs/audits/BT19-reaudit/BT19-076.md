## Defects found and fixed locally

1. **`[On Deletion] ＜Save＞` was dead.** The effect carried `keywords: [{ keyword: "Save" }]`
   with `actions: []`. `withSavePlacementDefaults`
   (`apps/api/src/engine/effects/interpreter/registration/normalize.ts:115`) only defaults the
   POSITION of an existing `PlaceUnder`; nothing in the engine synthesizes the placement from
   the keyword alone (`rg '"Save"' apps/api/src/engine` finds only the keyword token list, the
   combat regex and that normalizer). The card was therefore trashed on deletion. Fixed by
   adding the `PlaceUnder` action in the BT19-020 / BT19-022 shape.
2. **`[Digivolve][Shademon]` used the substring gate.** `names: ["Shademon"]` -> `namesExact`
   (lane 5 / BT19-012 finding). No live near-miss exists in the catalog today (nothing is
   named `*Shademon*` without being exactly `Shademon`), so this is correctness hardening
   rather than an observed misbehaviour; it is asserted structurally.
