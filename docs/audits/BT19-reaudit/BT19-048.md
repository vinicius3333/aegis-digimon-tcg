## Card summary

Green/Black, Lv.4, Virus, Cyborg / X Antibody / Royal Base / LIBERATOR / Insectoid,
4000 DP, play cost 4, evo costs Black Lv.3 = 3 and Green Lv.3 = 3.

Printed clauses:

1. `[Digivolve]Lv.3 w/[Royal Base] trait: Cost 2`
2. `[Security] [All Turns] All of your [Royal Base] trait Digimon get +1000 DP.`
3. `[All Turns] [Once Per Turn] When any of your other Digimon with the [Royal Base] trait
   would leave the battle area by effects, by placing this Digimon as the face-up bottom
   security card, they don't leave.`
4. `[Rule] Trait: Has the [Insectoid] type.`
5. Inherited: `[All Turns] This Digimon gets +1000 DP.`

Clause 2 is the BT18/BT19 "Royal Base" security-resident family (BT18-044, BT18-046,
BT19-045, BT23-038, BT23-042 print the identical line). `[Security]` here marks a
persistent effect whose source is a FACE-UP card in the security stack, not a
security-check trigger: `builderForTrigger`
(`apps/api/src/engine/effects/interpreter/effect.ts:321-327`) routes `isSecurity` +
`YourTurn|OpponentsTurn|AllTurns` to the `securityStatic` builder, whose base guard is
`isSecuritySource` (face-up in security, `effects/context.ts:86-88`).

## Findings

1. **No IR defect found.** Every filter, trigger, duration and cost key in the module is a
   key the engine actually reads. Specifically checked against this run's trap list:
   `match: "trait"` is the exact-trait form the bracketed `[Royal Base]` reference needs;
   the trigger is `AllTurns`, not `Static`; `duration: "permanent"` is a real
   `EffectDurationRef`; `sourceFilter.leaveReason: "effect"` is a supported alternative
   encoding of `leaveCause: "byEffect"`; the `[Rule]` line has a `Rule`/`GrantStatic` node.
2. **The previous test's claim "all and only controller Royal Base Digimon" was untested** —
   its fixture had no opponent permanent at all, and no near-miss trait. Both are now
   asserted.
3. **The `[Rule]` node is redundant but harmless.** The catalog already lists `Insectoid` in
   `types` for BT19-048, so the trait gate would pass without `effects[2]`. Unlike
   BT19-018/019 (whose catalog `types` lack the granted type) there is no way for a test to
   separate the node from the catalog fact. The node is kept because the line is printed;
   the cross-card consequence test proves the trait is effective either way.
4. **`[Once Per Turn]` is not behaviourally observable on this card.** The cost of the
   prevention is placing the source itself into the security stack, so after one use the
   source is no longer on the battle area and can never be asked a second time — in the same
   turn or any later one. The frequency is asserted structurally on the IR; there is no
   board state in which a second same-turn refusal could be observed. Not a defect, and not
   evidence either: recorded honestly here rather than dressed up as a behavioural pass.
5. **Testkit note (not a defect).** An opponent Option needs a matching-colour permanent on
   the player's own board (`color-requirement-unmet`), and an attack needs a SUSPENDED
   defender; the battle-deletion case therefore attacks on my own turn into a seeded
   suspended wall rather than seeding my own Digimon suspended (which would stand up at my
   unsuspend phase).

No engine gap was found, so no test is retained red.
