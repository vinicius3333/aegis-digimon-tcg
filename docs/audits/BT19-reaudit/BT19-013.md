## Defect fixed locally

`BT19-013.ts` carried the play-cost ceiling as `playCost: { op: "lte", value: 4 }`. That object
form is only honored for PERMANENT targets (`interpreter/matching/permanent.ts`); the loose-card
matcher used for `zone: "underTamers"` reads `playCostLte`
(`interpreter/matching/definition.ts:148-157`), so the ceiling was silently dropped and the
`[On Deletion]` clause could play a card of ANY cost from under a Tamer. Proved by the pre-
existing test "saves only this Digimon's Xros Heart sources when another stack also qualifies",
which asserted the cost-7 BT19-012 arriving in the battle area. Changed to `playCostLte: 4`;
that test now asserts BT19-012 staying under the Tamer, and a dedicated negative covers cost 7
and the missing trait.

This is an IR change, so `effects.json` is stale for BT19-013.
