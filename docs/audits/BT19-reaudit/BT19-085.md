Notes on the IR that were checked and found CORRECT rather than changed:

- `match: "name"` (substring). The printed text is "in its name", not a bare `[Name]`
  reference, so `namesExact` would be wrong here. Proved with BT3-057 MegaGargomon.
- Trigger is `AllTurns`, matching the printed `[All Turns]` — not `Static`.
- `sourceFilter` on `whenOneOfYoursDigivolves` is applied to the RESULTING permanent
  (`interpreter/actions/subTrigger.ts` `filterMatch` over `subjectPermanentId`), so it is the
  correct home for the "into a green Digimon" gate.
- `youHave` without `zone` already excludes breeding (lane 8's verified non-trap), so no
  `zone: "battleArea"` was added.
- `abortOnDecline: true` on the sole action is dead but harmless; not churned.
