## Defect fixed locally

`[ShootingStarmon]` is a bracketed exact card-name reference but the IR matched it with
`match: "name"`, the substring form (the trap lane 3 found on BT19-007/009). Changed to
`nameExact`. No printed card name today contains "ShootingStarmon" as a proper substring
(the catalog holds only `ShootingStarmon` BT5-039 and BT19-035), so the fix is not observable
in current data — it is a correctness fix, not a behaviour change, and no test can distinguish
the two forms.

This is an IR change, so `effects.json` is stale for BT19-014.
