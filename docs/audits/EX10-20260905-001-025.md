## Shared seam delivered

`GameEngine.recomputeContinuousEffects` now reaches a bounded fixed point for
continuous DP dependencies. It clears the continuous ledgers on every pass,
seeds the next pass from the engine-owned prior resolved continuous DP map,
re-resolves all persistent effects, and recomputes seeded permanents after the pass so a gate
that stopped matching cannot leave stale DP visible. Continuous subscriptions
and modifiers are still cleared and rebuilt each pass, so the iteration does
not accumulate duplicate watchers or grants. Failure to converge after 32
passes raises an error rather than silently accepting a partial result.

The reusable seed projection in `ModifierLedger` accounts for direct deltas,
base-DP overrides, minimum-DP floors, link DP and non-continuous player-wide
DP effects. It is independent of EX10 card IDs. The engine-owned seed cache
guards absent entries, removes departed permanents, and carries only proven
continuous contributions; a hand-laid or stale `currentDP` value cannot become
a continuous grant. Base overrides and floors are projected as stat layers,
not converted into accumulating deltas.

DP modifier provenance now records the source seat and source card kinds. An
opponent-origin modifier is suppressed through the target's matching
`beAffected` immunity while remaining in its duration ledger, so it can revive
when immunity lapses. Legacy player-wide modifiers without provenance continue
to honor the reduction-only `dpImmune` restriction. Provenanced player-wide
effects use the same source-seat distinction, allowing a friendly buff while
suppressing an opposing Digimon effect.

## Q5202 evidence

`EX10-010.test.ts` stages two facing EX10-010 copies and a third Digimon with
original DP 13000, in both seat orderings. The first derived pass activates the
directly qualified copy; subsequent fixed-point passes activate the opposing
copy as its DP reaches 15000. Both copies finish at 15000 and are immune to
the opponent's Digimon effects. Repeating recomputation remains at 15000
without accumulation. Removing the external 13000-DP seed leaves the
established mutual grants at 15000, as required by Q5202. Removing one facing
copy then breaks the dependency and drops the survivor to its printed 12000
DP, proving that stale seeds are not retained. The named tests
`Q5013/Q5202 mutual fixed point with the seed on seat %s` and
`keeps two unseeded facing copies at printed DP in either seat ordering` cover
the positive and negative stack cases.

The same suite names `Q5013 suppresses the temporary opposing +3000 after both
copies turn on` and `Q5024 revives a suppressed opposing DP grant when the
immunity gate lapses`. These prove that source provenance suppresses a live
opponent grant rather than deleting it, and that the stored grant becomes
visible again after the gate disappears.

## EX10-023 phase-scope evidence

The module now emits the reusable `unsuspendDuringUnsuspendPhase` restriction.
`unsuspendAllForSeat` checks it for every own Digimon and Tamer, and
`unsuspendRebootForSeat` checks it for an opponent's Reboot Digimon, including a
breeding permanent. The effect primitive continues to check only the unscoped
`unsuspend` restriction, so a mid-turn effect-driven unsuspend succeeds. The
new `unsuspendPhaseRestriction.test.ts` case
`Quartzmon blocks an actual start-turn Unsuspend effect but allows the same
action during Main` proves the real turn-machine path, while the EX10-023
suite proves the blocked active-phase path, blocked opponent Reboot path,
legal effect path, Quartzmon exemption, late entrants and duration lapse for
KB Q5075.
