# AD1-018 through AD1-025 Luna Audit

This audit uses the committed catalog in `packages/shared/src/cards/data/cards.json` and the local card KB (`node tools/kb/query.mjs card <CARD-ID>`). The existing AD1 ledger was treated as historical evidence only.

All eight modules use `registerIrCard` exclusively. Focused runs were executed with Vitest and `--maxWorkers=1`. The AD1-020 attack-only keyword now uses an atomic `Cost.kind: "attack"` path that resolves after attack declaration and before suspension-triggered/When Attacking effects. The shared combat mechanism regression is covered in `controller.test.ts`.
