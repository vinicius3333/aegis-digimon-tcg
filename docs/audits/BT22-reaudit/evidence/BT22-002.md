# BT22-002 Kyaromon

## Contract and sources

The catalog defines a yellow level 2 Digi-Egg with inherited text: `[Your Turn] [Once Per Turn] When any of your Tokens or other [Puppet] trait Digimon are deleted, Draw 1.` The local card query returns no BT22-002 ruling entry.

## Implementation and proof

`BT22-002.ts` registers only `registerIrCard`. The inherited watcher is Your Turn, once per turn, mine-controlled, excludes itself, and uses an OR of any Token or other Digimon with Puppet trait before Draw 1. The tests prove two qualifying Puppet deletions consume one OPT, non-Puppet/opponent/host exclusions, and an owned Puppet deletion during the opponent turn leaves the watcher unused. A public Cendrillmon play creates a real Familiar Token; deleting that token through the engine produces the observed draw.

## Stack and evolution

## Remaining boundary

The Token and Puppet alternatives are structurally asserted and each has a causal deletion path. The reset test records the initial turn count, runs public seat 0 and seat 1 turns with deck headroom, asserts turn count advanced and seat 0 is active again, then deletes a second Puppet and observes the second draw. A natural public Overclock deletion route is not needed because the Token route directly proves the printed Token alternative.
