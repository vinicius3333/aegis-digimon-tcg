# BT22-010 Meramon

## Catalog and rules

The catalog requires alternate level 3 Flame/CS digivolution for 2, a once-per-turn Main effect that pays exactly 2 memory, grants Raid and Piercing for the turn, then may attack, and inherited Your Turn +2000 DP. KB Q4866 and Q4867 require the full 2-cost payment and gate the post-then attack on that payment; Q4962 confirms post-resolution timing for chained effects.

## Implementation and proof

`BT22-010.ts` contains only `registerIrCard` and maps the paid Raid action with `abortOnDecline`, followed by Piercing and optional self-attack, with `frequency: OncePerTurn`; inherited +2000 DP is permanent. Focused tests `pays exactly 2 through public Main activation and grants Raid and Piercing`, `pays the Main cost even when the optional follow-up attack is declined`, and `gives the evolved host +2000 DP during its controller's turn` cover payment, optional refusal, duration projection, and stack source.
