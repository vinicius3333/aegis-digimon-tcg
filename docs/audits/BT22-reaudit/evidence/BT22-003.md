# BT22-003 Tapmon

## Contract and sources

The catalog defines a yellow level 2 Appmon Digi-Egg with inherited text: `[Your Turn] [Once Per Turn] When this Digimon gets linked, 1 of your opponent's Digimon gets -2000 DP for the turn.` The local card query returns no BT22-003 ruling entry.

## Implementation and proof

`BT22-003.ts` registers only `registerIrCard`. The inherited watcher is Your Turn, once per turn, self-scoped to `whenLinked`, and modifies exactly one opposing Digimon by -2000 with `forTheTurn` duration. Public `linkCard` tests prove a genuine link causes the exact reduction, another host does not trigger it, a second link in the same turn is suppressed, an opponent-turn link is suppressed, and a second opposing Digimon remains at base DP.

## Stack, timing, and boundaries

The public stack test hatches BT22-003 and evolves it into Appmon BT21-009 Gatchmon while rejecting BT22-008 Agumon. The duration test observes the grant during the owner's main phase, then verifies base DP at the end of that turn, throughout the complete opponent turn, and at the next owner main phase. The fixtures use real Appmon link cards and exact public link state. The -2000 DP is a triggered, resolved modifier that lasts for the turn independently of the link card, so unlinking does not revoke it.
