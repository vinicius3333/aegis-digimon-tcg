default Vitest configuration:

```text

timeout 180s pnpm effects:sync:set -- --set BT10
timeout 180s pnpm effects:check:set -- --set BT10 --base origin/main
timeout 180s pnpm --filter @aegis/api exec vitest run src/cards/BT10/BT10-catalog-sync.test.ts --maxWorkers=1 --no-file-parallelism
timeout 300s pnpm --filter @aegis/api exec vitest run src/cards/BT10 --maxWorkers=1 --no-file-parallelism
timeout 300s pnpm --filter @aegis/api exec vitest run \
  src/engine/actions/playCard.test.ts \

  --maxWorkers=1 --no-file-parallelism

timeout 180s pnpm --filter @aegis/shared build
timeout 240s pnpm --filter @aegis/api typecheck
```

The mechanism batch uses eight mutually compatible files. The primitives file
runs in its own process because its legacy `registerCard` seam shares a global
test registry with unrelated mechanism fixtures when Vitest reuses a worker.
