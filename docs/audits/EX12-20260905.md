  records `byOpponentEffectsOnly: true`, matching the printed opponent-only scope.
  The shared runtime already permits friendly effects; removing only this field
  did not break the friendly-DP test. This is an IR clarification and stronger
  behavioral coverage, not a demonstrated change to friendly-effect behavior.
  Only EX12-019 changes semantically in `effects.json`.
- EX12-065 Kaguyamon / Fortitude: Fortitude now joins the ordinary simultaneous
  deletion trigger pool. Event snapshots retain keyword eligibility and former
  digivolution cards after deletion; a deleted-host identity map prevents pending
  own/inherited effects from activating once Fortitude has replayed that host.
  Effect deletion, battle deletion and pooled DP rule checks retain this provenance.
  Scapegoat's combat sacrifice path also supplies the same Fortitude snapshot.
  The obsolete combat replay callback has been removed.

Source: local `node tools/kb/query.mjs card EX12-065` and
[official Q6866](https://digimoncard.com/rule/?card_no=EX12-065), checked 2026-09-05.
