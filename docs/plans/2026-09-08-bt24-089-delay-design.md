# BT24-089 reactive Delay correction

## Contract

The committed catalog prints `[Your Turn] When any of your [Owen Dreadnought]s
suspend, <Delay>`, not a grant of Delay for a later Main activation. Local
Comprehensive Rules15-4-2-2 and15-8-3-1/2 define the suspension as the trigger;
16-17-1/2/3 add optional source trashing and the entry-turn restriction.

## Alternatives and decision

1. Use the existing reactive Delay gate on the card's suspension subtrigger.
   This preserves printed timing and keeps the change within card IR.
2. Extend the shared engine only if a public regression proves that its existing
   reactive gate cannot express this contract. This has a larger regression scope.
3. Keep permanent arming and a manual Main activation. Rejected: the catalog
   does not grant that persistent ability.

The audit coordinator selects1 subject to a red-first public test. No engine
change is authorized merely because the current card representation is wrong.

## Representation and proof

Keep Main placement and Security activation unchanged. Replace the keyword
grant plus separate Main Delay effect with the reactive suspension effect,
using the existing intrinsic Delay source-cost/entry-age handling. Preserve
the legal host filter, hand-only evolution, reduction3, and Q5680 target
expression: Reptile OR (Dragonkin AND LIBERATOR).

Publicly place089, finish real turns, and publicly evolve an own Digimon to
trigger Owen082's suspension. Decline Owen's optional attack and accept Delay.
The old module must fail the immediate payload endpoint without any manual
Main activation. Assert source trash, exact paid and reduced costs, both
evolution stacks, distinct bonus draws and idle final decisions. Include
entry-turn, refusal and otherwise-legal target contrasts. Failures in the
shared gate are escalated with the smallest reproducible seam, not hidden by
timing injection or state mutation.

Acceptance requires focused tests, applicable mechanism/collection regression,
types, scoped style, effects synchronization and zero outside-set effects
changes. Delivery remains pending the full collection audit.

## Engine seam found

Reactive cards commonly attach the printed `Delay` keyword to the
`SubTrigger`/`Replacement` action that owns the event listener. The module
builder previously recognized only keywords on the enclosing effect, so the
listener bypassed the intrinsic source-trash gate. The reusable builder now
recognizes either location and applies the existing gate; focused Delay
placement/conformance coverage remains green (15 tests).
