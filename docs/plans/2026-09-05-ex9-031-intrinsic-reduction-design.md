# EX9-031 intrinsic evolution reduction

EX9-031 encodes its Ver.3-base reduction as a static nested would-digivolve
replacement. The registration layer collects that IR shape only for explicitly
verified card IDs. EX9-031 was absent, so a real evolution with two hidden
sources charged four memory instead of two.

Add EX9-031 to the existing verified intrinsic-reducer set alongside EX9-063
and BT22-038. Do not add a second handwritten reduction or change the card's
IR. The existing collector preserves the base trait filter and source-count
scaling, while marker classification avoids also installing the intrinsic
reduction as an ordinary continuous effect.

Focused tests establish two hidden sources, a mixed hidden/face-up stack, and
a non-Ver.3 legal yellow base. The latter two cases prove visibility and
trait boundaries. Comparative regressions use EX9-063 and BT22-038. Existing
card tests additionally cover Security Attack +1 and inherited DP behavior;
their success alone is not a final collection fidelity verdict.
