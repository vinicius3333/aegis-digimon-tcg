# Preview card art

These WebP files are a byte-preserving local cache of card images downloaded on
2026-09-12 from `https://images.digimoncard.io/images/cards/<card-id>.webp`.
They cover EX13-001 through EX13-071 and P-245 through P-250, whose committed
catalog definitions are included in this release. EX13-072 was not available at
that source and continues through the normal remote fallback and identity card.

The source is used only to provide same-origin preview art for this beta release;
the files are not modified or synthesized.
