## Corrections, registrations, and protected files

The audited implementation corrections were scoped to the following seams:

1. BT18-071 now requires the exact Sephirothmon base name and at least one exact Mercurymon card in that base's evolution stack.
2. BT18-072 now requires one Beetlemon and one MetalKabuterimon for DigiXros, and its leave replacement reads only from AncientBeetlemon's own evolution stack.

4. BT18-074 now has the exact Mercurymon/Sephirothmon DigiXros pair, its optional return-to-hand modal branch in addition to the stack-play branch, and a Digimon/Tamer kind gate for RevealAdd play.
5. BT18-076 now pays the attack-originating Digivolution, restricts its inherited leave replacement to causes other than the controller's own effect, and reads the PlayWithoutCost candidate only from that host's own evolution stack.

BT18-075, BT18-077, BT18-078, BT18-079, and BT18-080 required no semantic implementation correction in this range; their source proofs were strengthened.
