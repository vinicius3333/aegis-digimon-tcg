# BT11-041–050 Static Card Audit

## Scope and audit posture

This report covers BT11-041 through BT11-050 in strict ascending card order.
The branch was synchronized first with git fetch origin audit-bt-card-by-card
and a regular merge of origin/audit-bt-card-by-card (no rebase); the resulting
worktree is based on b85eb64bf. The printed contract was read from the
committed catalog blob
efbecc002fb9000789123e2f91f201466e1e5b0a, the local rules and Q&A knowledge
base were queried with node tools/kb/query.mjs card <CARD-ID>, direct modules
were traced through registerIrCard(cardId, compiled), and
packages/shared/src/effects/effects.json was inspected only as read-only
generated evidence.

The historical BT11-AUDIT.md and BT11-STATIC-AUDIT.md were preserved. No
generated effects record was edited in this audit, and BT11-STATIC-AUDIT.md
was not updated. The colocated tests and relevant peer tests were read as
behavioral proof, including their optional decisions, boundaries, security
events, and evolution stacks, but this dispatch explicitly forbade tests,
typecheck, lint, format, browser/UI checks, and git diff --check. Therefore
the execution gate is intentionally 0/2 for every card and every otherwise
complete card remains provisional at 8/10.

Each audited module contains exactly one executable registration through
registerIrCard("BT11-<ID>", compiled) and no second registerCard call. No new
production or test correction was justified after the synchronized branch was
reviewed. The previously delivered corrections relevant to this range are
listed explicitly below so this report does not silently reclassify historical
work as a new change.

## Card-by-card evidence

### BT11-041 — Etemon — 8/10 provisional

#### Contract and KB

The catalog defines a yellow/black level-5 Ultimate/Virus/Puppet Digimon with
play cost 7, 7000 DP, and yellow or black level-4 evolution for 4. Its
printed alternate route is from a level-4 Digimon with Sukamon in its name
for 3. The main effect is optional on both On Play and When Digivolving:
trash one Sukamon-named card from hand or this Digimon's digivolution cards,
then give one opposing Digimon -3000 DP and Security Attack -1 through the
end of the opponent's turn. The inherited All Turns clause may delete one
other Sukamon-named Digimon to prevent this Digimon's deletion.

node tools/kb/query.mjs card BT11-041 returned Q2075 and Q2076. Q2075
explicitly permits using an opposing Sukamon for the inherited prevention cost.
Q2076 allows distinct physical sources to participate in nested prevention but
forbids the source whose immediate prevention is already resolving from
reactivating. Ambiguity count is zero.

#### Implementation and snapshot comparison

apps/api/src/cards/BT11/BT11-041.ts has full coverage, an empty residual, and
only registerIrCard. Its two entry effects share the optional union-zone trash
cost, opponent target modifier, -1 Security Attack keyword, and
untilOpponentTurnEnd duration. Its inherited replacement uses an
any-controller, other-than-self Sukamon Digimon cost and an optional Prevent;
digivolutionRequirement carries the alternate level-4 Sukamon route at cost 3.

The exact shared correction already present from commit 834cc8e1f is in
apps/api/src/engine/effects/interpreter/costs.ts: the stack-cost classifier
recognizes an array zone containing digivolutionCards and routes payment
through trashDigivolutionCards. This makes a hand-or-own-stack payment
actually consume a selected evolution card while preserving stack semantics.
No new correction was needed in this pass.

The read-only snapshot entry matches the direct IR, including both triggers,
the union zone, alternate evolution, and any-controller prevention. Snapshot
drift is zero.

#### Seam, peer, and stack proof

The relevant seams are union loose-card/stack cost payment, optional cost-first
action resolution, inherited deletion replacement, and the shared
any-controller target matcher. BT11-040.ts and its tests provide the direct
Sukamon prevention peer; BT11-036 and BT11-040 provide realistic Chuumon to
Sukamon to Etemon naming and evolution-stack fixtures.

apps/api/src/cards/BT11/BT11-041.test.ts checks catalog and generated/direct
registration equality, hand payment, alternate Sukamon evolution at exactly 3,
the resulting -3000/SA-1 effect, friendly and opposing Q2075 costs, and the
Q2076 nested-re-entry boundary. The inherited source is carried under a host
permanent in the stack scenarios. Tests were reviewed but not executed.

#### Score and correction

Contract 2/2; direct IR 2/2; seams/peers 2/2; proof/stacks 2/2; execution 0/2.
Total 8/10 provisional. Historical shared-cost correction 834cc8e1f is
present and exact; no new correction or unresolved ambiguity remains.
