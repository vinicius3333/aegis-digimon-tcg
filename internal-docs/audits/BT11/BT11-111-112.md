## Shared interpreter, mechanism, and peer evidence

The relevant shared seams were traced directly:

- `apps/api/src/engine/effects/interpreter/actions/placeUnder.ts:287-390`
  resolves loose cards from the action's trash source, resolves the explicit
  `underFilter` host, and passes `belowTop: action.position !== "bottom"` to
  the primitive. Therefore BT11-111 needs both `underFilter: { isSelfRef:
  true }` and `position: "bottom"`; a broad own-Digimon host filter could
  prompt for a different permanent and the default position would be directly
  under its top card.
- `apps/api/src/engine/effects/primitives.ts:1617-1656` documents that
  `placeUnder` defaults to the stack bottom, while `belowTop: true` pushes
  directly beneath the top. The action interpreter's explicit bottom mapping
  is the stable contract used by the direct correction.
- `apps/api/src/engine/effects/interpreter/costs.ts:1145-1188` handles a
  `kind: "return"` cost whose target zone is `digivolutionCards` as loose
  stack instances. It enforces the required count, then routes
  `to: "deckBottom"` to `ctx.fx.returnToDeck(chosen, { toTop: false })`, which
  removes those cards from their host stacks and puts them at the bottom of
  their owners' decks. This is the required mechanism for BT11-111's
  leave-play replacement.
- `apps/api/src/engine/effects/interpreter/actions/board.ts:50-95` resolves
  `Suspend`, records the primitive's actual transition receipt, and returns
  an abort result when `abortOnDecline: true` and no permanent was really
  suspended. The distinction matters when Rina is already suspended: a
  selected-but-already-suspended Tamer must not permit the later
  `ActivateEffect` action to resolve.
- `apps/api/src/engine/effects/interpreter/actions/subTrigger.ts:994-1002`
  additionally preflights watchers whose action body has a self-suspension,
  excluding an already-suspended source from the event subscription's fire
  path. The card-level `abortOnDecline` is still retained as an action-local
  continuation guard for every path through the action sequence.
- `apps/api/src/engine/effects/interpreter/actions/borrowed.ts:296-320`
  translates `ActivateEffect` into the shared foreign-effect path, preserving
  its trigger and target. `resolvePermanentTargets` at
  `apps/api/src/engine/effects/interpreter/targeting/permanents.ts:373-403`
  resolves `sourceRef: "triggerSubject"` to the permanent that drove the
  event, satisfying Rina's “that Digimon” wording.
- Existing event peers use the same conventions. BT11-070 and BT21-060
  return Vemmon stack cards with `to: "deckBottom"` and
  `abortOnDecline: true`; BT13-075 uses a self-hosted stack `return` cost
  with `to: "deckBottom"`; BT19-083 uses a self-Tamer suspension with
  `abortOnDecline: true`; and BT2-004, BT15-005, BT24-022, and P-138 show the
  shared `whenUnsuspended` event-watcher family. No new engine seam was
  necessary.

#### Catalog contract and rules KB — 2/2; ambiguities: 0

The committed catalog record at `packages/shared/src/cards/data/cards.json:8527`
defines Galacticmon as a black level-6 Digimon with play cost 14, 14,000 DP,
and a black level-5 evolution for 6. Its alternate evolution is cost 9 from

`[Vemmon]` cards from your trash under this Digimon as its bottom

digivolution cards, delete one of the opponent's Digimon. Its All Turns
replacement triggers when this Digimon would leave the battle area and pays

`node tools/kb/query.mjs card BT11-111` returned Q2138–Q2141:

- Q2138 says De-Digivolve is not a would-leave-battle-area event for this
  replacement.
- Q2139 includes movement to trash, hand/deck, security, breeding, or under
  another card in the phrase “would leave the battle area.”
- Q2140 confirms the replacement can prevent a return to deck or security.
- Q2141 says the Start of Your Main Phase effect does not activate if an
  earlier phase effect has already moved memory to the opponent and changed
  the turn.

These rulings resolve the leave-play scope, destination, and timing edges;
there are no remaining contract ambiguities.

#### Direct IR and exact corrections — 2/2

   `{ names: ["Snatchmon"], cost: 9, isAlternate: true }`, matching the

2. The optional four-card trash placement is restricted to

   four Vemmon stack cards under the self host, with `to: "deckBottom"`.
   `optional: true` and `abortOnDecline: true` preserve the card's optional

   declined or unavailable. The replacement remains scoped to
   `sourceFilter: { isSelfRef: true }` and `event: "wouldLeavePlay"`.

### BT11-112 — Rina Shinomiya — 8/10 provisional (2+2+2+2+0)

#### Catalog contract and rules KB — 2/2; ambiguities: 0

The committed catalog record at `packages/shared/src/cards/data/cards.json:8552`
defines Rina Shinomiya as a blue play-cost-3 Tamer. Its On Play clause gives
one own Digimon with `Veemon` or `Veedramon` in its name Blocker and Evade
until the end of the opponent's turn. Its All Turns clause watches for one
own Digimon with `Veedramon` in its name becoming suspended; by suspending
this Tamer, it activates one of that Digimon's When Digivolving effects. Its
Your Turn/Once Per Turn clause gives one memory when one own blue Digimon
becomes unsuspended. Security plays Rina without paying her memory cost.

`node tools/kb/query.mjs card BT11-112` returned Q2142 and Q2143:

- Q2142 confirms that Rina is still suspended even when the Veedramon has no
  When Digivolving effect to activate. The suspension is not conditional on
  finding a borrowable effect.
- Q2143 confirms that after the Veedramon attacks and then evolves into a
  different Digimon, Rina can activate the current card's When Digivolving
  effect. This requires the activation target to be the event's trigger
  subject, not a stale pre-evolution card or an arbitrary Digimon.

The Q&A resolves the no-effect and post-evolution subject edges; ambiguity
count is zero.

#### Direct IR and exact correction — 2/2

`apps/api/src/cards/BT11/BT11-112.ts:3-91` is full coverage with an empty
residual and one exclusive `registerIrCard("BT11-112", compiled)` call. The
direct IR has the following verified mapping:

- On Play uses two owner-scoped name filters over Digimon whose names contain
  Veemon or Veedramon. Blocker and Evade have the opponent-turn-end duration,
  and the Evade action has `sameTarget: true`, so both keywords remain on the
  same selected Digimon.
- The All Turns body is a Static `whenSuspended` SubTrigger. Its source filter
  is an own Digimon whose name contains Veedramon. The first action targets
  the Tamer source with `isSelfRef`; the second activates one
  `WhenDigivolving` effect on `sourceRef: "triggerSubject"`.
- The direct correction adds `abortOnDecline: true` to the Tamer `Suspend`
  action. If Rina is already suspended or the suspension transition is
  otherwise unavailable, the interpreter's actual-transition receipt aborts
  the continuation, so the effect is not reactivated without paying the
  printed “by suspending this Tamer” cost. When the Veedramon has no
  When Digivolving effect, the Tamer still suspends before the activation
  path finds no eligible borrowed effect, as Q2142 requires.
- The Your Turn watcher remains a Static `whenUnsuspended` event subscription
  with an own blue-Digimon source filter, a nested `isYourTurn` condition on
  the memory action, and `frequency: "OncePerTurn"`. This is the direct
  executable event-bus representation of the printed timing clause.
- Security uses `PlayWithoutCost` on the self target with `payCost: false`
  and `isSecurity: true`.

Historical source/proof corrections already present after synchronization
were revalidated rather than duplicated: the On Play Evade target is bound to
the Blocker selection with `sameTarget`, and the All Turns activation uses
`sourceRef: "triggerSubject"`. This pass adds only the missing continuation
gate and its focused proof assertion.
