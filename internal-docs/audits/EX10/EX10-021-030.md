- **Clauses.** `[Digivolve] [Belphemon: Rage Mode]: Cost 1`; `[On Play] [When Digivolving] By

  affect it.`; `[Opponent's Turn] [Once Per Turn] When any of your opponent's Digimon suspend,
  by trashing 2 cards in your hand, suspend 2 of their Digimon or Tamers.` No Security text, no
  inherited text.
- **IR trace.** Two mirrored effects (`OnPlay`, `WhenDigivolving`), each a cost-bearing
  `Restrict{attack, untilOpponentTurnEnd}` with `cost.kind: "place"`,
  `destination: "digivolutionStack"`, `position: "top"`, `host: "self"`,

  subscription.
- **Defects corrected.** None. This module was already correct.
- **Tests added.** None; the existing suite already covers the positive path, refusal (neither
  restriction granted), the exact "Rage Mode only" name match against a near-miss trash card,

- **Mutation check.** Drop `abortOnDecline` → "may refuse the Rage Mode placement and then gains

  `stack.at(-1)` assertion fails. Change the cost count 2→1 → "cannot partially pay" fails.

  `frequency` → the second `fireSubTrigger` trashes two more cards and `trash` is no longer 2.
- **Open ambiguity.** Q5071 (an effect granted to an immune card does not trigger) is engine
  behaviour and is not pinned by this card's suite.

### EX10-023 Quartzmon (Green/Black, Lv.7 Mega ACE, [Unidentified], 9/15000, overflow 5)

- **Clauses.** `[Digivolve] While you have [Ryoma Mogami], [Astamon]: Cost 7`; `[Hand] [Counter]
  ＜Blast Digivolve＞`; `[On Play] [When Digivolving] Suspend all other Digimon and Tamers.`;
  `[When Digivolving] [When Attacking] [Once Per Turn] Delete 1 of your opponent's suspended
  Digimon.`; `[All Turns] Other than this Digimon, no Digimon or Tamers can unsuspend in the
  unsuspend phase.` ACE with `overflowMemory: 5` (a catalog fact, not an IR clause).
- **IR trace.** `Counter` + `isFromHand` keyword record for ＜Blast Digivolve＞; `OnPlay` and
  `WhenDigivolving` `Suspend` with `count: "all"` and `{ controllerDefault: "any",
  excludeSelf: true, kind: ["Digimon", "Tamer"] }`; `WhenDigivolving` and `WhenAttacking`
  `Delete` sharing `sharedUseKey: "EX10-023/suspended-delete"` so the printed single [Once Per
  Turn] budget spans both timings; `AllTurns` `Restrict{unsuspend}` over the same "everything
  but me" pool.
- **Defects corrected.**
  1. `duration: "untilEachTurnEnd"` → `"forTheTurn"` (see §3). Behaviour-identical; it removes
     the reliance on `toDuration`'s `default` branch.
  2. `controllerControls: { kind: ["Tamer"], … }` → `{ kind: ["Digimon", "Tamer"], … }`. "While
     you have [X]" is a "you have" clause (CR 16-42-3): it is satisfied by a Digimon **or** a
     Tamer with that name. Only Tamers are named Ryoma Mogami today (BT12-097, EX10-067), so
     this is a correctness alignment rather than an observable behaviour change, and it is
     recorded as such.
- **Tests added (3, all passing).**
  1. "keeps the unsuspend lock on a Digimon that entered after Quartzmon resolved" — an
     [All Turns] static must cover later entrants, which is the property that makes the
     `UntilEachTurnEnd` duration safe. This is also the observable benefit `restrictPlayer`
     would have bought, and it is already delivered by the current form.
  2. "Q5075 the opponent's unsuspend phase flips nothing but Quartzmon's own controller's exempt
     card" — drives the real `unsuspendForActivePhase(seat)` rather than reading the restriction
     ledger: seat 1's phase returns `[]` with both permanents still suspended, seat 0's returns
     exactly Quartzmon's id. This is the printed clause's actual scope, proven at the phase.
  3. "the lock currently also blocks effect-driven unsuspension, which is broader than the
     printed phase scope" — the boundary case (below), with a Quartzmon-free control that
     unsuspends normally.
  The IR assertions for the duration and for the widened `controllerControls` were updated.
- **Mutation check.** Drop `excludeSelf` → "never itself" and "Quartzmon remains exempt" fail.
  Remove `sharedUseKey` → the second delete in "shares the once-per-turn identity" removes
  `second`. Change the `Delete` filter's `suspended: true` → `standing` is deleted. Change
  `namesExact` to `names` → the negative base case in the alternate-route test passes wrongly.
  Remove `controllerControls` → the "Astamon base without Ryoma" case succeeds.
- **`restrictPlayer`: investigated and deliberately not adopted.** `restrictions.ts:83-95` takes
  the `restrictPlayer` path only for `whileMatchesTargetFilter: true` + `count: "all"`, and it
  records **the same `Restriction` kind** per seat with a dynamic predicate. It changes *who is
  covered* (dynamic membership), not *when the prohibition applies*. It therefore cannot express
  "in the unsuspend phase", which is the actual divergence, and the dynamic-membership benefit
  is already proven by test 1 above — the `staticModifier` re-derivation covers later entrants
  without it. Switching would have been an unobservable rewrite of a passing clause.
- **Gap, stated precisely (seam §6.3).** `Restriction` has one unscoped `"unsuspend"` member and
  two consumers read it: `GameEngine.unsuspendForActivePhase` / `unsuspendRebootForSeat` (the
  unsuspend phase, which is what Quartzmon prints) **and** `primitives.unsuspend` (every
  effect-driven unsuspension), the latter deliberately — its comment says "'Can't unsuspend' is
  not limited to the Active phase … the Samādhi Śānti and the wider freeze family". Quartzmon is
  not a freeze card: its clause ends at the unsuspend phase, so a mid-turn "unsuspend 1 of your
  Digimon" effect should still resolve and currently does not. Test 3 pins exactly that boundary
  so the divergence is observable rather than assumed. No phase-scoped restriction kind exists,
  and adding one is an engine change.
