## Provisional totals, corrections, and limitations

- **BT19-071 — 7/10 provisional.** No direct code change was required. The direct module provides the missing executable discard-library watcher that the generated record leaves unresolved; behavioral evidence is limited by manually firing On Play.
- **BT19-072 — 6/10 provisional.** No direct code change was required. Structural proof covers registration and effect shape, but no natural behavior assertion is present.
- **BT19-073 — 6/10 provisional.** No direct code change was required. The direct module corrects generated target binding/restriction semantics; available proof remains structural.
- **BT19-074 — 6/10 provisional.** Added `to: "deckTop"` to the ten-card return cost; without an explicit destination, the shared return-cost interpreter cannot honor the printed top-deck destination. Updated the direct runtime assertion.
- **BT19-075 — 7/10 provisional.** No direct code change was required. The direct module corrects generated hand-choice and deletion-scaling semantics; manually fired On Play is supplemental behavioral evidence.
- **BT19-076 — 6/10 provisional.** No direct code change was required. Structural proof covers the full reveal/play/Save IR, but no natural behavior assertion is present.
- **BT19-077 — 6/10 provisional.** Added `payCost: true` to the Main Digivolve action; shared `runDigivolve` treats an omitted payment flag as free, which would incorrectly bypass the reduced evolution cost. Updated the direct runtime assertion.
- **BT19-078 — 7/10 provisional.** No direct code change was required. Manual On Play timing provides supplemental debuff evidence; the stack-play and optional redirect path remains unexecuted.
- **BT19-079 — 8/10 provisional.** No direct code change was required. The direct module is necessary for the dedicated under-Tamer DigiXros expansion seam, and the source includes natural public-intent positive and negative behavior proof.
- **BT19-080 — 6/10 provisional.** Changed the watcher from `AllTurns` to `YourTurn`, made the Tamer suspension an optional aborting gate before the mandatory attack, and changed the attack to normal suspension. These corrections align direct runtime behavior with the catalog and KB Q3141; available proof remains structural.
