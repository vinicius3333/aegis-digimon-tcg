# BT19-031–BT19-040 audit

## Scope and scoring

This audit covers BT19-031 through BT19-040 in strict ascending card-ID order. The catalog source was `packages/shared/src/cards/data/cards.json` at immutable catalog blob `efbecc002fb9000789123e2f91f201466e1e5b0a` (SHA-256 `d9c3892e26c3bee5f800557f6619eb413d39cdc1e7460fa70c291af5ac135ca8`). The generated IR snapshot `packages/shared/src/effects/effects.json` was inspected read-only (SHA-256 `fb2f278d4a77b940be0bda05141b308a07a3787dfcd54abdc53d00340bf661cf`) and was not edited.

Each card is scored on the five required two-point dimensions: Catalog/rules, IR trace, Behavioral proof, Peer and stack proof, and Executed delivery gates. The first four dimensions are 2/2 where the committed source and behavior-driving tests provide reproducible evidence; Executed delivery gates are fixed at 0/2 because this dispatch explicitly prohibited execution. Every score below is therefore provisional 8/10, not a claim of collection completion.

The ten audited modules each have exactly one `registerIrCard("BT19-<id>", compiled)` registration and no `registerCard` registration. The direct TypeScript modules are the executable source registered by the interpreter; the generated snapshot remains a read-only comparison artifact and is stale for several audited repairs. Shared runtime traces covered effect dispatch, target and source-zone resolution, optional-cost abort semantics, name/trait and color matching, DigiXros-only aliases, Option-use event payloads, restrictions, replacement costs, security operations, token registration, and inherited-effect collection.
