## Scope and evidence

This report covers exactly BT19-011 through BT19-020, inspected in strict
ascending card-ID order. The immutable catalog source is the committed Git
blob `efbecc002fb9000789123e2f91f201466e1e5b0a`. Each card was compared with
the local rules knowledge base, direct TypeScript module, generated IR and
shared interpreter, neighboring implementations, legal evolution/DigiXros
stacks, and behavior-driving test source.

All ten audited modules have `coverage: "full"`, `residual: []`, exactly one
`registerIrCard("BT19-NNN", compiled)` registration, and no `registerCard`
registration. The generated `packages/shared/src/effects/effects.json` and
`BT19-STATIC-AUDIT.md` were inspected read-only and were not modified.

The score has exactly five two-point components: Catalog/rules, IR trace,
Behavioral proof, Peer and stack proof, and Executed delivery gates. Executed
delivery gates are fixed at `0/2` because this dispatch explicitly prohibited
tests, typecheck, lint, formatter, browser checks, focused/mechanism/collection
gates, and `git diff --check`. Structural assertions and manually injected
timings are not counted as behavioral proof when a natural public origin is
available; the behavioral scores below therefore distinguish source evidence
from actual natural-origin coverage. All totals are provisional and no card is
claimed as 10/10.

## Shared runtime and generated-IR trace

The shared interpreter paths inspected for this range include:

- `DeleteByDPBudget`, its dedicated and generic deletion-cap ledgers, live
  DP candidate selection, and `deletedByThisEffect` result binding used by
  BT19-011;
- DigiXros-only name grants and ordinary-name exclusion used by BT19-012,
  exact DigiXros slot validation used by BT19-013/014, and alternate
  digivolution requirements;
- replacement leave processing, stack-to-Tamer Save placement, free play from
  under-Tamers, and action ordering used by BT19-013/020;
- distinct source-stack color scaling, relative-to-source DP targeting,
  mandatory deletion/fallback result binding, and temporal keyword/DP effects
  used by BT19-014/015;
- placement-as-cost followed by draw, reveal/add with non-duplicating target
  selection and deck-bottom remainder, Rule trait grants, Evade, and
  condition count limits used by BT19-016 through BT19-019.

The read-only generated records exposed several known parser/normalization
differences that the direct modules already reconcile: BT19-011's generic
delete/cap form versus the direct budget action; BT19-012's ordinary Shoutmon
alias; BT19-013/014's collapsed DigiXros recipes and BT19-014's broad source
color/under-Tamer shapes; BT19-015's missing Piercing fallback; BT19-017's
`trait` rather than `traitContains` matching; BT19-019's raw Tamer condition;
and BT19-020's stale generated optional marker on the post-Then Save action.
The direct modules are the executable registration source. The shared
`DIGIXROS_REQUIREMENT_OVERRIDES` already supplied BT19-013 and BT19-014 to the
legality subsystem; BT19-013 now also carries the same five-slot recipe in its
direct compiled object for a complete IR trace.

### BT19-011 — WarGrowlmon — 6/10 provisional

- **Catalog/rules — 2/2.** The immutable catalog identifies a Red level-5
  Cyborg/Virus ACE with Blast Digivolve, On Play/When Digivolving deletion of
  opponent Digimon within a base 3000 DP budget plus 2000 for each opponent
  Digimon, followed by one memory per deletion. The inherited clause adds 3000
  to this Digimon's printed DP-deletion maximum. Q6016 was applied to the
  continuation after source removal.
- **IR trace — 2/2.** `BT19-011.ts` uses `DeleteByDPBudget` on both triggers,
  scales the budget from live opposing Digimon cards, and binds memory gain to
  the actual Digimon deleted by that effect. The inherited
  `DeletionMaxDpModifier` is self-scoped and permanent. The ACE counter marker,
  full coverage, empty residual, and exclusive registration are present.

  and memory, but drives both On Play and When Digivolving with
  `advance(...).fire` and drives the inherited case with another injected
  timing. Natural play/evolution is feasible, so these source assertions are
  not counted as natural behavioral proof under this audit boundary.
- **Peer and stack proof — 2/2.** The budget action was checked against the
  shared deletion-capability tests and neighboring DP-budget cards. The source
  stack fixture includes BT19-011 under a host, and the runtime path confirms
  the aggregate DP maximum and result-bound memory accounting.
- **Executed delivery gates — 0/2.** Deferred by instruction; no gates were
  executed.
- **Correction status:** no new production correction in this dispatch. The
  existing direct module is the scoped implementation and supersedes the
  generic generated record.
