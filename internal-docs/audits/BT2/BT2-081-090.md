## Scoring policy

Each card receives five integer components worth two points each:

1. Catalog and rules — exact printed data, traits, and applicable rules/KB evidence.
2. IR trace — direct module action mapping, generated snapshot comparison, and interpreter primitive trace.
3. Behavioral proof — focused tests and the added aggregate direct-IR assertions are present; they were not executed.
4. Peer and stack proof — same-mechanism peers, trait boundaries, and legal source/evolution stacks were inspected.
5. Executed gates — deliberately 0/2 because the task prohibits tests, typecheck, lint, formatting, and git diff --check.

Every card below is 2/2 + 2/2 + 2/2 + 2/2 + 0/2 = **8/10 provisional**. No card is above 8/10, and this report makes no collection-completion claim.

## Static-only evidence policy

This audit followed the repository `verify-card-implementation` workflow card by card. I inspected the committed catalog, card-specific KB results, rules KB, direct TypeScript modules, generated effects snapshot, shared IR/interpreter primitives, focused tests, aggregate tests, traits, same-mechanism peers, legal source stacks, and banlist data where applicable.

No behavioral test, typecheck, lint, formatter, or git diff --check was run. The exact deferred commands are recorded at the end of this report.
