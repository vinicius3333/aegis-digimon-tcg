## Scope and canonical result

This report audits BT2-091 through BT2-100 in strict ascending order against the committed catalog, card-local rules and KB material, direct TypeScript modules, generated effects snapshot, shared interpreter primitives, focused tests, aggregate IR coverage, catalog kinds/traits, same-mechanism peers, and legal source-stack fixtures. All ten cards are Options and have no inherited effects or evolution-dependent card behavior. The source-stack tests for BT2-094, BT2-095, and BT2-096 nevertheless use legal same-color evolution stacks because those cards explicitly trash sources when resolving a return/source-selection effect.

Every audited module registers executable behavior only through `registerIrCard(cardId, compiled)`; no duplicate `registerCard` registration was added or retained. Existing direct IR already corrects three stale generated records: BT2-093's red-Tamer branch is exclusive, while BT2-095 and BT2-096 return only the selected opponent Digimon(s) and rely on the return primitive to trash only those sources. The generated snapshot is retained as committed evidence; `registerIrCard` writes the normalized direct record into the runtime registry, so the direct module is authoritative when these records differ (`docs/ARCHITECTURE.md:48-51`, `apps/api/src/engine/effects/interpreter/compiledCards.ts:7-20`, `apps/api/src/engine/effects/interpreter/registration/module.ts:312-341`).

All cards receive the canonical provisional score `8/10`: catalog and rules `2/2`, IR trace `2/2`, behavioral proof `2/2`, peer and stack proof `2/2`, and executed gates `0/2`. No card is claimed complete, and this range does not claim BT2 collection completion.
