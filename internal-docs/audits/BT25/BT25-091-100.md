## Card findings

### BT25-091 Monica Simmons

The catalog defines Monica as a Black, level-less TS Tamer costing 4. At the start of the owner's turn, memory is set to 3 when it is 2 or less. On Play, the controller may return one TS Option from trash to hand; if the return did not happen, the card draws 1. During the owner's turn, using a TS Option lets the controller suspend Monica to prevent one opposing Digimon from attacking until the opponent's turn ends. Security plays Monica for free.

The IR preserves the memory boundary, the optional return and `ifThisEffectDidNotAct` draw, the TS Option watcher, the suspension cost, the one-opponent-Digimon restriction, and free Security play. Source tests use real `playCard` Option origins, test declined/no-target returns, distinguish Security activation from Option use, cover non-TS Options and suspension decline, and test the start-turn boundary. Q6430-Q6433 are reflected in the action ordering and watcher filter.

Peers BT25-092/086/087/088/090 establish the adjacent Tamer timing and resource patterns; BT25-094/095/097/099 establish TS Option use and Security-origin boundaries. No semantic correction was required.

### BT25-092 Asuna Shiroki

The catalog defines Asuna as a Purple TS Tamer costing 4. At the start of the owner's Main Phase, the controller trashes one hand card with Three Musketeers in its text or the TS trait, then draws 1 and gains 1 memory. Main requires suspending Asuna and trashing one Option from hand or one of the controller's Digimon's digivolution cards; one own Digimon may then digivolve into a Three Musketeers-in-text or TS Digimon from hand or trash with the cost reduced by 1. Security plays Asuna for free.

The IR retains the Start Main hand filter and draw/memory tail. The Main processing condition is now one `CostGatedBlock` with a compound suspend-plus-trash cost, followed by the optional reduced digivolution. This prevents a suspended Asuna from paying the Option cost or reaching the evolution clause. The new source test resolves the public `activateEffect` intent through `effectsOf(OnDeclaration, cardSourceOf(...))`, expects `illegal-target`, and verifies that the Option and host remain unchanged. Existing tests cover successful hand/stack payment, the two-copy boundary, the Tamer-stack negative, Start Main refusal, and Security play. Q6434-Q6435 are represented directly.

Peers BT25-091/086/087/088/090 cover Tamer phase and payment patterns, while BT25-083/085/093 provide Three Musketeers, TS, Option, and Link-era stack comparisons. The local atomic-cost correction is the only reason this card differs from its assigned-base implementation. Behavioral credit remains 1/2 because the positive Main proof is still a manual timing-seam drive.

### BT25-093 Ignition Flare

The catalog defines Ignition Flare as a Red TS Option costing 5. Its TS Use Req. waives the color requirement. Security activates its Main effects. Main deletes all opposing Digimon with the lowest DP; if none were deleted, it trashes one opposing Option in the battle area, then may link itself to one own Digimon on the field without paying the Link cost. The linked card has 2000 DP, requires TS at Link cost 3, and has a once-per-turn When Attacking deletion against an opposing Digimon whose DP is no higher than the host.

The IR keeps the exact lowest-DP all-target deletion, the placed-Option fallback, optional free Link to battle or breeding, Link requirement/DP, and relative-DP linked deletion. The Use Req. waiver was corrected to require a TS Digimon or Tamer in the battle area; a TS Digimon in breeding and a TS Option in the battle area are now rejected, as demonstrated by new natural `playCard` source tests. Existing tests cover deletion prevention and lowest ties, Security activation, natural Option use, linked attack/Once Per Turn, and the Digimon-effect classification. Q6436-Q6443 are reflected in the filters, placement marker, source-kind handling, and recipient allowance.

Peers BT25-094/095/097/099 establish the TS Option/security model; BT25-076/080 validate lowest-target and fallback behavior; BT25-100 provides the adjacent TS Link Option. The local Use Req. filter correction is the only semantic change for this card.
