## Card findings

### BT25-001 Tokomon

- Catalog: Red Digi-Egg, level 2, In-Training, Lesser/Iliad/TS, inherited Draw 1 when attacking once per turn if the stack has TS.
- IR: `WhenAttacking` inherited effect, `selfHasTrait` TS condition, Draw 1 for the controller, `OncePerTurn`, `coverage: "full"`, `residual: []`.
- Runtime trace: `selfHasTrait` reads the live stack’s top-card trait union; the inherited source is anchored to the host permanent, and the once-per-turn ledger gates the second attack.
- Behavioral evidence: public attacks prove one draw on a TS host, no draw on a non-TS host, and no second draw after unsuspend.
- Peer/stack: host-stack tests use the engine’s normal inherited-effect path; registration is sole `registerIrCard("BT25-001", compiled)`.

### BT25-002 Wanyamon

- Catalog: Blue Digi-Egg, level 2, In-Training, Lesser/DATA SQUAD, inherited both players Draw 1 when one of the controller’s DATA SQUAD Tamers is played once per turn.
- IR: `YourTurn` inherited `SubTrigger` on `whenPlayed`, source-filtered to controller-owned Tamer cards with DATA SQUAD, with one Draw action for each player, `OncePerTurn`, full/residual-free.
- Runtime trace: the played permanent is matched by the canonical source filter; the inherited watcher is scoped to the Wanyamon host and its turn scope/frequency are applied by the subtrigger interpreter.
- Behavioral evidence: natural public Tamer play proves both draws and once-per-turn behavior; opponent-turn play is negative.
- Peer/stack: the stack host is created through normal setup and the watcher is registered only by `registerIrCard("BT25-002", compiled)`.

### BT25-003 Frimon

- Catalog: Yellow Digi-Egg, level 2, In-Training, Lesser/Glowing Dawn/BEATBREAK, inherited optional attack digivolution into a Glowing Dawn hand card for 1 less after trashing top security.
- IR: `WhenAttacking` inherited optional Digivolve from hand with Glowing Dawn trait, `payCost: true`, `reduceCost: 1`, and a top-own-security trash cost with `abortOnDecline`; full/residual-free.
- Runtime trace: the security cost is paid before the optional digivolution, the destination is selected from hand, and decline leaves the security, hand, memory, and stack unchanged.
- Behavioral evidence: public attack proves the security removal, reduced memory payment, selected destination, and decline path.
- Peer/stack: the digivolution is placed on the existing host stack through the normal engine path; registration is sole `registerIrCard("BT25-003", compiled)`.

### BT25-004 Tapmon

- Catalog: Green Digi-Egg, level 2, Appmon form, Tool attribute, Tap type, inherited Your Turn/Once Per Turn reduction for Social, Tool, or Game cards linking to this Digimon.
- IR: hand-authored but compiled `GrantLinkCostReduction` effect; recipient is self, amount 1, matching traits are Social/Tool/Game, declaration optionality and once-per-turn consumption are explicit, full/residual-free.
- Runtime trace: continuous effects install a recipient-scoped grant; link cost lookup takes the largest single matching reduction, so multiple reductions do not stack; `runLink` consumes the optional grant only on acceptance.
- Behavioral evidence: source proof includes grant-on/off and non-stacking isolation plus a public live-engine Link declaration on a legal stack, proving a Social link costs 0 instead of 1 and is installed on the recipient regardless of declarer.
- Peer/stack: Link procedure, recipient ownership, optional-at-declaration timing, and linked-card placement were compared with the neighboring Link implementations and interpreter. Sole registration is `registerIrCard("BT25-004", compiled)`; no legacy duplicate exists.
