## BT23-079 Eri Karan — 10/10

Blue App Driver/Appmon Tamer, cost 3. Start-main gains 1 if the opponent has a Digimon. On the controller's turn, linking an own Digimon may suspend Eri to give that exact Digimon +3000 DP through the opponent turn, then optionally App Fuse one own Digimon using a Digimon in hand; Security self-plays. Q5354 requires the suspend cost to gate the App Fuse tail. The prior IR placed App Fuse outside the linked watcher; it is now ordered inside the subtrigger after the cost-gated DP action. Public proof observes source suspension, exact trigger-subject DP and non-target stability; clause nesting, refusal, duration, App Fuse choice and Security are mapped.

## BT23-078 Gorou Matayoshi — 10/10

Red CS Tamer, cost 3. Catalog and the 2025-10-17 erratum establish the English name `Gorou Matayoshi`. Start-main gains 1 if the opponent has a Digimon. During the controller's turn, a qualifying own play/evolution (Avian, Bird, Beast, Animal or Sovereign in any trait other than Sea Animal, or CS) returns Gorou to hand, buffs one own Digimon +3000 for the turn, then may make one own Digimon attack; Security self-plays. Q5353 gates the attack tail on the return cost. Public tests cover qualifying play, Sea Animal exclusion, returned source, DP result and owner-turn memory. The start-main owner guard was corrected.

Keyword, controller, cost ceiling, count, source identity, stack ordering and de-digivolution floor map to shared tested primitives.
