### Follow-up: placed-card accumulator lifetime

The `placedUnderInstanceIdsThisEffect` field was **not** guaranteed fresh for
every independent effect resolution before this follow-up. Ordinary timing
collection usually creates a new context, but `GameEngine.fireBeforePayCost`
and nested effect paths deliberately seed/reuse a context with `selections` so
that result values can be returned to the caller. `runEffect` therefore may
operate on the same object across independent effects. `runPlaceUnder` appended
to the existing array (`placeUnder.ts:12–19`), while `scaleFactor` read its full
length for `unit: "placedCards"` (`scaling.ts:210–212`); a prior effect's
placements could consequently inflate a later effect's memory gain.

The smallest safe reset is now at the action-bearing `runEffect` boundary
(`interpreter/effect.ts:596–625`): it saves the caller's outer accumulator,
sets `placedUnderInstanceIdsThisEffect` to a new empty array before dispatching
the action list, and restores the outer value in `finally`. This keeps all
three BT9-067 PlaceUnder actions in one resolution visible to their following
GainMemory action, prevents independent effect overcount, and isolates nested
resolutions without changing the public IR or generated snapshot. The
`EffectContext` contract documents this lifecycle at `:1923–1929`.

The static trace also checked the early keyword-only return in `runEffect`: it
cannot read `placedCards`, while every action-bearing path reaches the reset
and restoration block. No ambiguity remains; a runtime regression test remains
deferred with the other prohibited gates.

Errata and color boundaries were checked against `data/kb/errata.json`, rules
§4-8/§15-15-4, and `conditions.ts:610–617`. The legal Black level-5 and
alternate Black level-6 evolution requirements were inspected.

Snapshot evidence (`effects.json:121948–122028`) materially drifts: it merges
the three names into one broad OR selection, omits bottom position, scales
memory using the live board rather than actual placements, and leaves the
color conditions as raw text. The direct module and the new shared scaling
