## 4. Per-card findings

### EX11-011 Dinomon — no defect found

Clauses: Red/Green, Lv.6, 13000 DP, play 13, evo Red/Green Lv.5 cost 5; alternate
`[Digivolve] Lv.5 w/[Tyrannomon] in name or w/[Dinosaur] trait: Cost 4`; ＜Security A. +1＞;
＜Fortitude＞; `[On Play] [When Digivolving]` may suspend 1 Digimon, then choose 1 of **each**
player's highest-play-cost Digimon and delete all others; `[Opponent's Turn]` while suspended,
all opponent Digimon can only attack suspended Digimon. No inherited or Security text.

IR trace: both entry timings map to `Suspend (optional, controllerDefault any)` →
`SelectBind mine/highestPlayCost` → `SelectBind opponent/highestPlayCost` →
`Delete count:"all"` filtered by `excludeSelectionRef`. `upTo: true` on each bind is what
implements Q5796 (no choosable Digimon ⇒ no exemption ⇒ everything is deleted). The delete is
correctly not `optional` — only the suspension is "may". The `[Opponent's Turn]` aura installs
the `attackOnlySuspendedDigimon` restriction, which `combat/legality.ts` enforces at declaration
only (Q5798) and which the "unaffected by effects" guard skips (Q5799).

Test added: **"restricts opposing attacks only on the opponent's turn and only while
suspended"** — asserts the restriction is absent on your own turn, present on the opponent's
turn, and gone again once Dinomon unsuspends. Mutation check: dropping `trigger:
"OpponentsTurn"` or `while: { kind: "selfIsSuspended" }` now fails a named assertion; nothing in
the pre-existing suite covered either field's negative side.

Other mutation-check anchors (pre-existing): `superlative` → "chooses exactly one among tied
highest-play-cost opponent Digimon"; `excludeSelectionRef` → "deletes every non-chosen Digimon…";
`optional: true` on `Suspend` → same test (`autoDeclineOptional` and Dinomon stays unsuspended);
`amount: 1` on ＜Security A. +1＞ and ＜Fortitude＞ → "publishes both keywords only on Dinomon
itself and replays through Fortitude"; both alternate requirement rows → the `it.each` evolution
test plus the "rejects the alternate path" negative.

### EX11-012 Medusamon — type error resolved, semantics unchanged

Clauses: Red, Lv.6, 12000 DP, play 11, evo Red Lv.5 cost 3; ＜Rush＞; ＜Progress＞;
`[When Digivolving] [End of Attack]` may delete 1 opponent Digimon with DP ≤ this Digimon's,
then by returning 1 card from the opponent's trash to the bottom of the deck, **they** play 1
[Petrification] Token; `[All Turns]` when this Digimon would leave the battle area, by deleting
1 Token it doesn't leave.

Type error (lines 45 and 86 before the fix): `PlayTokenAction` (`ir/actions/play.ts:193`) makes
`tokens`, `count` and `payCost` **required**; `token`/`amount` are documented aliases only. The
module supplied only the aliases, so the object was not assignable to `Action`. It was not a
semantic defect in this engine — `actions/play.ts:842` reads `action.tokens ?? [action.token]`
and `action.count ?? action.amount ?? 1`, precisely because a singular-form card was once
silently inert. `placedAs: "opponentDigimon"` and `controller` are both real fields the
interpreter reads (`placedAs` chooses the placement seat, `controller` is attribution only).

Fix (before → after), applied at both timings:

```ts
- kind: "PlayToken", token: "Petrification Token", amount: 1,
+ kind: "PlayToken", tokens: ["Petrification Token"], count: 1, payCost: false,
  controller: "mine", placedAs: "opponentDigimon", cost: { kind: "return", … to: "deckBottom" }
```

This is the shape BT24-017 already uses for the same token. `EX11-012.test.ts`'s IR assertion was
updated to match. Mutation check: the token **name** is pinned by the behavioural tests that
assert a `TOKEN-Petrification-Token` permanent appears under seat 1 — the persisted record's
`"Petrification"` would resolve to `undefined` and fail them; `placedAs` is pinned by
`expect(token.controllerSeat).toBe(1)`; `to: "deckBottom"` by
`expect(deck.at(-1)?.instanceId).toBe(returnedId)`; `cost.kind: "deleteOwn"` with
`filter: { isToken: true }` by the three prevention tests (including the one that pays with the
*opponent's* token, which the printed unpossessed "1 Token" allows).

No further defect found. The `OnDeletion` security trash that the persisted record attributes to
Medusamon belongs to the token; the suite asserts `compiled.effects.some(trigger ===
"OnDeletion") === false` and separately exercises the token's own On Deletion.

### EX11-017 Skadimon — no module defect; two test gaps closed

Clauses: ＜Ice Clad＞; ＜Barrier＞; `[On Play] [When Digivolving] [When Attacking] [Once Per Turn]`
may play 1 [Suzune Kazuki] **or** a level 4 or lower [Ice-Snow] Digimon from hand for free;
`[All Turns] [Once Per Turn]` when **other Digimon** are played or digivolve, trash any 3
digivolution cards from the opponent's Digimon, then 1 of their Digimon with no digivolution
cards can't suspend until their turn ends.

IR trace: the three timings share `sharedUseKey: "ir-shared-0"` with `frequency: "OncePerTurn"`,
so the printed single [Once Per Turn] covers all three. The union target is expressed as
`filter` (Suzune by name) + `orFilters[0]` (Digimon, `levelComparison lte 4`, Ice-Snow trait) —
correctly keeping the level and trait gates off the Tamer branch. The watcher pair
(`whenPlayed`, `whenAnyDigivolves`) uses `sourceFilter: { excludeSelf: true, kind: ["Digimon"] }`
with **no controller**, matching "other Digimon" (either player's). `Restrict { restriction:
"suspend", blocksCombatSuspend: true }` records both `beSuspended` and `suspend`
(`actions/restrictions.ts:63-121`), which is what a printed "can't suspend" must do: it blocks
both being suspended by effects and suspending to declare an attack.

Tests added:
1. **"watches the opponent's plays too, and blocks both being suspended and suspending to
   attack"** — fires `whenPlayed` with an **opponent's** Digimon as subject and asserts the three
   pooled digivolution cards are trashed and that exactly one source-less opponent Digimon holds
   both the `suspend` and `beSuspended` restrictions. Mutation check: re-adding the persisted
   record's `controllerDefault: "mine"` to `sourceFilter`, or dropping `blocksCombatSuspend`,
   now fails this test; nothing previously covered the opponent-side subject.
2. `blocksCombatSuspend: true` added to the IR-shape assertion in "publishes the pooled watcher
   and its until-opponent-turn-end suspension restriction".

Other anchors (pre-existing): `orFilters` → the `it.each` pair that plays a Tamer and a level-3
Ice-Snow Digimon and the pair that refuses a level-5 Ice-Snow and a level-4 non-Ice-Snow;
`sharedUseKey` → "spends the shared once-per-turn use at only the first of its three timings";
`amount: 3` and `scope` → "trashes exactly three sources across opposing stacks";
`excludeSelf` → "ignores Skadimon itself"; ＜Barrier＞ and ＜Ice Clad＞ → their combat tests.

### EX11-018 Ryugumon — Decode host scope made explicit, plus the neighbor-stack negative

Clauses: ＜Evade＞; ＜Decode (Lv.5 or lower w/[Aqua]/[Sea Animal] in any trait)＞;
`[On Play] [When Digivolving] [When Attacking] [Once Per Turn]` by placing 1 Digimon card with
[Aqua] or [Sea Animal] in any of its traits from hand as **this Digimon's bottom** digivolution
card, 1 of your Digimon unsuspends; `[All Turns] [Once Per Turn]` when effects add to this
Digimon's digivolution cards, return 1 opponent Digimon with as many or fewer digivolution cards
as this Digimon to the bottom of the deck.

Defect corrected (before → after) in the ＜Decode＞ replacement's `PlayWithoutCost` target:

```ts
  filter: {
    controller: "mine",
    kind: ["Digimon"],
+   hostFilter: { isSelfRef: true },
    levelComparison: { op: "lte", value: 5 },
    nameOrTrait: [{ tokens: ["Aqua", "Sea Animal"], match: "traitContains" }],
  },
```

Severity: **latent, not live.** `applyDecodeHostScope` (`actions/play.ts:72-85`) already injects
`hostFilter: { isSelfRef: true }` for any `playedByDecode` play that names no host scope, so the
engine default was already correct; the IR now states CR 16-36-1 itself and cannot silently
regress if that default is ever narrowed. The module's stale auto-generated header comment was
replaced with the audited rationale.

`match: "traitContains"` (not `trait`) is required and correct: `matching/definition.ts:356` does
a substring compare over `staticTraitsOf` = forms ∪ attributes ∪ types ∪ `[Rule] Trait:` grants.
No printed trait is literally `Aqua`; the clause is meant to reach `Aquatic`, `Aquabeast` and
`Ancient Aquabeast`, and via the `[Rule] Trait: Has [Aquatic] Type` line it also reaches
EX12-031 MarineBullmon, which the existing suite uses as its second Decode branch.

Test added: **"plays only from its own digivolution cards, never from a neighbor's stack"** —
modelled on EX12-014's: a neighbouring permanent holds an eligible Decode candidate, Ryugumon is
deleted `byEffect` with nothing eligible in its own stack, and the assertions are that the
foreign card never enters the battle area and stays in the neighbour's stack. Ryugumon is set up
**suspended**, exactly as the file's other Decode tests do: ＜Evade＞ prevents a leave by
suspending, so an unsuspended Ryugumon opens an `evadePrompt` that no intent answers and the
deletion never resolves (this is what made the first version of the test time out at 15s). A
suspended Ryugumon cannot pay Evade, so the deletion proceeds and the Decode scope is what is
actually under test. `hostFilter:
{ isSelfRef: true }` was also added to the test's IR-shape assertion.

On the `AllTurns` watcher: `sourceFilter` deliberately carries **no** `byEffect: true` even
though the text says "when **effects** add". The `onAddDigivolutionCards` bus is fired only from
`primitives.placeUnder`, `placeUnderFromDeck`, `relocatePermanentByEffect`, the top-card rotation
seam, and `breeding.ts`'s egg placements — never by ordinary digivolution — so the event is
already effect-only. Adding `byEffect: true` would additionally require a non-empty
`effectSeatStack` (`subTrigger.ts:314-318`) and risks silencing the card's own paid-cost combo;
it is left off deliberately and recorded here.

Other anchors (pre-existing): `position: "bottom"` + `host: "self"` → the stack-order assertion
`[aquaticCost, oldBottom]`; `abortOnDecline` → "does nothing when the optional placement cost is
declined"; `traitContains` → the "does nothing without an Aqua/Sea Animal-containing hand card"
