# EX8 Runtime Re-audit — 2026-08-27

This is a fresh card-by-card re-audit of EX8 on branch `audit-ex8-luna`, based on
`c0ee1a4ba190c0ce40902913cc6e29eca9da1115`. The existing `EX8-AUDIT.md` ledger
was treated as a lead, not as proof.

## Method

- Three Luna agents audited contiguous ranges (`001–025`, `026–050`, and
  `051–074`) in ascending order, one card at a time.
- Every verdict was recalculated from the committed catalog record, the local
  card KB query, the direct TypeScript module, relevant shared primitives,
  peers/evolution stacks when applicable, and observable focused tests.
- All 74 modules register executable behavior exclusively through
  `registerIrCard(cardId, compiled)`; none use `registerCard`.
- Existing tests were left unchanged when they already proved the complete
  contract. Tests were added or corrected only where the audit found a behavior
  defect, missing boundary, asynchronous assertion, or invalid fixture.

## Repairs

Implementation repairs:

- EX8-009 now treats X Antibody as a trait in both reveal effects.
- EX8-015 now accepts either a WarGrowlmon-name source or an X Antibody-trait
  source.
- EX8-026, EX8-029, and EX8-035 now evaluate printed memory conditions from
  the effect controller's side of the gauge.
- `ContinuousEffectLedger.hasRestriction` now treats `suspend` and
  `beSuspended` as equivalent read vocabularies, so “can't suspend” also blocks
  the mandatory suspension used to initiate an attack.

Proof repairs:

- EX8-009 and EX8-015 gained trait-only positive cases that fail when reverted.
- EX8-023 and EX8-024 wait for asynchronous restriction installation before
  asserting observable state.
- EX8-026 gained real opposing-turn and accepted-Blitz legality coverage;
  EX8-029 and EX8-035 gained opposing-turn memory-orientation coverage.
- EX8-066, EX8-069, and EX8-073 now use fixtures that express the printed
  mechanism instead of passing through unrelated card behavior or an invalid
  prevention route.

Independent review found no remaining Critical or Important issues after
branch-specific proof was added for EX8-009's `WhenDigivolving` filter and
EX8-029's DS immunity. The remaining Minor observation is that the
`suspend`/`beSuspended` alias is not mirrored for player-scoped restrictions;
there is no current player-scoped producer for this vocabulary, so it does not
affect EX8 behavior.
