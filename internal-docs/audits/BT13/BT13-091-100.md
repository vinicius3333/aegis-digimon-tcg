## Shared rules, interpreter, and registration trace

The exact/substrings rule is implemented by `apps/api/src/engine/effects/interpreter/matching/definition.ts:273-339`: `match: "nameExact"` compares normalized names for equality, while `match: "name"` checks name inclusion. Alternate digivolution requirements use the same distinction in `apps/api/src/engine/cards/cardData.ts:476-483`, where `names` is a substring gate and `namesExact` is equality. This supports the corrections to BT13-092 and BT13-098 and the destination correction to BT13-093; BT13-095 and BT13-097 correctly retain substring matching because their catalog text says “in its name.”

`apps/api/src/engine/effects/interpreter/conditions.ts:253-303` implements memory and zone-count conditions, `:351-355` sums both security stacks, and `:458-464` implements exact `selfHasName`. `:720-727` supplies result binding for follow-up clauses such as “then” or “if you did.” Permanent filters and trait unions flow through `matching/permanent.ts:19-60`; the BT13-095 battle-area boundary is therefore carried by the shared permanent matcher rather than a broad own-card count.

Play, source-zone, level, and optional handling flow through `apps/api/src/engine/effects/interpreter/actions/play.ts:72-100,104-330,359`. `CostGatedBlock` pays one shared processing condition before nested actions in `actions/controlFlow.ts:90-99`; `runAction.ts:484-540` supplies optional cost/abort-on-decline semantics, and `actions/placeUnder.ts:329-370,515-556` separates loose-card selection from an `isTriggerSource` host. Digivolution effects flow through `actions/digivolution.ts:63-80`; the regular intent path handles Burst payment and marking at `apps/api/src/engine/actions/digivolve.ts:715-767`. Burst’s pending top-card trash is a rule process, not a card’s ordinary End-of-Your-Turn effect, and is handled by `apps/api/src/engine/GameEngine.ts:1770-1790`. This is why BT13-092’s unconditional `EndOfYourTurn` action was removed while the valid Burst source case still asserts end-turn trash.

BT13-094’s granted On Deletion body resolves through `apps/api/src/engine/effects/interpreter/grantedEffects.ts:260-288`; its Biyomon target now uses `nameExact`. The All Turns watchers, optional costs, deletion, suspension, security, and temporary duration cases use the shared action dispatch and continuous-effect machinery. Each direct card module has one exclusive registration at its final line: BT13-091 `:130`, BT13-092 `:72`, BT13-093 `:58`, BT13-094 `:69`, BT13-095 `:108`, BT13-096 `:112`, BT13-097 `:95`, BT13-098 `:116`, BT13-099 `:99`, and BT13-100 `:81`.

The relevant comprehensive-rule seams are §2-3-1-2/3 (`comprehensive.md:216-225`) for exact versus substring names, §8-3-2/§8-3-3 (`:1541-1573`) for Burst pending processing and Tamer return, §11-1 (`:1691-1703`) for attack timing, §15-2-1-2 (`:1917-1923`) for Tamer-effect classification, §15-4 (`:1960-2015`) for pending activation, §15-7 (`:2082-2128`) for optional processing, and §15-16 (`:2705-2740`) for timing windows. Blocker and treated-as-Digimon behavior for BT13-099 was compared with the corresponding §16 keyword rules.
