## Shared interpreter and peer evidence

The shared trace used for the range includes the following seams:

- `Draw` in `apps/api/src/engine/effects/interpreter/actions/resources.ts` supports mine, opponent, and both-player draws and records the effect only when a card is actually drawn.
- `Aura` in `actions/statics.ts` re-evaluates live conditions and modifies the resolved self target through the continuous-effect ledger.
- `TrashDigivolution` in `actions/placeUnder.ts` is the dedicated source-stack trash primitive; it differs from a generic field `Trash` that resolves a permanent and can accidentally trash another host's top source.
- `PlayWithoutCost` in `actions/play.ts` has a strict `fromOwnDigivolutionStack` branch that reads only the triggering permanent's stack, applies the level cap, and plays selected cards from that source.
- `PlaceUnder` binds the selected host, preserves bottom placement, and exposes the bound host to the following `Digivolve`. The digivolve action resolves `fromSelectionRef`, accepts `source: "triggerSource"`, pays the explicit cost override, and honors `ignoreRequirements` only for the printed exception.
- `Return` in `costs.ts` supports `orderReturnedCards`. When the selected return has more than one card, the interpreter asks for one final order with destination `deckBottom`; `EffectContext.orderCards` exposes that destination to the decision seam.
- `SubTrigger` maps opponent-hand additions, played-card events, and opponent attacks to their event subjects and applies source filters and once-per-turn state. `sharedUseKey` in registration gives separate clauses one once-per-turn ledger where required.
- The matching definition distinguishes substring `match: "name"` from normalized literal equality `match: "nameExact"`. The shared `nameExactMatch.test.ts` covers the exact boundary and punctuation normalization. Scaling counts explicit battle-area sources and the combat legality seam treats Blocker as an attack-target switch.

Peer/stack source reviewed for these shapes includes BT13-031's exact Thomas target, BT13-033's ordered bottom-deck return, BT26-016's ordered return cost, EX3-035's ordered return, same-stack play cards, the shared name-exact matcher regression, and combat/trigger tests for Blocker, attack-target restrictions, simultaneous triggers, and effect-driven hand additions.

## Per-card audit

The direct When Attacking action draws one for the controller and one for the opponent under one Once Per Turn trigger. The inherited All Turns Aura targets self and is live while the opponent hand count is at least 8, adding 1,000 DP.

The snapshot agrees with the direct draw and aura structure.

### BT13-028 — Thetismon — provisional 8/10

`BT13-028.ts` is full/no-residual with one exclusive registration. The Hand/Main condition now requires exact `[Kiyoshiro Higashimitarai]` using `match: "nameExact"`. The inherited End of Attack Once Per Turn action unsuspends self only after an optional return cost selects exactly three own trash cards whose text matches `[Jellymon]`, sends them to deck bottom, and asks for one final order. The source correction in commit `0587a6001` adds `orderReturnedCards: true`; the shared return-cost seam supports this flag directly, so no engine change is required. `BT13-028.test.ts` now uses heterogeneous text-qualified sources (`EX12-023`, `EX12-027`, and `BT13-028`), disables automatic ordering, responds with a deliberately non-default instance order, and asserts the exact bottom-deck instance sequence. The same test source covers exact TeslaJellymon/Jellymon host matching, missing Kiyoshiro, missing placement cost, successful hand digivolution, optional End of Attack return, and Once Per Turn behavior. The shared `PlaceUnder`, bound-host Digivolve, exact matcher, ordered return-cost, and End of Attack timing seams all match the catalog. ### BT13-029 — MachGaogamon — provisional 7/10

`BT13-029.ts` is full/no-residual and exclusively registered. Its When Attacking Restrict action targets self, applies `attackTargetChange` for the turn, and is conditioned on the opponent having at least 8 hand cards. The inherited All Turns Once Per Turn subtrigger listens for `whenEffectAddsToOpponentHand` and unsuspends self.

`BT13-029.test.ts` behaviorally drives the attack restriction against an opposing Blocker at 8 cards and allows Blocker target switching below 8. The behavioral score is conservatively `1/2` because the inherited proof invokes the event seam with `effectAddedToHandSeat` rather than causing an actual card effect to add a card to the opponent's hand. The subtrigger's source/event/once-per-turn mapping is structurally correct, and the snapshot's direct shape is materially equivalent; no card-specific KB ambiguity remains.

### BT13-030 — UlforceVeedramon — provisional 8/10

`BT13-030.ts` is full/no-residual and exclusively registered. The On Play and When Digivolving effects each perform a scaled top-source trash against exactly one opponent Digimon: base amount 2 plus two per own Royal Knight Digimon or blue Tamer. The separate On Play Your Turn branch returns one opponent Digimon with no sources to hand, and a Your Turn `whenPlayed` subtrigger repeats that return when an own Royal Knight Digimon or blue Tamer is played. Both return clauses use `sharedUseKey: "bt13-030-return"` and Once Per Turn state.

The direct source makes the three Q rulings explicit. Q2281 is represented by `target.count: 1`: even when two qualifying own sources produce four cards of trash, only one opponent host is selected and its stack is emptied; cards are not split across multiple hosts. Q2282 is represented by the explicit On Play return clause, which can activate when UlforceVeedramon itself is played. Q2283 is represented by keeping the On Play and Your Turn branches as simultaneous trigger candidates, allowing the player to choose their order, while the shared once-per-turn key prevents both return clauses from resolving twice in one turn.

`BT13-030.test.ts` covers On Play trash and empty-stack return, Q2281 one-host scaling, When Digivolving scaling, blue-Tamer plus Royal Knight counting, self-play trigger ordering for Q2282/Q2283, the shared once-per-turn behavior, and rejection of an opponent Digimon that still has a source. The scaling, top-source trash, empty-stack target, simultaneous-trigger order, and shared-use ledger seams all match the catalog and KB. The generated snapshot omits the explicit self-play On Play return and `excludeSelf`/shared-key details from the direct module; it was not edited, and the direct source remains authoritative.
