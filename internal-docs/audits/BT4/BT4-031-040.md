### Shared interpreter trace and correction

The action pipeline in `apps/api/src/engine/effects/interpreter/actions/runAction.ts:80-205` gates processing conditions, preflights target-bearing costs, pays costs, and dispatches the action. The corrected cards now use the already-supported cost-bearing Return shape, so a no-target activation cannot pay Digi-Burst before discovering that the bounce target is absent.

BT6-002 Q1399 supplies controlling same-wording evidence: "Trash all of the digivolution cards" after a return is explanatory rule teardown and does not count as source trash by effect. Therefore the direct IR must not dispatch `TrashDigivolution` for those attachments:

- BT4-032 uses one level-4-or-lower Return with its Digi-Burst 2 cost attached. Its structural guard requires that single action and its no-target proof checks that the two source cards and own trash remain unchanged.
- BT4-033 uses one level-5-or-lower Return with its Digi-Burst 2 cost attached. Its structural guard requires that single action and its level-6 negative keeps the evolved host stack intact.

The downstream primitives were traced without modification: `returnToHand` moves the selected top card and trashes attachments as rule teardown (`primitives.ts:3523-3600`), while the dedicated source-trash path publishes the watcher event that Q1399 forbids here.

Other relevant shared paths are direct and match the assigned cards: `GrantStatic` maps `unblockable` to `cantBeBlocked` (`actions/grantStatic.ts:457-461`), security-trash costs recognize the raw “security stack” wording (`costs.ts:619-660`), the security trash primitive sets `lastEffectActed` (`actions/security.ts:143-207`), and static Aura/DP effects enter the continuous ledger (`actions/statics.ts:45-85`).
