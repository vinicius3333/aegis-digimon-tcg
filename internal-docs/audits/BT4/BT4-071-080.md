## Shared interpreter and peer evidence

- Direct registration takes precedence over the aggregate snapshot: `registerIrCard` normalizes the supplied record and installs the IR module (`apps/api/src/engine/effects/interpreter/registration/module.ts:312-341`). The range aggregate proof is `apps/api/src/cards/BT4/BT4-071-080.audit.test.ts:31-39`, which imports all ten direct modules in ascending order and checks direct registration, full coverage, and empty residuals.
- `runEffect` resolves actions in order and stops when `runAction` returns an abort signal (`apps/api/src/engine/effects/interpreter/effect.ts:597-618`). `runAction`'s generic optional gate historically asks the source controller; the BT4-075 action is a deliberate exception because its `chooser: "opponent"` redirect owns the optional decision at combat resolution. The minimal correction is `apps/api/src/engine/effects/interpreter/actions/runAction.ts:280-296`: opponent-chosen optional redirects bypass the source-controller prompt.
- `runCombatAction` scopes a `chooser: "opponent"` redirect to the defending player's own candidates and passes that seat and optionality to the primitive (`apps/api/src/engine/effects/interpreter/actions/combat.ts:81-101`). `redirectAttack` asks that seat with a minimum of zero for optional redirects and leaves the current target unchanged when no instance is selected (`apps/api/src/engine/effects/primitives.ts:4829-4854`). This is the shared seam required by BT4-075 Q1224/Q1227.
- `RevealAdd` reveals exactly the requested count, independently matches the nested Commandramon play slot, and places untaken cards at the selected deck destination (`apps/api/src/engine/effects/interpreter/actions/reveal.ts:511-551`). `Return`'s deck-top path preserves any requested ordering, and the Darkdramon action's named count drives its following memory gain.
- The Digi-Burst source path uses the dedicated source-card cost machinery rather than a generic field `Trash`; the latter resolves permanent targets (`apps/api/src/engine/effects/interpreter/actions/runAction.ts:451-515`, `apps/api/src/engine/effects/interpreter/actions/removal.ts:531-572`). The inherited Ghostmon source gate matches the trashed source instance in the Digi-Burst batch (`apps/api/src/engine/effects/interpreter/actions/subTrigger.ts:715-726`, `apps/api/src/engine/effects/primitives.ts:2189-2243`).

Same-mechanism peers inspected include BT5-046's cost-bearing reveal action, BT5-050's Digi-Burst source watcher, BT3-030's source-stack condition, P-086's target restriction, and BT15/BT19 attack-redirect records. These peers confirm the target, source, turn, keyword, optional-selection, scaling, and registration shapes used by the direct range modules. Existing evolution-stack tests for BT4-072 and BT4-077 were inspected; their source cards are arranged under a legal host and the resulting inherited/effect behavior is asserted. The added BT4-071, BT4-074, BT4-075, and BT4-078 focused cases further exercise source deletion, mixed trait pools, defending-player decisions, and optional cost refusal.
