# EX10 card-by-card audit — 2026-08-25

Scope: the 74 catalog entries from EX10-001 through EX10-074, audited in ascending card ID order.

This is a live collection ledger. A card is marked 10/10 only after its exact catalog record,
every applicable local rules-KB ruling, direct TypeScript module, shared primitive semantics, and
focused behavioral tests have been inspected together. The collection is not complete until every
row is 10/10 and the collection/mechanism gates, typecheck, and `git diff --check` are green.

## Reproduction

- Focus one card: `pnpm --filter @aegis/api exec vitest run src/cards/EX10/EX10-NNN.test.ts`
- Collection gate: `pnpm --filter @aegis/api exec vitest run src/cards/EX10`
- Shared mechanism tests are listed on rows that changed an engine seam.
- Catalog source: `packages/shared/src/cards/data/cards.json`
- Rules source: the local KB queried by exact card ID and cited below by Q-number.
