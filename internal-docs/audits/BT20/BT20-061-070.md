## Rules findings applied

- The rules KB's optional-processing section treats “by trashing” as an optional processing condition. If the player declines or cannot perform that condition, subsequent processing is skipped. This supports `optional: true` plus `abortOnDecline: true` for the paid effects on BT20-062, BT20-065, BT20-067, and BT20-070.
- A plain mandatory `Trash` of one card is an “as many as possible” selection when fewer than one card is available; it does not imply `abortOnDecline`. BT20-069's subsequent keyword grants therefore correctly remain executable with an empty hand.
- DNA digivolution requires explicit DNA processing and two qualifying battle-area materials, then pays the result's cost unless the effect says otherwise. BT20-066 uses the shared `DnaDigivolve` action with two own Digimon, an Imperialdramon/Free hand result, `payCost: true`, and a Your Turn condition.
- Static `[Your Turn]` DP effects are represented as permanent modifications guarded by the source controller's turn. The adjacent BT20 inherited DP implementations use the same recomputed static shape.
- KB Q4285/Q4286 confirm that inherited On Deletion behavior must preserve the source/host identity through a stack deletion; moving the host and moving the inherited source have different validity consequences. The Ghostmon/Bakemon source tests and the natural battle fixtures below retain that distinction.
