# BT20-076–089 strict proof gap plan

This is an independent read-only comparison of the committed catalog text, local KB queries, direct IR, and current colocated test bodies. Existing historical scores and collection snapshots are not treated as proof. The fixtures below are plans only; no tests were run.

- **BT20-076 Imperialdramon: Dragon Mode:** the public DNA fixture proves Fighter Mode from hand/trash, and the ordinary-entry negative proves the DNA gate. No substantive printed gap remains. If a sensitivity case is desired, use legal DinoBeemon + Paildramon field materials and a Fighter Mode in trash, then decline the optional free evolution and assert the Dragon Mode stack and trash card remain unchanged.

A minimal boundary fixture, if required, is five hand cards with exactly one 8,000-DP Dark Dragon/Evil Dragon target and one 6,001-DP target; assert the fifth card is not forced below four and the 6,001 target is rejected when no cards were trashed.
- **BT20-078 Reapermon:** the direct tests cover the once-per-turn de-digivolve metadata and the On Deletion Digimon cost boundary. - **BT20-080 Fenriloogamon:** Scapegoat, legal Soloogarmon alternate route, Tamer-placement reactivation, optional attack refusal, and inherited security trash are covered.
