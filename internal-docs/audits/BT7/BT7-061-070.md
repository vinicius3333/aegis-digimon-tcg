## Shared interpreter evidence

- `apps/api/src/engine/cards/cardData.ts:538–556` derives the special
  Tamer-onto evolution path from registered IR, requiring a field Tamer and a
  shared color, and obtains the actual cost from the evolving card's level-3
  evolution cost. This is the runtime path for BT7-061; the stale snapshot's
  gateless alternate requirement is not authoritative.
- `apps/api/src/engine/effects/interpreter/actions/statics.ts:17–81` applies
  continuous Aura effects and their live `while` conditions. BT7-061's
  Blocker therefore remains an active top-card effect rather than relying on
  the stale intrinsic-keyword snapshot representation.
- `apps/api/src/engine/effects/interpreter/actions/placeUnder.ts:274–380`
  resolves source zones, destination hosts, arbitrary order, and bottom-stack
  placement. `:450–515` and
  `apps/api/src/engine/effects/interpreter/targeting/loose.ts:426–484`
  implement exact-name and exact-name-up-to selection, including one material
  per named identity and all-or-none behavior for `requiredNamesExact`.
- `apps/api/src/engine/effects/interpreter/actions/play.ts:260–329` handles
  playing cards from the source permanent's own stack, preserving the source
  host and suspended state. The audited correction makes this branch honor
  `requiredNamesExact` and `requiredNamesExactUpTo`; previously it ignored
  both fields and simply sliced the matching stack cards.
- `apps/api/src/engine/effects/interpreter/actions/reveal.ts:108–139` applies
  `trashFilter` only to the revealed set, and `:511–550` sends untaken cards to
  the requested deck bottom/top destination with ordering. This is the
  BT7-070 implementation seam that prevents unrelated Tamers in play from
  being trashed.
- `apps/api/src/engine/effects/interpreter/scaling.ts:253–264` counts the
  source permanent's digivolution-card stack for `unit: "digivolutionCards"`;
  `matching/permanent.ts:583–593` materializes the BT7-065 dynamic play-cost
  cap. The stack model stores cards beneath the top card, so the count is the
  printed “this Digimon's digivolution cards” count.
- `apps/api/src/engine/effects/interpreter/matching/definition.ts:297–330`
  normalizes trait whitespace and hyphens. Thus direct IR tokens `"X
  Antibody"` and catalog traits `"X Antibody"` match, as do the direct
  module's historical `"X-Antibody"` tokens. Name checks remain exact for
  `requiredNamesExact` and name-substring for the candidate pool where the
  bracketed card identity is intentionally narrowed by the exact-name fields.
- Deletion/replacement, inherited timing, and stack transitions were followed
  through the action dispatcher and removal primitives. The shared rules
  confirm that a card beneath a Digimon is a digivolution card, inherited text
  is gained by the host, and cards under a removed stack leave with it unless a
  replacement effect plays them first.
