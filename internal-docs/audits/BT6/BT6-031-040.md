## Shared interpreter trace

The following shared seams were traced for the applicable cards:

- `apps/api/src/engine/effects/interpreter/registration/module.ts:44-95`
  constructs the executable IR module and applies timing/frequency. The
  `OncePerTurn` and turn-scope wrappers are implemented through
  `apps/api/src/engine/effects/interpreter/effect.ts:384-403`.
- `apps/api/src/engine/effects/interpreter/conditions.ts:262-265` resolves
  security thresholds through the player's security count. Both
  `securityAtLeast` and `securityAtMost` are live conditions. This is the
  relevant seam for BT6-033 and BT6-037, while the exact-three BT6-033 Aura
  uses `allOf` of the lower and upper bounds.
- `apps/api/src/engine/effects/interpreter/actions/subTrigger.ts:216-230`
  implements the security-removal gate and its `sourceFilter.controller`
  ownership comparison. The default is the effect source's controller, and
  the explicit `controller: "mine"` in BT6-032, BT6-034, and BT6-040 makes the
  owner boundary visible in the direct module. The related by-source-control
  handling is at `:582-595`.
- `apps/api/src/engine/effects/primitives.ts:2628-2660` moves cards from
  security to trash and emits `whenSecurityRemoved` with the removed card's
  security owner and effect metadata. The security-to-hand path at
  `:4666-4677` emits the same generic event. Thus the direct security watcher
  shape was checked against both effect-caused security movement and the KB
  cases above.
- `apps/api/src/engine/effects/interpreter/actions/security.ts:143-207`
  implements `trashTop`, including `leaveCount`, `upTo`, and actual-count
  tracking. With `leaveCount: 3`, the operation cannot reduce security below
  three; `upTo: true` offers zero through the allowed maximum, and
  `trackCount` records the number actually trashed for BT6-033's memory
  scaling.
- `apps/api/src/engine/effects/interpreter/conditions.ts:1076-1080` and the
  scaling path use the current effect's actual activation/count state. This
  supports BT6-033's “one memory for each card trashed” rather than a fixed
  amount.
- `apps/api/src/engine/effects/interpreter/actions/statics.ts:17-81`
  re-evaluates live Aura effects and maintains keyword/DP ledgers. This is
  relevant to BT6-033's exact-three Jamming, BT6-037's live Security Attack,
  and BT6-039's security-dependent DP.
- Duration resolution at
  `apps/api/src/engine/effects/interpreter/primitives.ts:500-510`,
  `apps/api/src/engine/effects/interpreter/duration.ts:10-34`, and continuous
  cleanup at `:455-475` was checked for BT6-031's “opponent's next turn”
  duration.
- `apps/api/src/engine/effects/interpreter/matching/definition.ts:68-88`
  supplies card kind/color/name/trait matching. No reviewed card's printed
  behavior requires a broader name or trait match than its direct module
  expresses.
