The original direct IR had two behavior gaps. The corrected module (`BT6-077.ts:8-67`) has one optional self-targeted `GainKeyword` action with the hand-trash cost, Blocker as its primary keyword and Retaliation in the combined keyword list, followed by an All Turns self-targeted `GrantStatic` color Black action. Focused tests add a decoy Digimon and prove only the source gains Blocker and Retaliation, and add a decline path proving that declining the optional effect neither trashes a hand card nor grants either keyword. Q1466’s breeding-area boundary and Q1467’s empty-hand cost boundary were checked. A legal historical stack is covered by `titamon-historical-deck.test.ts:18-23`, where BT6-077 evolves over Purple Lv.4 sources including BT6-006 and BT6-073; its downstream assertions at `:57-86` exercise the resulting keywords. The two evolution colors and level-4 bases were checked against the catalog; All Turns color treatment was compared with BT6-013’s direct `GrantStatic` color pattern.

The generated snapshot (`effects.json:111523-111563`) is stale in behavior-bearing fields: it targets a generic own Digimon for the Blocker and Retaliation grants, splits the grants into separate optional actions, and uses `grant: "trait", tokens: ["black"]` rather than the direct self-targeted `grant: "color", tokens: ["Black"]`. ## Shared primitive and boundary findings

The important shared seams were inspected directly:

- `apps/api/src/engine/effects/interpreter/targeting/permanents.ts:21-124` resolves a self target from `source.permanent` when `isSelfRef` is present, while a generic own-permanent filter falls back to all eligible permanents. This proves why BT6-077 required a self-target correction.
- `apps/api/src/engine/effects/interpreter/matching/permanent.ts:107-129` supplies controller scoping for own/opponent target boundaries; the level comparison path enforces BT6-072 and BT6-080 ceilings.
- `apps/api/src/engine/effects/interpreter/actions/board.ts:260-421` resolves `GainKeyword`, records continuous keyword state, and applies `action.keywords` extras. This supports BT6-077’s single combined Blocker/Retaliation action.
- `apps/api/src/engine/effects/interpreter/actions/grantStatic.ts:32-85` distinguishes `grant: "color"` from `grant: "trait"`; `GameEngine.ts:4884-4897` consumes color grants in effective-color calculation. This proves the direct BT6-077 black-color action is materially different from the stale snapshot trait grant.
- `apps/api/src/engine/effects/interpreter/actions/subTrigger.ts` maps `whenTrashedFromHand`, checks the source instance, and applies `bySourceController` against the event’s effect-causing seat. `apps/api/src/engine/effects/primitives.ts:2012-2151` records both hand owner and `byEffectSeat` when trashing from hand. These seams prove BT6-073 and BT6-078’s own-effect provenance.
- `apps/api/src/engine/effects/interpreter/actions/placeUnder.ts:330-489` resolves exact required names, optional/up-to selections, order, and bottom position. This supports BT6-075’s exact Kinkakumon/Ginkakumon placement and BT6-078’s source-to-bottom-stack effect.
- `apps/api/src/engine/effects/interpreter/actions/runAction.ts:290-330,454-530` processes optional actions and then their costs. A single optional BT6-077 action therefore gates both keywords behind the one hand-trash cost.
- `apps/api/src/engine/effects/interpreter/conditions.ts:283-304` reads the current trash count. `apps/api/src/engine/effects/primitives.ts:2980-3010,3124-3194` and the On Deletion movement path resolve deletion triggers after the deleted card is moved, proving BT6-079’s nine-to-ten boundary.
- `apps/api/src/engine/combat/legality.ts:99-125` handles Rush and same-turn attack sickness; `apps/api/src/engine/combat/controller.ts:1198-1227` handles holder-side Retaliation. Static keyword projection and Security Attack consumption were checked through `board.ts` and the GameEngine continuous-effect seams.
- `apps/api/src/engine/effects/interpreter/registration/module.ts:44-85` confirms direct modules enter the executable pipeline through the single `registerIrCard(cardId, compiled)` route. No duplicate legacy `registerCard` path was added or preserved in this range.

Trait and name boundaries were checked explicitly: BT6-075 requires the exact names Kinkakumon and Ginkakumon, excludes Ginkakumon Promote, and places selected cards under the source; BT6-079 requires exact Ornismon; BT6-072 and BT6-080 restrict targets by Digimon level and opponent controller; BT6-077’s All Turns action changes color rather than trait; and BT6-073/BT6-078 distinguish the source instance and effect-causing controller. Ordinary legal stacks were checked against every catalog level/color/evo-cost row, including alternate Purple/Black Lv.4 paths for BT6-077 and both Purple Lv.3/Purple Lv.4 paths for BT6-075.
