## Executive result

All ten direct modules were reviewed against the committed catalog, the local
rules knowledge base, the generated effects snapshot, shared interpreter
primitives, focused tests, same-mechanism peers, trait/name boundaries, and
legal evolution stacks where applicable. One proven implementation gap was
corrected: Gundramon's revealed cost-7 Option choice is now explicitly
optional. Focused fixtures were strengthened for legal stacks, exact target
boundaries, optional/trait behavior, registration loading, and dynamic
conditions; no shared seam or generated snapshot was edited.

All ten production modules in this range had `@ts-nocheck` removed without semantic changes.

This is a static audit only. Every card receives the provisional static score
of **8/10**: the four evidence components are each 2/2, while the runtime-gate
component is 0/2 because the requested focused tests, mechanism/collection
tests, typecheck, lint, formatting, browser/UI checks, and `git diff --check`
were deliberately not run. This range does not claim collection completion or
10/10 evidence.

## Registration and snapshot audit

Each direct module has exactly one registration, at its final line, using
`registerIrCard(cardId, compiled)`. A repository search found no duplicate
`registerCard` path for any card in this range. All ten modules report
`coverage: "full"` and `residual: []`; the direct registered module is the
executable authority.

The generated snapshot was inspected but intentionally not edited, as
required. Snapshot records begin at `packages/shared/src/effects/effects.json`
line 111185. The following drift is documented rather than silently treated as
executable behavior:

* BT6-061's snapshot grants the token `trait: red`, while the direct module
  correctly grants `color: Red`. The color grant is supported by the
  interpreter's color map and effective-color calculation.
* BT6-065's snapshot represents reveal/use/rest/delete as a more fragmented
  legacy shape and does not preserve the direct module's consolidated
  `RevealAdd` semantics. The direct module now marks its `useOption` choice
  `optional: true`, which is required by the printed “You may use” text.
* BT6-066's snapshot includes a legacy explicit `Unsuspend` action next to
  Reboot. The interpreter intentionally skips that legacy action and the
  game engine performs Reboot during the opponent's unsuspend phase; the
  direct Reboot marker is therefore authoritative.
* BT6-068's snapshot uses a raw “if you do” condition without the direct
  binding, while the direct module gates the return on the successful optional
  hand trash through `bindingExists`.
* BT6-069's snapshot omits the direct `bySourceController: "mine"` gate. The
  direct module is authoritative because the card requires trashing by one of
  its controller's effects.

BT6-062, BT6-063, BT6-064, BT6-067, and BT6-070 have snapshot shapes matching
the direct executable modules for the clauses audited here.

## Shared interpreter and peer evidence

The registration module and effect builder were traced to confirm that trigger,
inherited, frequency, and turn-scope metadata are consumed by the shared IR
interpreter. `GrantStatic` color grants use the shared color map and are merged
by `effectiveColorsOf`; the BT6-077 color-grant peer confirms the same shape.
Aura effects recompute their `while` gate, so the unsuspended-opponent clauses
on BT6-062 and BT6-067 disappear as soon as the last eligible Digimon is
suspended. The targeting matcher implements exact levels, inclusive play-cost
limits, exact play-cost sets, kind, controller, and trait/name matching.

The reveal primitive publishes the bounded visible set before selection, honors
an optional zero-card choice, marks whether the Option was actually used, and
resolves the remaining revealed cards to trash. The play/use primitive treats
an Option used from the reveal as an Option effect rather than a permanent
play. The deletion condition `ifThisEffectDidNotAct` therefore distinguishes
declining Gundramon's Option from successfully using it. Reveal processing also
supports a short deck by revealing the available cards.

The deletion event bus supplies `onDeletionOf` with the deleted source context;
the PileVolcamon watcher filters to another of its controller's Digimon and
uses a once-per-turn identity. De-Digivolve peels the top card and promotes the
underlying card while respecting the level-3 floor. Hand-trash events carry the
effect controller, allowing Goblimon's `bySourceController` gate to reject
opponent-caused trash. Decoy is implemented as an engine keyword: the static
marker carries `Decoy (Black)`, and the engine enforces opponent-effect,
specified-color, another-Digimon, and optional self-deletion semantics. The
BT6-059 Decoy peer, BT6-060/BT6-112 cost-7 Option peers, BT6-073 hand watcher,
BT6-077 color grant, BT9-016 security-removal watcher, and focused conformance
tests were read as comparative evidence.

Catalog contract: Black level 5, play cost 6, 7000 DP, Black or Red level-4
evolution for 3, Virus/Cyborg. The main effect is `[Your Turn] This Digimon is
also treated as red`; the inherited effect is `[Opponent's Turn] This Digimon
gets +2000 DP`.

The direct module (`apps/api/src/cards/BT6/BT6-061.ts:9-49`) maps the main text
to a self `GrantStatic` color `Red` under `YourTurn`, and maps the inherited
text to self `ModifyDP` +2000 under `OpponentsTurn` with permanent duration.
The inherited flag is on the second effect, and the module is full with no
residual. The color grant is intentionally not a trait grant despite the
generated snapshot drift. The Q1455/Q1456-focused tests verify battle-area
color identity and no color grant in breeding; the inherited test now uses the
legal BT6-065 level-6 top over BT6-061 level 5 rather than an invalid level-3
fixture (`BT6-061.test.ts:15-35`).

Evolution requirements and the battle-area/breeding boundary are consistent
with the rules. No range erratum or restriction applies. Score: **8/10
provisional** — catalog 2/2, rules/rulings 2/2, executable fidelity 2/2,
focused/cross-card evidence 2/2, executed gates 0/2.

### BT6-065 — Gundramon

Catalog contract: Black level 6, play cost 11, 11000 DP, Black level-5

The three focused cases (`BT6-065.test.ts:10-91`) cover use without payment,
publication of all five revealed identities, and decline leading to the <=4
deletion. Fixtures now use the legal level-6 BT6-065 top over level-5 BT6-061.
The cost-7 Option peers and reveal/use interpreter were cross-checked. No
erratum or restriction applies. Score: **8/10 provisional** — 2/2, 2/2, 2/2,
2/2, 0/2.
