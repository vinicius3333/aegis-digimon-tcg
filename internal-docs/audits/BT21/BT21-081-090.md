## Scope and result

This audit covers BT21-081 through BT21-090 in ascending order. I inspected the immutable catalog blob `efbecc002fb9000789123e2f91f201466e1e5b0a`, one local knowledge-base query per card, the local rules and glossary, direct TypeScript IR, generated effect snapshots, shared interpreter seams, focused card assertions, same-mechanism peers, and legal stack/evolution data.

The generated snapshot and shared implementation files were read as evidence only. I did not edit `packages/shared/src/effects/effects.json`, `BT21-STATIC-AUDIT.md`, or any shared primitive. ## Per-card evidence

### BT21-081 Owen Dreadnought

The catalog identifies BT21-081 as a red Tamer with play cost 3. Its clauses are: gain 1 memory at the start of the controller’s main phase if the opponent has a Digimon; at the end of the controller’s turn, by suspending this Tamer, give one own Reptile/Dragonkin Digimon Piercing for the turn and make that same Digimon attack; and play this Tamer for free from Security.

The direct module `apps/api/src/cards/BT21/BT21-081.ts:17-117` maps the first condition to `opponentHas` and the end-turn clause to one `SelectBind` (`piercingTarget`), an outer Tamer-suspension cost, `GainKeyword` from that selection, and mandatory `Attack` from the same selection. The selected target cannot change between Piercing and attack, and the attack is not optional after the cost is accepted. The Security clause is a self-only `PlayWithoutCost`.

The single KB query returned Q4593, which confirms the selected Digimon must attack if able, and Q4594, which confirms another copy cannot create a second attack while the first attack is still resolving. The focused test `BT21-081.test.ts:61-126` provides a natural end-of-turn path, decline/no-target boundaries, and Security behavior. The attack/subscription and selection-binding seams were compared with BT21-083 and BT21-086; no evolution stack applies to this Tamer.

The snapshot entry at `packages/shared/src/effects/effects.json:69037` has the condition and Tamer cost but models the final clause as `Restrict`/`attacksPlayer`, rather than executing the printed attack. The direct IR is the executable authority and is more precise. No direct gap remains.

### BT21-082 Takuya Kanbara

The catalog identifies BT21-082 as a red Tamer with play cost 3. It plays free from Security. At the start of the controller’s main phase, one own Digimon or Tamer may digivolve into a Hybrid/Hero Digimon from hand, reducing that digivolution cost by 1 for each own red Tamer with a different name. Its inherited Your Turn effect may play one red Tamer from hand for free when the opponent’s security stack is removed, once per turn.

The direct module `apps/api/src/cards/BT21/BT21-082.ts:29-111` uses a paid `Digivolve` action from hand, keeps ordinary target digivolution requirements active, and folds `reduceCostScaling` with `unit: "distinctNames"` into that same digivolution. This is important: a sibling `wouldDigivolve` replacement cannot reduce the cost of the same action after it has already been declared. The inherited watcher is `whenSecurityRemoved`, gated to the opponent’s security seat and restricted to a red Tamer from the controller’s hand; it is marked `OncePerTurn`. Security is a self-only free play.

Q4595 confirms that BT21-082 itself counts toward the different-name reduction, and Q4596 confirms security-effect precedence. The focused test `BT21-082.test.ts:34-127` naturally digivolves, checks duplicate-name collapsing, rejects a non-Hybrid/non-Hero destination, exercises opponent security removal, and checks Security play. The shared digivolution-cost seam and the distinct-name scaling primitive were inspected; the Tamer itself has no evolution stack, but the selected base and destination still use legal evolution requirements.

The snapshot at `effects.json:69100` has the digivolve and inherited watcher but omits the folded reduction from the Digivolve action and instead contains a sibling replacement with a generic `cards` unit. It also lacks the explicit opponent-security-seat gate. The direct module is authoritative and correct; no direct gap remains.

### BT21-083 Taiki Kudo

The catalog identifies BT21-083 as a red/yellow General, Xros Heart, Hero Tamer with play cost 4. At the start of the controller’s main phase, it may place one hand Digimon with Xros Heart, Blue Flare, or Hero under this Tamer, then Draw 1 and gain 1 memory. During the controller’s turn, when an own Xros Heart or Hero Digimon is played or digivolves, this Tamer may suspend to make that arriving Digimon attack. It plays free from Security.

The direct module `apps/api/src/cards/BT21/BT21-083.ts:35-81` models the placement as the cost of the optional Draw action; the placement defaults to the source Tamer, so the card goes under Taiki in the correct stack position. The memory action follows the transactional draw/cost action. Two separate `SubTrigger`s cover `whenPlayed` and `whenOneOfYoursDigivolves`, each filtering an own Xros Heart/Hero Digimon and attacking `sourceRef: "triggerSubject"` only after the Tamer suspension cost. This preserves the arriving Digimon identity and does not create a second attack during an ongoing attack. Security is a self-only free play.

Q4597 confirms bottom-stack placement order, Q4598 confirms that simultaneous copies do not create multiple attacks, and Q4728 confirms that a card played during End of Attack cannot start another attack while that attack is ongoing. The focused test `BT21-083.test.ts:35-207` includes natural play and digivolution attack paths, natural hand placement, decline behavior, a nonmatching Digimon, and Security play. The source-reference attack seam was compared with BT21-081 and the event-ordering peer in the KB.

The snapshot at `effects.json:69164` is broadly aligned but is less explicit about the cost placement host and transactional continuation. It was not edited. No direct gap remains.

### BT21-084 Haru Shinkai

The catalog identifies BT21-084 as a red Tamer with play cost 4. At the start of the controller’s turn, if memory is 2 or less, set it to 3. During the controller’s turn, when an own Digimon gets linked, this Tamer may suspend to Draw 1, then one own Digimon may App Fuse into a Digimon from hand. It plays free from Security.

The direct module `apps/api/src/cards/BT21/BT21-084.ts:11-94` uses `StartOfYourTurn` plus `memoryAtMost`, then one own-Digimon `whenLinked` watcher. The Draw has the Tamer suspension cost and `abortOnDecline`; the AppFuse is nested in the same linked-trigger body, so it cannot become available from an unrelated turn action or after declining the trigger cost. AppFuse is optional as printed. Security is a self-only free play.

Q4599 establishes the relevant linked-trigger window: if the trigger’s first processing changes the state, the pending fusion clause follows the actual trigger resolution rather than becoming a global AppFuse action. Q5444 is a separate Raid interaction and was excluded from this card’s behavior. The focused test `BT21-084.test.ts:42-174` checks natural public linking, the linked-only fusion window, decline behavior, opponent-linked negative behavior, memory setting, and Security play. The link event, AppFuse, and optional-cost seams were compared with other linked cards.

The snapshot at `effects.json:69261` places `AppFuse` beside the linked watcher instead of inside it, which would expose fusion outside the printed trigger window. The direct module already contains the required correction; no further direct gap remains.

### BT21-085 Davis Motomiya

The catalog identifies BT21-085 as a blue/red Tamer with play cost 4. It gains 1 memory at the start of the controller’s main phase if the opponent has a Digimon. During the controller’s main phase, by suspending this Tamer and trashing the top stacked card of one own Armor Form Digimon, it Draws 1 and gains 1 memory. It plays free from Security.

The direct module `apps/api/src/cards/BT21/BT21-085.ts:11-97` maps the conditional memory clause to `opponentHas`. Its Main Draw action has a primary suspension cost and an additional trash cost restricted to the top card of an own Digimon with the Armor Form trait; the following memory gain is in the same action list and is protected by the Draw’s `abortOnDecline`. This means both printed costs are preflighted and declining or failing either cost does not grant the reward. Security is a self-only free play.

Q4600 confirms that the Once Per Turn behavior for this mechanism remains reached after the top stacked card is trashed. The focused test `BT21-085.test.ts:61-177` naturally activates the Main intent, checks that only the top Armor Form source is trashed, verifies Draw and memory, checks decline/no-eligible-stack behavior, and checks Security play. The multi-cost `canActivateEffect` and top-stack trash seams were inspected; no evolution requirement applies to the Tamer itself.

The snapshot at `effects.json:69312` matches the direct action shape, including the additional top-stack trash cost and Security play. No direct gap remains.

### BT21-090 The Strongest of Brothers

The catalog identifies BT21-090 as a red Option with cost 3. It may ignore its color requirement while the controller has a Digimon or Tamer with Gammamon in its text on the field. Its Main effect reveals the top three cards, adds one Gammamon-text card to hand, returns the rest to the bottom of the deck, and places this Option in the battle area. During all turns, when an effect places digivolution cards under one of the controller’s Digimon, it gains Delay. Delay lets one own Digimon digivolve into a Gammamon-text Digimon from hand without paying the cost. Security may play one Gammamon-text card costing 4 or less from hand or trash for free, then places this Option in the battle area.

The direct module `apps/api/src/cards/BT21/BT21-090.ts:11-161` maps the static color waiver to own Digimon/Tamer text matching, which includes the breeding-area Digimon boundary confirmed by Q4733. Main uses reveal-three/add-one/deck-bottom followed by mandatory self placement. The Delay grant and its payload are deliberately separate All Turns entries: the first is an `onAddDigivolutionCards` watcher and the second carries the Delay keyword and free hand digivolution. Security filters the free-play card to Gammamon text and cost 4 or less from hand/trash, then performs mandatory self placement.

The confirmed defect was in the watcher’s event scope. Without a source filter, it could arm on manual/rule-driven additions, an opponent’s Digimon, or a Tamer destination, rather than only an effect placing cards under an own Digimon. The additive correction at `BT21-090.ts:71-73` is:

```ts
sourceFilter: { controller: "mine", kind: ["Digimon"], byEffect: true },
```

The interpreter’s `onAddDigivolutionCards` seam removes `byEffect` for normal permanent matching, then independently checks effect provenance; the remaining controller/kind fields scope the receiver to an own Digimon. This matches the established BT17-090 and BT8-069 peer shape. The focused structural assertion at `BT21-090.test.ts:12-42` checks both gates, and the natural-origin test at `BT21-090.test.ts:47-75` uses BT17-086 Leon’s public Mind Link effect to place the Tamer under BT17-030 Pulsemon before observing Delay on BT21-090. Q4604 confirms the “in its text” matcher, and Q4733 confirms that “on the field” includes breeding.

The snapshot at `effects.json:69680` lacks the effect-provenance/own-Digimon source filter and still makes Security placement optional, despite the printed “then” placement. The direct module keeps Security placement mandatory and now has the missing watcher scope. The correction is committed in `f6b655b60`.
