## Scoring rubric

Each independently reviewed component is worth 2 points:

- **Contract and rules:** catalog fields and printed clauses are reconciled
  against the local card KB and applicable local rules material.
- **IR trace:** each clause maps to compiled IR with `coverage: "full"`, an
  empty residual list, and exactly one exclusive
  `registerIrCard(cardId, compiled)` registration; no `registerCard` path is
  present in the assigned modules.
- **Behavioral proof:** the colocated test source covers the meaningful positive,
  boundary, negative, optional, frequency, duration, ownership, zone, and
  target cases applicable to the card.
- **Peer and stack proof:** relevant neighboring cards, shared interpreter and
  primitive seams, and realistic evolution/DNA stacks were inspected.
- **Delivery gates:** focused, mechanism, collection, typecheck, style, and
  diff-validation commands passed. This is 0/2 because execution was
  explicitly deferred.

  Save inherited gate.

ten snapshots report `coverage: "full"` and `residual: []`. Snapshot drift is
not itself an ambiguity: every difference above has a direct module trace and
