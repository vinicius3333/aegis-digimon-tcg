# BT17-061–BT17-070 Audit Report

## Scope and provenance

This report covers exactly BT17-061 through BT17-070, inspected in strict
ascending card-ID order under the `verify-card-implementation` protocol. The
catalog source was the immutable blob
`efbecc002fb9000789123e2f91f201466e1e5b0a` for
`packages/shared/src/cards/data/cards.json`; each card was also queried against
the current local rules knowledge base. Direct card modules, compiled IR,
shared runtime primitives, relevant peers, legal evolution stacks, and
behavior-driving test source were inspected for every card.

No changes were made to `packages/shared/src/effects/effects.json` or
`BT17-STATIC-AUDIT.md`.

## Scoring and deferred boundary

Each card receives five independent two-point components: Catalog/rules, IR
trace, Behavioral proof, Peer and stack proof, and Executed delivery gates.
The dispatch fixed Executed delivery gates at `0/2`. Accordingly, every result
below is provisional `8/10`, not a green execution result.

The following were intentionally not run: focused card tests, mechanism tests,
collection tests, any other tests, typecheck, lint, formatter, browser checks,
focused/mechanism/collection gates, and `git diff --check`. The behavioral
component is based on source-level natural-event proof present in the tests;
structural assertions, manual event-bus/timing injection, and unexecuted test
claims were not used as substitutes for execution. The deferred gates remain
next verification boundary.
