Audit date: 2026-08-28

time in ascending card-ID order against immutable catalog blob
`efbecc002fb9000789123e2f91f201466e1e5b0a`, the current local rules

## Scoring and deferred gates

1. Catalog/rules

## Shared evidence and implementation seams

Catalog and rules evidence was inspected for every card from the immutable
blob and the local KB query `node tools/kb/query.mjs card <CARD_ID>`. The
relevant implementation seams included:

- `apps/api/src/engine/effects/interpreter/effect.ts` for timing, source,
  inherited, turn-owner, and continuous-effect routing.
- `apps/api/src/engine/effects/interpreter/actions/board.ts` and
  `actions/removal.ts` for keyword grants, play/deletion, target resolution,
  and delayed returns.
- `apps/api/src/engine/effects/interpreter/actions/resources.ts` for draw,
  memory, security-to-hand, and end-of-turn processing.
- `apps/api/src/engine/effects/interpreter/registration/keywords.ts` for
  compiled keyword/evolution metadata extraction.
- `apps/api/src/engine/cards/cardData.ts` and
  `apps/api/src/engine/cards/tamerOntoDigivolve.ts` for Tamer-as-Digimon
  evolution legality.
- `apps/api/src/engine/actions/digivolve.ts` and
  `digivolveState.ts` for virtual evolution bases, stack/source transitions,
  and selected host persistence.
- Combat, security, and continuous-effect runtime paths were inspected for
  inherited attack effects, Jamming, unsuspension, security movement, and
  turn-scoped restrictions.

The tests were edited where needed to provide feasible natural originating
events and observable state proof, but none of them were executed under the
deferred-gate boundary.

## Per-card findings

### BT17-021 Labramon — provisional 8/10

- Catalog/rules: Blue Rookie Lv.3; On Play places either one Seasarmon or one
  level-3 Blue Digimon from hand at the bottom of this Digimon's stack, then
  draws one; inherited once-per-turn When Attacking gains one memory when this
  Digimon has Jamming.
- IR trace: `apps/api/src/cards/BT17/BT17-021.ts` maps both the named Seasarmon
  branch and the level-3 Blue branch, plus the inherited Jamming-gated attack
  gain. The original named branch incorrectly constrained Seasarmon to level
  3, although catalog card BT17-024 Seasarmon is level 4.
- Correction: commit `fe17fed19` removed the erroneous level/color constraint
  from the named Seasarmon filter while retaining the level-3 Blue alternative.
  `apps/api/src/cards/BT17/BT17-021.test.ts` now uses BT17-024 as natural hand
  material, so the named placement path cannot regress to a level-only match.
- Peer/stack proof: nearby stack-placement and Jamming implementations were
  compared, and the proof covers actual On Play placement/draw and the
  inherited attack condition.
- Unresolved: only deferred execution gates; no card-specific source or IR
  seam remains identified.

- Peer/stack proof: a real BT4-083 Cerberusmon evolution with BT17-021 in trash
  proves the source stack and effect-played target; the delayed case also
  preserves the evolved target's stack semantics.
- Unresolved: only deferred execution gates; the delayed opponent-end return
