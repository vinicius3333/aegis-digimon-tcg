Scope: BT22-087 through BT22-083, independently audited in descending order on 2026-08-20. Each card is scored against the same ten mandatory evidence points.

## BT22-087 — Torajiro Asuka — 10/10

1. **Catalog.** Yellow cost-3 App Driver/Appmon Tamer: opponent-Digimon start-main +1; owned Digimon link may suspend Torajiro for -2000 DP, then optionally App Fuse an owned Digimon from hand; Security free play.
2. **KB.** Q4957 requires the entire activated effect to finish before the rule check deletes 0-DP Digimon.
3. **Clauses.** Conditional GainMemory, `whenLinked` SubTrigger, costed ModifyDP followed by AppFuse, and Security self-play map all text.
4. **Requirements.** Link subject is an owned Digimon; DP target is opposing Digimon; App Fuse source is owned Digimon and destination hand Digimon subject to App Fusion requirements.
5. **Costs/failures.** Self-suspension gates both the DP step and following “Then”; App Fuse remains optional and cannot bypass fusion legality.
6. **Controllers.** Owner chooses opponent DP target, fusion source/destination, or refusal; opponent has no decision.
7. **Zones/order/face.** Fusion hand card moves through the App Fusion stack path; Security checked self enters battle.
8. **Timing/OPT.** Your Turn only, no printed OPT; Q4957 is preserved because rule checks follow full effect resolution.
9. **UI.** Generic target/fusion decisions apply; no special presentation path.
10. **Gates.** Focused clause tests and observable start-main memory proof pass with wave gates.
