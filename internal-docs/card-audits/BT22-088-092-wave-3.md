# BT22 implementation audit ledger — wave 3

Scope: BT22-092 through BT22-088, audited individually in descending order on 2026-08-20. Each numbered entry is one mandatory rubric point and is scored only where catalog, exact KB, implementation, and focused behavioral proof agree.

## BT22-092 — Jimmy KEN — 10/10

1. **Catalog.** Purple cost-4 CS Tamer, limit 4: memory setter; owned Flame/CS play or evolution may suspend Jimmy to activate one of that Digimon's Main effects, then gain 1 if an effect activated; Security free play.
2. **KB.** Q4961 includes inherited Main effects after evolution; Q4962 requires the chosen Main effect to finish before Jimmy's gain; Q4963 preserves the chosen effect's once-per-turn usage.
3. **Clause/code map.** Hand-written start-turn, `OnEnterFieldAnyone` trait/subject binding with `reactivateOnPlay(OnDeclaration)`, conditional gain, and Security skill cover all clauses.
4. **Requirements/traits.** Subject is an owned Digimon whose current top has Flame or CS. Main effects from the whole current stack remain discoverable, satisfying Q4961.
5. **Costs/failures.** Jimmy must be unsuspended and in battle; suspension precedes activation. No Main candidate/no activation means no bonus memory.
6. **Controllers.** Jimmy's owner pays and chooses among the subject's eligible Main effects; opponent subjects are excluded.
7. **Zones/order/face.** No movement except Security checked-card play. The subject stays bound through the awaited Main resolution.
8. **Timing/OPT/interactions.** Your Turn only; full resolution precedes +1 (Q4962), and the shared use tracker enforces Q4963.
9. **UI.** Existing effect-choice decisions cover multiple Main effects; no custom UI path.
10. **Gates.** Behavioral proof covers setter bounds/turn ownership, Flame positive, nontrait negative, suspension, sequencing, memory delta, and Security play.
