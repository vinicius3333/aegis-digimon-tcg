# BT22 implementation audit ledger — wave 11

Scope: BT22-052 through BT22-048, audited independently in descending order on 2026-08-20. Each numbered item is mandatory evidence.

## BT22-052 — Leopardmon — 10/10

1. **Catalog.** Green level 6 ACE, cost 7/12000, Holy Warrior/Royal Knight/CS, overflow 4, CS level-5 cost 3, Blast Digivolve, free play, Blocker grant, and leave watcher.
2. **KB.** Q4905 confirms the memory watcher activates at would-leave timing even when a simultaneous effect later prevents the leave.
3. **Clauses.** Counter/Blast, alternate evolution, optional ≤5000 DP free play, mandatory Then Blocker grant, and memory replacement map all text.
4. **Requirements.** Free-play boundary is inclusive 5000 DP; Blocker reaches all own level-3+ Digimon; watcher excludes Leopardmon itself.
5. **Costs/failures.** Free play may be declined or no-op without a target; Blast follows counter legality; Overflow pays 4 when applicable.
6. **Controllers.** Owner chooses the free-play card and trigger ordering under Q4905.
7. **Zones/order/face.** Chosen Digimon moves hand→battle before the all-Digimon Blocker grant; leave watcher changes memory without changing the pending move.
8. **Timing/OPT.** Entry/evolution windows are separate; All Turns replacement now carries one stable once-per-turn key.
9. **UI.** Generic Counter, alternate evolution, free-play selection, keyword display, and leave narration apply.
10. **Gates.** Public tests prove the 5000 boundary/all-target Blocker grant and exactly one memory gain across two leave events; focused test passes.

## BT22-051 — Okuwamon — 10/10

1. **Catalog.** Green level 5, cost 8/7000, Insectoid/CS; CS level-4 cost 3; Fortitude, suspend/conditional lowest-DP return, and inherited security trash.
2. **KB.** Q4903 defines repeated levels across the whole stack; Q4904 bars inherited activation when its host and opponent are deleted simultaneously.
3. **Clauses.** Fortitude, paired suspend→conditional Return windows, alternate evolution, and inherited battle-delete watcher map every clause.
4. **Requirements.** Return requires any repeated stack level and selects a suspended opponent Digimon tied for lowest DP; inherited trigger requires the host to remain present.
5. **Costs/failures.** No effect cost; without the repeated level only suspension resolves; empty security makes the inherited body a no-op.
6. **Controllers.** Owner chooses suspension and any tied lowest-DP return target.
7. **Zones/order/face.** Suspension precedes hand return; battle-deleted stack and top security go to trash in their respective windows.
8. **Timing/OPT.** Main clauses are On Play/When Digivolving; inherited battle watcher is All Turns once per turn and respects Q4904 source presence.
9. **UI.** Generic suspension, superlative target, Fortitude, and security narration apply.
10. **Gates.** Public evolution proves Q4903 and return; public battle proves surviving host deletion plus top-security trash; focused test passes.
