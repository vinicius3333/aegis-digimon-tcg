## BT22-077 — Dianamon — 10/10

1. **Catalog.** Purple/blue level 6, cost 12/12000, Shaman/Olympos XII/Night Claw/CS: alternate level-5 Night Claw/Light Fang/CS cost 3; Iceclad, Blocker; evolution effect; main and inherited end-turn unsuspends.
2. **KB.** Q4941 defines any same-level pair across the stack. Q4942 makes the bottom-deck “Then” unconditional. Q4985/Q4986 order inherited attacks and either unsuspend. Q6247 requires presence as a source at the trigger window.
3. **Clauses.** Keywords, conditional distributed TrashDigivolution, unconditional Return, two separately keyed end-turn Unsuspend effects, and alternate requirement map every clause.
4. **Requirements.** Alternate traits are OR. Trash step requires two same-level stack cards; Return requires an opponent Digimon with at most one source.
5. **Costs/failures.** Trash is as many as available up to four; return still resolves when the condition fails. Each unsuspend is optional.
6. **Controllers.** Dianamon's owner distributes source trash, selects the return target, and chooses each unsuspend.
7. **Zones/order/face.** Trashed sources go to owners' trash; returned Digimon goes to deck bottom with its sources processed normally.
8. **Timing/OPT.** Evolution ordering follows Q4942; main and inherited effects are independent OPTs and only effects present at the end-turn window trigger.
9. **UI.** Generic distributed-source and target decisions apply; no card-specific UI path.
10. **Gates.** Public evolution proof shows Q4942's return with the pair condition false; focused resource-limited test and wave gates pass.
